# 2026-11-11

## 南禅寺大殿 Blender 程序化建模脚本

产出：`nanchan_temple.py`（约 1200 行，Blender 3.3+/4.x 可直接运行）

### 关键技术决策
- **歇山屋面用 10 片参数曲面拼合**，不用单一高度场：
  前/后坡中央各 1、四角回落段各 1、两山撒头面各 1（含前后两半）。
  高度场 `roof_z(x,y)` 分支判据为 `ax > XG and ay < den` → 撒头，否则主坡；
  戗脊线 `ay = den(u)` 两侧严格等值（实测接缝误差 0）。
- **举折曲线** `z = HE + RISE·t^1.5`（t 为距檐口归一化距离），檐部平缓近脊陡峻。
- **山花为垂直三角面**，位于 x=±XG，从 H_G 到 `roof_z(XG,y)`；`XG` 必须大于角柱缝
  （`WIDTH/2*(1-SIDE_FOOT)+0.12`），否则梁架叉手会露在山花外侧 —— 曾踩坑。
- **椽子必须沿曲面分段**（`curved_beam`），两端点直连会因曲线下凹穿出屋面 —— 曾踩坑。
- 斗拱：五铺作双抄偷心造，分 FEN=CAI/15，柱头铺作 8 朵 + 转角双向叠置，无补间（唐制）。
- 屋面坡度、撩檐槫标高闭环：由「槫上皮 + 椽望厚」反推 `HE`，保证屋面与斗拱咬合。

### 验证方法（无 Blender 环境时）
用 `bpy`/`mathutils` 桩件 + 纯 Python z-buffer 光栅化器渲染预览，
配合「按集合分色 / 逐像素归属探针」定位穿帮构件，比盲改有效得多。

### 尺寸参数
面阔 11.75 / 进深 9.90 / 台基 1.05 / 柱高 3.45 / 檐口 6.05 / 正脊 10.50 / 通高 11.06

## 补充：本机 Blender 位置（重要）
`D:/blender/blender.exe` —— Blender 5.0.1。**不在 PATH，不在 Program Files**，
查环境要用 `ls /d/blender` 或全盘搜 `blender.exe`，不要只看 PATH。

## Blender 5.0 实测修正
1. 相机朝向公式：`rot_x = π/2 + atan2(dz, horiz)`、`rot_z = atan2(-dx, dy)`。
   两处符号都曾写错，导致渲染全空/只拍到屋顶。
2. 山花板必须独立对象 + 独立木材质，混在瓦基层里会被当成瓦色，视觉像破洞。
3. Sun 的 energy 单位是 W/m²，2.4~3.6 合适；给到 6 会全画面过曝，AgX 后再压平。
4. Blender 5.0 的 `view_settings.look` 枚举只剩 'NONE'，AgX 预设不可用 → 用 'Standard'。
5. 瓦垄 TILE_R 0.085 / GAP 0.225，瓦当拆到 flat shading 的独立对象才不像珠子；
   屋面基层用更深一档的"瓦沟"材质，瓦垄才有立体感。
6. 渲染：Cycles CPU 48 samples，1500x980，四机位约 40 秒。
