### 立面做法（自下而上）

1. **墙裙** 0.86 m 粉红抹灰，门洞处断开；
2. **碑刻板** 每侧间两块（白色石材 + 浅灰竖行碑文 + 深色碑文区）；
3. **菱花格心窗** 每侧间一樘（45° 斜棂双向对插 + 中心团花）；
4. **板壁** 深褐木，直纹木色；
5. **门洞** 明间 2.40 × 3.04 敞开，穿堂直通后园（山石 + 绿植 + 暗背景）；
6. **匾额** 3.36 × 0.78，楷体金字「保國寺」，贴在阑额下、门洞正上方；
7. **楹联** 明间两侧柱面，竖排金字。

## 技术说明

- 屋面为解析高度场：`surf_xi()` 用 `z=H·(1-t)^k` 实现举折，`(u·v)³` 抬升做翼角起翘兼外扩出翘；
  歇山由「悬山剖面 + 撇山小庑殿 + 山花竖板」构成。
- 瓦垄按「檐口 → 脊线/山花基线」扇形投影逐条放样半圆筒瓦，瓦当与滴水带包檐口。
- 斗拱为参数化模块，矩阵实例化到柱头 / 补间 / 转角。
- 材质全程序化（噪波 / 波纹 / 砖纹 + 按 Z 高度做旧），无外部贴图，文件自包含。
- 天空由天穹球（自发光渐变）提供，兼作环境光；World 仅作弱补光。

## 已知取舍

- 树木、山石为配景简化体块；
- 碑文为示意性竖行刻痕，未逐字还原照片中无法辨识的碑文内容；
- 门内后院为简化透景，非完整庭院。
