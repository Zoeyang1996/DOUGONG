## 保国寺大殿 Blender 建模（技能大赛）

- 依据 4 张实景照片重建宋式重檐歇山殿堂，产出 `保国寺大殿.blend`（86 对象 / 273,828 顶点 / 19 程序化材质 / 8 集合）+ 4 张 2560×1440 Cycles 成图。
- 技术路线：Python 程序化生成（`scripts/temple_core.py` 网格与材质库、`temple_arch.py` 建筑构件、`build_temple.py` 场景组装、`render_views.py` 出图）。
- 关键实现：
  - 屋面用高度场解析函数：`surf_xi()` 举折 `z=H(1-t)^k`，`(u·v)³` 抬升做翼角起翘，角部水平外扩出翘；歇山 = 悬山剖面 + 撇山小庑殿 + 山花竖板 + 博风板。
  - 瓦垄按「檐口→脊线」扇形投影逐条放样半圆筒瓦，瓦当 / 檐口滴水带遮屋面板端头。
  - 斗拱参数化模块（栌斗/泥道拱/华拱两跳/下昂/令拱/耍头/柱头枋）矩阵实例化到柱头、补间、转角。
  - 材质全程序化（噪波/波纹/砖块 + 按 Z 高度乘算做旧），无外部贴图，文件自包含。
- Blender 5.0 注意点：
  - 新建材质默认只有输出节点，删除节点后引用会失效，须重新获取。
  - 天空类型枚举为 `MULTIPLE_SCATTERING / PREETHAM / HOSEK_WILKIE`，无 NISHITA。
  - 中文字体：`STXINGKA.TTF` 缺繁体字形（國/莊/進），匾额改用 `simkai.ttf`。
- 尺度：面阔 21.2 m，进深 13.2 m，檐柱 5.86 m，下檐 9.36 m，正脊 17.70 m。

## 追加：保国寺山门（第 4 张参考图，单檐歇山三开间）

- 新场景 `保国寺山门.blend`（74 对象 / 125,160 顶点 / 23 材质 / 9 集合）+ `renders_gate/` 三张 2160×1040 成图。
- 脚本：`scripts/gate_arch.py`（构件）+ `build_gate.py`（装配）+ `render_gate.py`（出图），复用 `temple_arch` 的屋面 / 瓦垄 / 脊饰函数。
- 尺度：面阔 14.2（明间 3.2 + 次间 5.5×2），进深 6.2，檐柱 3.9，檐口 6.58，正脊 10.13，台基 16.4×7.9×1.3。
- 立面要素：粉红墙裙、白色碑刻板（4）、菱花格心窗（4）、深褐板壁、敞开门洞穿堂、匾额「保國寺」、柱面楹联、两侧白墙拱券门（左红门右洞开）。
- 关键教训：
  - 拱门洞必须把墙身拆成「左段 + 右段 + 拱上段」三块，整块 box 会把洞堵死。
  - `MeshAccum.box/cyl` 带矩阵时是「绕自身中心旋转后平移到 c」，斜棂要用 (长度, 厚, 截面) 尺寸而非 (dx,0,dz)。
  - World 里 Generated/Incoming 做渐变天空在 Cycles 下不可靠，改用**自发光天穹球**（Generate→SeparateXYZ→MapRange→ColorRamp→Emission）。
  - 匾额文字、碑文用几何体实现时要注意面板 bevel 会把刻字吞掉（刻字需前移 5mm 以上）。
