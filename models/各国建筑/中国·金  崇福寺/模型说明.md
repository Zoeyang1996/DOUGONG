## 二、形制判定（据照片）

- 单檐**歇山顶**，正脊—垂脊—戗脊齐全，两端鸱吻、中央脊刹，翼角强烈起翘、垂脊走兽。
- **面阔七间、进深四间**；正立面七间全部装隔扇门（与照片一致），只明间敞开。
- 檐下为**七铺作双杪双下昂**斗拱，补间铺作每间 3 朵，柱头各 1 朵，转角用 45° 角华拱。
- 朱红灰泥墙身，下段**白灰墙基**约 1.05 m；屋顶灰布瓦，檐口**绿琉璃剪边**＋勾头滴水，正脊亦为绿琉璃。
- 山面做**收山 4.60 m**，山花**敞开**（可见丁栿、太平梁、脊瓜柱、叉手），外覆博风板、悬鱼、排山勾滴。
- 台基为青砖台明＋条石压阑，正面踏跺带垂带石；殿前铜香炉、青砖铺地、甬道、花坛。

### 屋面数学（本版核心）

```
z(x, y) = min( 长坡 f_main(y), 撒头 h_end(x) ) + 翼角起翘 corner_lift(x, y)
```

- 戗脊即长坡与撒头的交线，由 `hip_y(x)` / `hip_x(y)` 二分法求解，两片几何必然贴合，不会错缝。
- 长坡拆为**三片独立网格**：正身中段（`|x| ≤ 收山线`）、两端翼角段、两山撒头。山花正处于三片之间，因此**天然敞开**。
- 举折曲线按「九举—七五举—六五举—五举」分段（`PROF_D/PROF_M`），实例中为 Hermite 平滑插值。
- 翼角起翘 `corner_lift` 集中于角部 40% 范围上扬，向内平缓衰减，可由 `corner_rise` 整体调幅。

## 五、材质与贴图

全部贴图由 `cf_tex.py` 用 numpy 程序化生成（可复现、可改参数），共 29 张：朱红灰泥墙、白灰墙基、深褐木构、朱红木作、梁枋木纹、裙板浮雕、条石、阶条石、青砖铺地、布瓦屋面、绿琉璃、鎏金、铜锈，均配对应法线图；匾额与榜书为几何＋纯色材质。

主要材质参数：墙面粗糙度 0.86、木构 0.58–0.72、瓦面 0.93、琉璃 0.52、石材 0.80–0.94（Principled BSDF，AgX 色彩管理）。

## 六、光照与出图

- 太阳光：暖白（1.0 / 0.940 / 0.835），能量 3.30，自左前上方照射，`angle = 0.38` 以求柔和阴影。
- 天空：程序化渐变天空（天顶蓝 → 地平淡青，强度 0.95）＋冷色面积补光（关闭相机可见）。
- 色彩：AgX，Medium High Contrast，`exposure = 0.42`。
- 相机：正面 35 mm、转角 32 mm、门前 42 mm、细部 54 mm。
- 输出：1920×1080、Cycles 220 采样＋降噪。

## 七、本版修复与对齐记录

针对反馈的「山面破损／异常」，本轮定位与修复：

1. **山面斜向瓦面条带、覆盖山花的灰白三角面** —— 根因是长坡网格在收山线处跨越两段（脊起 / 戗脊起）连续连面，生成了竖直折面；撒头网格首行又因 `x == 收山线` 退回长坡高度，同样拉出竖面。现改为三片独立网格 + 撒头直接以 `h_end` 定高，竖折面彻底消除。
2. **山花形态改为敞开** —— 与转角近景照片一致，内部补建丁栿、太平梁、脊瓜柱、瓜柱、叉手与暗背景板。
3. **翼角起翘** —— 起翘量 0.95 → 2.55 m，并改为集中于角部的上扬曲线。
4. **出檐** —— 3.90 → 4.60 m（收山同步 4.60，山花位置不变），屋顶出挑更深、檐下阴影更接近照片。
5. **台基** —— 高度 2.40 → 2.00 m、院坪 −1.30 m（露出 1.30 m），踏跺改为 8 级并加前缘暗缝；台基砖 `uv_scale` 0.20 → 0.55，砖块尺度回到真实比例。
6. **屋面颜色** —— 瓦面基色大幅压深（0.372 → 0.238），粗糙度 0.88 → 0.93，接近照片中的深青灰布瓦。
7. **七间全设隔扇门** —— 原仅中间五间，与照片不符。
8. **匾额** —— 尺寸 1.34×4.8 → 1.70×3.5 m，位置上移至檐下；黑底（albedo 0.009）金字，字号与字距调整为竖排满幅。
9. **斗拱** —— 统一为略亮的木色（新增 `斗拱木` 材质），消除明暗反差过大的「石块感」。
10. **铜香炉** —— 移到台阶前院中，比例与照片一致。

## 八、还原程度与已知差异

- 开间、进深、举高、出檐、收山、斗拱层高等主要比例参照照片与金代《营造法式》做法推定，整体轮廓、层级、屋顶形态、门窗划分、斗拱密度与照片一致。
- 照片未覆盖的部位（背面墙体、室内、山花背侧、斗拱内侧构造）按同时代规制补全，属于合理推定。
- 为控制面数与渲染速度，斗拱、瓦垄、勾头、脊兽做了适度简化；细看不如实物繁密。
- 照片中的石狮、朱漆栅栏、柏树未纳入，以保持建筑主体的净空；如需可再行添加。
- 如需更精细的斗拱（逐件出跳、卷杀）或更大尺寸贴图，可在现有参数与脚本基础上加密。
