## 一、建模思路

### 1. 尺度标定

以法隆寺五重塔实测数据（总高 32.5 m，其中相轮 9.1 m；初重柱间三间；各重平面由下至上递减至约 0.6）为基准，
先定一套"标高递推"常量，其余构件全部由这些常量推导，保证任何一处比例改动都能整体联动。

| 常量 | 含义 | 取值（第 1→5 重） |
|---|---|---|
| `PLAT_H` / `PLAT_HALF` | 二重基坛高 / 半宽 | 1.10 m / 8.30 m |
| `B[i]` | 塔身（柱心）半宽 | 6.25 / 5.65 / 5.05 / 4.45 / 3.90 |
| `W[i]` | 檐口半宽（出檐深度） | 10.44 / 9.30 / 8.35 / 7.35 / 6.45 |
| `H_WALL[i]` | 柱高（墙体段） | 2.66 / 1.92 / 1.82 / 1.70 / 1.58 |
| `BR_H[i]` | 组物（云斗栱）高 | 1.16 / 0.96 / 0.91 / 0.86 / 0.81 |
| `SLOPE` | 屋面坡度 | 0.47（约 25°） |
| `LIFT` | 檐角起翘量 | 0.64 m |
| `ROOF_T` | 屋面厚度 | 0.42 m |

派生标高 `F[i]`（各重地面）、`E[i]`（檐口）、`T[i]`（屋脊）：

```
F[0] = 基坛顶
BRTOP = F + H_WALL + BR_H          # 组物顶（丸桁标高）
E     = BRTOP − 0.085 × 出檐深度    # 檐口低于组物顶 → 檐下露出小壁
T     = E + 出檐深度 × SLOPE
F[i+1] = T[i]
```

这样"柱 → 组物 → 小壁 → 屋面"四段的叠压关系与实物一致：檐口略低于云斗栱顶部，白壁（小壁）因此能从檐下露出一条，
这正是法隆寺重檐外观最关键的层次特征。

### 2. 屋面曲面（决定整体气质）

四注造屋面用解析函数直接生成，而不是手拉控制点：

```python
z(t) = T − (T − E)·t^0.72            # t = 0 在脊部，1 在檐口
z   += LIFT · t^2.4 · (min(|x|,|y|)/r)^4.2   # 四角起翘
```

- `t^0.72 < 1` 使屋面呈**凹曲面（照り）**：近脊陡、近檐平——这是日式屋面与中式/歇山直坡面的分水岭；
  早期版本误用 `t^1.15`（近檐反而陡），屋面就成了"鼓起的枕头"。
- 起翘项对 `t` 取 2.4 次幂、对角部比例取 4.2 次幂，起翘集中在檐口靠角约 30% 的范围内，
  形成平缓下垂后向上飞起的"翼角"，避免了尖端锐角。
- 62×62 网格 + Solidify（厚度 0.42、`offset=-1`）得到带厚度的瓦面，
  上表面贴瓦材质、下表面（轩裏）单独给深色木材质、檐口侧壁保持瓦色。

### 3. 构件级建模清单

所有构件都由一个自写的网格累加器 `MB` 生成（累积顶点/面/材质索引/UV，最后一次 `from_pydata` 建对象），
避免了几千次 `bpy.ops.mesh.primitive_*` 的性能开销。

| 部位 | 做法 |
|---|---|
| 基坛 | 三层石砌体 + 束腰线脚 + 四面石阶；石缝由 Brick 纹理生成 |
| 初重 | 卍崩し高栏、廻縁木地板（含板缝、悬臂梁、石础）、板扉（含八双金具与门环）、连子窗 |
| 塔身 | 白壁 + 地覆/头贯/长押 + 圆柱（含柱础、柱头）+ 各间连子窗/板扉；上四重窗洞缩小并上移，留出大面积白壁 |
| 组物 | 每面 7 朵：大斗 → 云肘木（横向）→ 云肘木（纵向）→ 尾垂木 → 通肘木两道 |
| 屋面 | 凹曲面网格 + 丸瓦（沿坡 sweep，剖面为半圆）+ 平瓦行 + 轩丸瓦（檐口圆瓦当）+ 茅负 + 隅栋（云形剖面）+ 鬼瓦 + 风铎 |
| 轩下 | 地垂木、尾垂木、丸桁、椽子（两段出挑，凸出于轩裏形成条状阴影） |
| 相轮 | 露盘（三级方座）→ 伏钵 → 请花（16 瓣莲瓣）→ 擦管 → 九轮（自写 `annulus` 环形薄片）→ 水烟（火焰镂空板 ×4）→ 龙车 → 宝珠 |
| 环境 | 二重石灯笼 ×2、150 株程序化树木（阔叶为不规则椭球 `blob()`，针叶为锥叠）、砂砾地面 + 石叠 |

最终场景：**189 个物件、约 30 万顶点**。

## 二、贴图与材质方案

### 1. 贴图来源

Poly Haven **CC0** 2K PBR 贴图三套（`tex/`，已解包为 diff / rough / nor_gl / disp）：

| 贴图集 | 用途 | 通道 |
|---|---|---|
| `stained_pine` | 木构件（板扉、地板、部分梁） | diff / rough / nor_gl |
| `gravel_embedded_concrete` | 砂砾地面、石叠 | diff / rough / nor_gl |
| `plastered_wall_05` | **不直接用作白壁**（见下） | 仅作 AO/起伏参考 |

> 实测 `plastered_wall_05` 的平均色为 RGB(69,73,77)，是深灰熟石灰，直接乘 tint 也做不出法隆寺的明亮白壁，
> 因此白壁改为纯程序化材质。

### 2. 材质矩阵

| 材质 | 类型 | 关键参数 |
|---|---|---|
| `vermilion` / `vermilion_b` | 程序化丹涂り木 | 基色 (0.106,0.063,0.043) / (0.078,0.048,0.034)；拉伸噪波做木纹，大尺度噪波做风化斑；粗糙度 0.70 / 0.78 |
| `soffit_wood` | 程序化深木 | (0.046,0.032,0.023)，粗糙度 0.90，用于轩裏，保证檐下压暗不跳 |
| `plaster` | 程序化石灰壁 | (0.76,0.74,0.69)，细噪波做抹灰颗粒 + 竖向拉伸噪波做雨痕，粗糙度 0.86 |
| `tile` | **UV 驱动**本瓦葺 | 每列瓦 u/0.315、每行 v/0.30 取整后送 White Noise → 逐瓦色差；行缝用 fract 生成暗线；丸瓦/平瓦双 wave 起伏进 Normal；粗糙度 0.74 |
| `tile_dark` | object 空间瓦件 | 用于无量 UV 的 sweep 件（隅栋、鬼瓦），同色域明度稍低 |
| `tile_edge` | 轩丸瓦瓦当 | 浅灰 (0.33)，形成檐口那条醒目的浅色锯齿带 |
| `wood_light` / `wood_dark` | 针叶木 PBR | `stained_pine` + Box 投影 + tint + 噪波污渍 |
| `stone` / `stone_step` | 石 | 噪波底色 + Brick 纹理做砌缝与色差 |
| `bronze` / `bronze_l` / `gold` | 金属 | 噪波色差 + 铜绿 patina 混合；九轮/水烟用较亮的 `bronze_l` 以便在天空前读得出轮廓 |

### 3. 瓦面的 UV 约定

屋面网格的 UV 不是常规展开，而是**按构造展开**：

```
u = (abs(y) >= abs(x)) ? x : y      # 沿檐口方向（横向）
v = max(|x|, |y|) − 内圈半径         # 沿坡向（纵向）
```

于是无论四个坡面如何拼接，u 始终沿瓦垄、v 始终顺水，瓦垄密度与出檐长度自动匹配，
不会出现"棋盘格"或横向错铺——这是早期版本最大的一个坑。

## 三、光照与色彩管理

- **环境**：`kloofendal_48d_partly_cloudy_puresky` 4K HDRI（`hdri/sky_pure.hdr`），强度 0.72；
  世界坐标取 `Incoming` 取反后按 Z 分带，用地平线以下替换为暖灰地面色，使地平线过渡自然。
- **主光**：Sun，强度 3.3，色温偏暖 (1.0, 0.958, 0.900)，仰角约 55°，方位偏前左，使正立面有明暗面。
- **补光**：地面反弹 Area（900 W，大面积、低强度）+ 天光 Area（220 W，冷色），
  补光刻意压低——过强的反弹会把檐底轩裏打成一片平白，失去斗栱与椽子的阴影层次。
- **色彩管理**：`Khronos PBR Neutral`，曝光 −0.20（备选 AgX / AgX-Punchy）。
- **采样**：Cycles 自适应采样，阈值 0.01，OpenImageDenoise 降噪；成图 256 spp。

## 五、还原要点小结

1. **凹曲面屋面 + 翼角起翘**用一条解析函数控制，是形体相似度的第一决定因素。
2. **檐口略低于组物顶**，让白壁（小壁）从檐下露出，形成"瓦—白—丹—白"的横向条纹节奏。
3. **出檐深度按 4.2 → 2.55 m 递减**，配合塔身 6.25 → 3.90 m 的收分，得到法隆寺特有的"厚重而不过高"的剪影。
4. **色彩关系**：深灰瓦（明度最低）→ 白壁（最高）→ 丹涂り木（中调偏红），三色面积比约 4:2:4，
   与参考照片的色块分布一致；金属相轮用冷绿铜色压住顶部，避免整体偏暖。
