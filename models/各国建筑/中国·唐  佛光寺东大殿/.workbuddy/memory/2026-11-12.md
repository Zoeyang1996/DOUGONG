# 2026-11-12

## 佛光寺东大殿 Blender 参数化建模

- 环境：Blender 5.0.1 位于 `D:\blender\blender.exe`，无系统 numpy（用 Blender 自带 python）。
- 依据：张荣/刘畅/臧春雨《佛光寺东大殿实测数据解读》(2007) 实测值 —— 通面阔 34.00m（中五间各 5.06、梢间 4.41）、通进深 17.66m（4.40/4.43/4.43/4.40）、平柱高 5.00m、檐柱径 0.54~0.60m、角柱生起 0.24m、斗栱高 2.50m、总檐出 3.63m、撩檐槫距 21.52m、举高 4.39m、脊槫高 11.845m、屋面举折 1:4.77。
- 结构：七铺作双抄双下昂斗栱（柱头铺作 + 每间补间一朵 + 转角铺作）、单檐庑殿顶、板门（门钉/铺首/门环）、两梢间直棂窗、山面直棂窗、拱眼壁、彻上明造椽望、正脊鸱吻+宝顶、四条垂脊、台基+月台+踏道+石栏板、唐石经幢。
- 配色（sRGB albedo）：土朱木构 #84503A、檐下深木 #6B4029、门板 #8A5036、白灰走马板 #B4A78C、檐墙土朱 #8E4E38、青灰筒瓦 #585C61 / 瓦沟 #41454A、石作 #9E9483、门钉 #6B5B44。
- 代码：`build/blib.py`（网格/扫掠/材质分组）、`build/mats.py`（程序化材质，低频色差+高频细节，近地风化渐变）、`build/hall.py`（全部构件参数化）、`build/build_scene.py`（场景/灯光/相机/渲染）。
- 渲染：EEVEE，AgX + Medium High Contrast，环形渐变天幕（Emission）+ 铺地砖纹地面。
- 产物：`佛光寺东大殿.blend`（约 4MB，18.2万顶点/15.5万面）、`render/{front,three,corner,back}.png`。

## 踩过的坑（重要）

- Blender 5.0 渲染引擎标识为 `BLENDER_EEVEE`（不是 `BLENDER_EEVEE_NEXT`）。
- 用 Object 坐标的 Wave 纹理做木纹会产生"斑马纹/条形码"，必须低对比、只做 bump。
- 庑殿两山坡网格的 y 范围应为 `±AY*(1-t)`，写成 `±(RX+AY*(1-t))` 会多出一大块飞出的屋面。
- 椽子/飞椽端点与檐口封边共面会 z-fighting，端点需内收 5~6cm。
- 瓦垄必须铺满到垂脊（不能只到正脊两端），否则翼角区出现无瓦空白带。
