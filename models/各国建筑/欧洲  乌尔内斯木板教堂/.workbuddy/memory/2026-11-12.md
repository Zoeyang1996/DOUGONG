# 2026-11-12 · 乌尔内斯木板教堂程序化建模

## 交付物
- `Urnes_Stave_Church.blend`（D 盘工程根目录，5.2MB，Cycles 160spp，4 机位）
- `renders/render_front|hero|side|detail.png`（成品图）
- `scripts/build_urnes.py`（建模主脚本）+ `scripts/urnes_lib.py`（几何/材质库）+ `scripts/render_check.py`（仅渲染检查）

## 关键技术决策
- 全程序化：Python 生成 verts/faces，per-loop `tint` FLOAT_COLOR 属性做逐瓦/逐板色差，无外部贴图。
- 集合分层 `01_Site`…`09_Cameras_Lights`，对象前缀 `FND_/GAL_/POR_/NVE_/CHN_/TOW_/ROF_/DET_/SITE_`。
- 屋面瓦片：菱形鱼鳞场，`pitch_u = tile_w/2`、`v` 方向每层一个 `course`，四角按 `k = 1-gap/hw` 内缩留暗缝；
  每片 11% 概率深色(0.34-0.58)、14% 漂白(1.22-1.62)，其余 0.80-1.16。
  **踩坑**：早期按层只抬 3.2mm 而板厚 22mm，层间互相吞没 → 屋面渲染成一整块灰板。
- 材质为节点组合：Wave/Noise/Voronoi + ColorRamp + Mix(MULTIPLY)，`tint` 经 Mix 混入，木纹/风化/地衣分层。
- 渲染：AgX + Medium High Contrast，exposure 0.32，Sun(54°,0,-46°) + 2 盏 Area，世界渐变天空 1.55。
- 中文界面下 `nodes["Principled BSDF"]` 会 KeyError，须按 `n.type=='BSDF_PRINCIPLED'` 取节点。

## 结果
64 对象，112604 面，五次逐轮渲染比对参考照片（屋面层理、菱形山墙、尖顶横瓦、门廊背板、东端收口）。

## 追加：塔顶对齐修复
- 病灶：`TOW_Y0..Y1 = -4.30..-0.90`（塔身轴心 y=-2.60），而尖顶/顶饰全部按世界原点 (0,0) 生成 → 尖顶整体偏移 2.60m，半侧悬空。
- 修法：引入 `TCX, TCY = 0, 0.5*(TOW_Y0+TOW_Y1)`，尖顶 levels / 四角压条 / 顶饰轴 / 十字全部随轴心；`SPIRE_R 2.26 → 2.00`；新增 `TOW_Spire_Skirt`（封顶方板 + 菱形檐口板 + 四边裙板）收拾挑出部分；檐口板不可做成大方形平板（四角会成薄刃）。
- 经验：`MB.build` 加空网格保护；blend 保存必须 `compress=False`，否则文件头为 zstd `28 B5 2F FD`，通用性差。
