# 新 IP 角色设定：小斗（栌斗拟人）v01

> 用途：展陈触屏、拼搭游戏、科普讲解与周边衍生的第二枚 IP；与已有「小拱」搭档。
> 原型依据：宋《营造法式》栌斗（大斗）；保国寺大殿栌斗随柱做八瓣。术语口径沿用宋式，不用清式。
> 关联素材：`docs/02-内容/03-斗拱-术语与构件.md`、`docs/02-内容/02-保国寺-结构与斗拱形制.md`；已有形象 `~/Downloads/xiaogong-turnaround-v01.png`。

---

## 一、定位与使命

- **角色名**：小斗（Xiaodou）；构件学名：栌斗（ludou，大斗）。
- **原型**：整朵铺作最底部、体型最壮的方形垫块，置于柱头或阑额之上，十字开口承托交叠的华栱与泥道栱；容量约等于 8 个齐心斗。
- **展陈分工**：
  - 小拱主「向外挑出」——讲出跳、栱臂形态与屋檐；
  - 小斗主「向下承托」——讲受力传递、榫卯咬合、模数与基础。
  - 拼搭游戏中作为「起始底座」角色，第一块被放上去的构件就是它。
- **一句话人设**：我在最底下，托住整朵斗拱。

## 二、与小拱的区分对照（五项必须拉开）

| 维度 | 小拱（已有 IP） | 小斗（新 IP） |
|---|---|---|
| 原型构件 | 栱（横向挑出的弓形木） | 栌斗（底部方形垫块） |
| 主剪影 | 对称横展、宽冠、圆头 | 竖立方墩、方头、**无横展栱臂冠** |
| 头身比例 | 八棱圆头 + 短袍少年 | 三段式斗形方头 + 矮壮躯干、低重心 |
| 主色 | 浅橡木 / 中棕 / 深棕暖木系 | 深栗木 / 老杉深色系，面部手部略浅一档 |
| 点缀色 | 红领、橘粉腮红 | 朱红 + 白「七朱八白」小面积彩画，淡赭腮红 |
| 性格气质 | 温和外向、讲解员 | 沉稳托底、守护者，话少靠谱 |
| 标志部位 | 整朵斗拱横展冠 | 斗形三段头（耳 / 平 / 欹）+ 四耳十字开口 + 八瓣切角 |

> 剪影测试：去掉颜色与细节后，小拱是「一横展宽冠的圆头」，小斗是「一方墩厚头的矮个子」，二者并排不能混淆。

## 三、造型细节（建模 / 生图直接依据）

### 1. 头部（身份锚点，优先保证）

- 整体是一只立起来的栌斗，立面自上而下分三段：
  - **耳**：开口后向上突起的部分，左右成对；
  - **平**：中段平直束腰；
  - **欹**：下段底面斜收、向外微撇。
- 头顶为**十字开口**，前后左右共四只耳；正面见左右两耳，侧面见单侧厚耳，背面见后两耳。
- 头部外轮廓做**八瓣瓜棱 / 海棠瓣切角**（保国寺八瓣栌斗特征），方块形态但边角圆润。
- 五官：方形脸盘上一对大圆深棕眼（眼形与小拱呼应，脸型偏方），平直厚眉，嘴角平实微抿；淡赭石色圆腮红，**不用粉色**。
- 头顶斗口内嵌一枚小小的散斗作为身份标记（坐于耳间）；头上**不生长横展栱臂**，与小拱冠饰明确区分。

### 2. 身体与姿态

- 矮壮墩实、低重心，短四肢；双脚扎实分开站立，双手习惯向上托举或按在腰间（承托意象）。
- 服装：短褐 / 坎肩式木甲，由一块块枋木板拼合，板缝与榫卯隐约可见；交领，腰束宽带；下身短裙甲，脚穿方座靴（靴头如柱础方墩）。

### 3. 配色与材质

- 主色：深栗木 / 老杉，哑光木纹；面部、手部略浅一档以保证五官可读。
- 强调色：宋式「七朱八白」——朱红用于领缘、腰带、耳瓣边缘；小面积白色块点缀；朱红总面积控制在 10% 以内。
- 材质：3D 哑光木质玩偶，可见细腻木纹，边角圆润；布光、渲染管线与小拱保持一致，便于同框出现。

### 4. 性格与行为

- 面对观众：先稳稳站定，再开口；讲解受力与榫卯时眼睛发亮。
- 习惯动作：双手向上托举（承托）、双手按腰（站稳）、低头看脚下（讲基础）。
- 口头禅方向：
  - 「我在最底下，托住整朵斗拱。」
  - 「稳不稳，先看底子。」
  - 「不用一根钉，咬得住才站得久。」

## 四、衍生预留

- **表情页**：托举、托底、沉稳、鼓劲、疑惑（5 个起）。
- **双人组合**：小拱横展挑出在上，小斗方墩承托在下；一横一竖、一浅一深、一圆一方。
- **游戏角色**：拼搭流程的起始底座；知识点围绕「栌斗位置、十字开口、耳平欹三段、八瓣、传力路径」。
- **命名登记**：中文名「小斗」，拼音 Xiaodou，构件名「栌斗 / 大斗」；对外文案首次出现时标注学名。
