# 第二幕 · 四级：建筑三维预览

> 2026-11-15｜在「三级详情」之上加一层：点详情页的图片，画面中心出现该建筑的三维模型。
> 素材来自 `models/各国建筑/`，代码只动第二幕自身与 `shared/vendor`（新增解码器，未改原有文件）。

---

## 一、这一层长什么样

```
一级  地区（中国 / 日本 / 欧洲）
二级  朝代（唐 / 五代 / 辽 / 宋 / 金 / 元 / 明清）
三级  点地名签或名录 → 左侧详情（图文）
四级  点详情页的图片 → 全屏三维预览
```

- 详情页图片右上角出现一枚 **「三维 ↗」** 标签，图本身变成按钮（`<button class="photo-frame has-model">`）。
- 点开**不是跳转到新页面**：原界面留在原处不动，被压成一层暖墨玻璃（`backdrop-filter: blur(20px) saturate(.8) brightness(.88)`），
  模型从下方升起、浮在玻璃之上；**没有天空，也没有地面**，只有模型背后一团极淡的暖光。
- 左上建筑名与操作提示，**右上圆形叉叉**；拖拽旋转、滚轮/双指缩放、`Esc` 或点叉叉或点背景关闭。
- 关闭时模型沉回下方、玻璃散去（220ms），动画结束后才释放几何与贴图；重新打开会重新加载（有进度百分比）。

**没有模型的建筑不显示标签**，图片仍是原来的静态图，不会出现死按钮。

### 导出做了四件事（脚本见附录）

1. **清辅助物**：相机、灯光，以及名字含「地面 / 广场 / 甬道 / 参道 / 砂利 / 天空穹顶」的网格——它们会把包围盒撑到几百米，取景全乱。
2. **只留主建筑**：以面数最多的物体为锚点，扔掉离它 2.4 倍尺寸以外的散景（东大寺一次扔掉 64 个远处的树石配景）。
3. **颜色落进材质**：这些工程的颜色多在程序化 Mix / ColorRamp 里，glTF 无法表达，直接导出会是全白。做法是用 Cycles 把漫反射色烘到顶点，再按材质求平均写入 `baseColorFactor`；金属材质没有漫反射（烘出纯黑），回退到它原本的基色。乌尔内斯的色带含大量风化高光，按沥青浸黑的实际情况压到 42%。
4. **归一化 + Draco**：最大边缩到 10 个单位、底面落地、水平居中；开 Draco 压缩，体积约为未压缩的 1/5。

> 试过把顶点色原样交给 glTF（`COLOR_0`），但在这批文件上要么全是 1、要么全是 0，三家加载器表现不一致；改用「每材质一色」后稳定且更小。

## 五、改成「玻璃雾化 + 升起」（2026-11-15 下午修订）

原来点开是一层全屏黑场，等于换了个页面，与"在原界面之上浮出"的意图不符。改动集中在 `css/viewer.css` 与 `js/viewer.js` 的取景与关闭流程。

### 1. 背景：不再是黑场，而是玻璃

| 项 | 值 |
|---|---|
| 底色 | `radial-gradient`，中心 `rgba(44,35,25,.42)` → 边缘 `rgba(16,12,9,.70)` |
| 雾化 | `backdrop-filter: blur(20px) saturate(.8) brightness(.88)`（含 `-webkit-` 前缀） |

底色刻意只压到半透明：下面的详情页、地球、导航仍隐约可见，但被糊成色块，不抢模型的注意力。
不能改用 `body { filter: blur() }`——那会把遮罩层自身一起糊掉。

### 2. 舞台：四周留白，模型浮在中间

`inset: clamp(70px,9.5vh,116px) clamp(20px,4.5vw,88px) clamp(54px,7.5vh,88px)`，
canvas 透明（`alpha: true`），场景里只有灯光与模型——**没有天空盒，也没有地面网格**。
舞台背后加一团 `radial-gradient` 暖光（中心 10% 不透明度），让轮廓从雾面里透出来；这不是几何地面，关掉也不影响模型。

### 3. 升起 / 沉回

- 打开：遮罩 320ms 淡入，舞台 480ms 从 `translateY(46px)` 升到位。
- 关闭：`is-closing` 类 → 遮罩 220ms 淡出、舞台沉回 `translateY(38px)`，230ms 后才 `hidden` 并释放模型。
  必须先播完再释放，否则模型会在淡出中途消失（闪一下）。

### 4. 取景重算（顺带修的两个问题）

| 问题 | 原因 | 处理 |
|---|---|---|
| 手机竖屏模型缩成一小块 | 宽度约束里用了 `max(0.6, aspect)`，竖屏 aspect≈0.5 被强行当 0.6，距离多算 20%；再乘 1.45 余量 | 改为按真实 aspect 计算，竖屏余量 1.1、横屏 1.34 |
| 拖拽到低角度时台基跑出画外 | 没有俯仰限位，且视线略低于中心 | `minPolarAngle = 0.55`、`maxPolarAngle = 1.44`；视线按 `size.y × 0.04/0.12` 下移，模型在画面里上浮 |
