# 第二幕 · 全国统计与省域特写

> 2026-11-16｜两处改动：朝代页从「本图册收录数」改成「全国现存统计」；点击单座时镜头压到球面上，显示省界与省域填充。

---

## 一、为什么要改

原来的朝代页只显示本图册收录了几处（如明清 2 处），读起来像"明清只有 2 座木构"——这是错的。本图册是选集，不是全集。

另一件事：从"朝代"点到"单座"时，镜头只从 0.94 到 1（都已贴着"整球可见"的上限），点了几乎没有反应。用户希望有明显的推近，并且能看到省份。

---

## 二、数据：口径先定死

### 2.1 采用的两套口径

| 口径 | 内容 | 来源 |
|---|---|---|
| A · 元以前木构 | 全国 580 座，山西 495（85%）；唐 3、五代 5、宋辽金 183、元 389 | 山西省文物局（2021，公开答复与三普数据） |
| B · 分朝代明细 | 唐 3、五代 5、辽 8、北宋 47、金 138、元 427 | 王慧莲《了不起的山西古建筑》（据三普与山西省文物局资料整理） |

两套总数不一致（580 vs 628），原因是统计范围不同（是否计入次要殿宇、断代存疑者、石窟窟檐等）。**页面上不做加总，逐朝代分列，并注明来源**，避免用一套口径的数去凑另一套。

## 三、实现

### 3.1 版面：两个数字分开

朝代页现在有两块数：

```
全国现存  3 座              ← 新增，来自 ERA_STATS
 山西 ████████████ 3

3 处 · 本图册收录           ← 原有，可点
 收录分布（省份格）
 建筑名录
```

两块数字各有标题，不会再把"收录数"误读成"现存数"。

### 3.2 省界层（`js/globe/globe.js`）

- 数据：`assets/data/china-provinces.json`，35 个省级单元，24,234 个顶点，398KB。
  源为阿里云 DataV 的省级边界（GCJ-02），已抽稀到 0.02°（约 2km），去掉多余属性。
- 几何：每个 ring 的相邻点连成线段，半径 `2.004`（比球面高 0.004，防 z-fighting）。
- 显示：两个 `LineSegments` —— 底图（全部省界，opacity 0.22）+ 高亮（当前省，朱红 1.0）。
- 填充：高亮省用 `THREE.ShapeUtils.triangulateShape` 在经纬度平面三角化，再映射回球面，`opacity 0.26`。只填外环，不管洞（省界数据里几乎没有洞）。
- 显隐条件：`country === '中国'` 且（已选单座 或 已选朝代 或 已筛省份）。
- 省名：`#province-tag` 在画布上方标出当前省，去掉"省/市/自治区"后缀。

### 3.3 镜头：允许球边出血

原来 `nearestDistance()` 是"整球可见"的极限（约 5.6）。现在分两级：

| 级 | 用途 | 距离 |
|---|---|---|
| `nearestDistance` | 全球 / 地区 / 朝代，整球可见 | ≈ 5.6（2.8R） |
| `detailFloor` | 单座特写，压到球面上方 | 2.16（1.08R） |

`LENS` 新增 `closeup: 1.9`（日本、欧洲用），`building: 2.6`（中国用）。

**为什么中国更近**：中国有省界与填充，贴到 1.08R 时画面变成省域地图；日本、欧洲没有省界数据，太近会只剩一片陆地纹理，所以退到 1.9（约 2.76，能看到海岸线）。

实测镜头距离：地区 6.09 → 中国单座 2.16（视野约 44°）→ 日欧单座 2.76（视野约 88°）。

### 3.4 近景可读性

球面压到近处后是深褐色，原来的深字标签完全读不出来。处理：

- `body.is-closeup` 时，`.map-label` 垫一层 `rgba(242,228,204,.9)` 纸底，去掉外描边；
- 引线改成浅色（纸色 55%），红点改成纸底朱边；
- 省名标与标签同色系，浮在画布上方。

## 五、已知限制

1. **球面物理极限**。相机最近只能到 1.08R（再近会被近裁剪面切穿球体）。此时视野约 44°，一个省约占画面 1/8——**看不到整省**，靠填充与省名弥补。要真正"一屏一个省"，只能改成平面地图模式，那是另一套渲染。
2. **离线包未更新**。`~/Downloads/木构星图-离线版/` 是 11-12 打的，不含 `china-provinces.json`（398KB）。用离线包时省界会缺失（不影响其他功能）。要在西沃上用省界，需重新打包。
3. **省界坐标是 GCJ-02**（高德系），与建筑坐标（WGS84）有百米级偏移。球面尺度下不可见，但严格说不是同一坐标系。
4. **宋金元三省之外的分省数字缺失**。已在页面上写明「其余 N 座」，没有编造。
