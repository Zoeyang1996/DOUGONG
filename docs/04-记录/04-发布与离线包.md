## 二、为什么不能直接双击 index.html

`act-02-globe` 用了 ES 模块与两处 `fetch`（`data.json`、`shared/data/land.geojson`）。浏览器在 `file://` 下会拦截这两类请求，双击只会得到白屏。所以离线包必须打包，不能直接拷贝源码目录。

## 三、离线包怎么重建

目标：一个 HTML + 一个 assets 目录，双击即开，不联网、不起服务。

```bash
# 1. 建立镜像目录（保持相对路径结构，three 与 OrbitControls 才不会找不到）
B=/tmp/act02build
mkdir -p $B/web-exhibits/shared
cp -R web-exhibits/act-02-globe $B/web-exhibits/
cp -R web-exhibits/shared/vendor web-exhibits/shared/data $B/web-exhibits/shared/

# 2. 把两处 fetch 改成静态引入（改完的副本，不动源码）
#    js/data.js      : fetch('./data.json') → import BUILDINGS from '../data.json'
#    js/globe/globe.js: fetch('../shared/data/land.geojson') → import LAND from '../../../shared/data/land.geojson'

# 3. 打包成单文件 ESM（内联模块在 file:// 下可执行，外链模块不行）
web-exhibits/act-01-history/node_modules/.bin/esbuild js/main.js \
  --bundle --format=esm --loader:.geojson=json \
  --alias:three=../shared/vendor/three.module.js \
  --outfile=/tmp/act02build/bundle.js --minify --legal-comments=none

# 4. 生成 HTML：内联 4 个 CSS + bundle，去掉 importmap 与外链 script
# 5. 组装成品
#    ~/Downloads/木构星图-离线版/
#      打开-木构星图.html      （约 740KB）
#      assets/buildings/**     （78 张照片，35MB）
#      使用说明.txt
```

**验收标准**（必须用默认安全策略，不要加 `--allow-file-access-from-files`）：

```bash
chrome --headless=new --screenshot=/tmp/x.png \
  "file:///Users/yangzhe/Downloads/木构星图-离线版/打开-木构星图.html"
```

截图应看到地球与版式；页内再点「中国 → 佛光寺东大殿」，左侧应出现详情且照片 `naturalWidth = 2048`。

## 四、西沃一体机注意事项

1. 拷**整个文件夹**，只拷 HTML 会缺照片。
2. 若被 IE 或旧内核接管（白屏），右键 →「打开方式」→ Chrome / Edge；或把 HTML 拖进 Chrome 窗口。
3. 老旧显卡不支持 WebGL 时，页面会提示「地球暂时无法显示」，左侧名录仍可浏览 39 条。
4. 建议进全屏（右上角按钮）后固定为展项首页。
