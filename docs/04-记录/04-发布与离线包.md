## 二、为什么不能直接双击 index.html

`act-02-globe` 用了 ES 模块与两处 `fetch`（`data.json`、`shared/data/land.geojson`）。浏览器在 `file://` 下会拦截这两类请求，双击只会得到白屏。所以离线包必须打包，不能直接拷贝源码目录。

## 三、离线包怎么重建

一条命令：

```bash
python3 web-exhibits/tools/build_offline.py
```

脚本在 `/tmp/act02_offline_build` 里建镜像（不动源码），依次完成：

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| 1 | `data.json` / `land.geojson` / `china-provinces.json` 改成静态 `import` | `fetch` 在 `file://` 下被拦 |
| 2 | esbuild 打成单文件 ESM | 外链 `<script type="module">` 在 `file://` 下被 CORS 拦，内联模块可以 |
| 3 | CSS + bundle + 省界 + Draco 解码器内联进 HTML | 少一处文件就少一处可能读不到 |
| 4 | 12 个 GLB → `assets/models-js/<id>.js`（base64） | 见下一节 |

成品（约 63MB）：

```
打开-木构星图.html     1.5MB   样式 / 程序 / 39 条资料 / 省界 / 解码器
assets/buildings/       30MB   78 张照片
assets/models-js/       31MB   12 个模型（base64 脚本）
使用说明.txt
```

### 3.1 三维模型为什么要转一遍

`file://` 下浏览器禁止 `fetch` 本地文件，`GLTFLoader.load('xxx.glb')` 必然 `ERR_FAILED`；
`DRACOLoader` 内部也用 `FileLoader` 取 `draco_wasm_wrapper.js` 与 `.wasm`，同样读不到。
所以打包时把两道读取全部换掉：

1. **模型**：GLB → base64 → 普通 `.js`，内容是一句
   `window.__MODEL_B64["<id>"]="…"`。普通 `<script src>` 在 `file://` 下可以加载
   （被拦的是 `fetch`/XHR/模块导入，不是脚本）。点开时按需注入，再
   `loader.parse(arrayBuffer, '')`，全程不发起网络请求。
2. **解码器**：`draco_wasm_wrapper.js` 与 `draco_decoder.wasm` 的 base64 内联进 HTML，
   赋给 `window.__DRACO_LIB`；`viewer.js` 里把 `DRACOLoader._loadLibrary` 换成从内存返回，
   解码器由 `new Worker(blobURL)` 启动——blob worker 在 `file://` 下可用。

`viewer.js` 两种模式共存：`location.protocol === 'file:'` 走 base64 + `parse`，
http 下仍走原来的 `loadAsync`。所以线上与离线共用同一份代码，不必分叉。

代价：base64 比原 GLB 大 33%（22.9MB → 31MB）。实测最大模型（太和殿 330 万面）
从点击到出图 **1.2 秒**，其余不到 1 秒。

**验收标准**（必须用默认安全策略，不要加 `--allow-file-access-from-files`）：

```bash
chrome --headless=new --screenshot=/tmp/x.png \
  "file:///Users/yangzhe/Downloads/木构星图-离线版/打开-木构星图.html"
```

截图应看到地球与版式；页内再点「中国 → 佛光寺东大殿」，左侧应出现详情且照片
`naturalWidth = 2048`；再点带「三维 ↗」的照片，模型应升起且 `.viewer-status` 变为空。

## 四、西沃一体机注意事项

1. 拷**整个文件夹**，只拷 HTML 会缺照片。
2. 若被 IE 或旧内核接管（白屏），右键 →「打开方式」→ Chrome / Edge；或把 HTML 拖进 Chrome 窗口。
3. 老旧显卡不支持 WebGL 时，页面会提示「地球暂时无法显示」，左侧名录仍可浏览 39 条。
4. 建议进全屏（右上角按钮）后固定为展项首页。
