#### 二、二级视角拉近

**根因不是常数太小，而是上限算错了。** 原来“不裁切”的上限用的是
`min(舞台高 × 0.97, 舞台宽)`——在窄窗口（浏览器预览面板、平板）里**宽度变成瓶颈**，
球被压到和舞台同宽，于是二级看起来很远；而且所有级别的固定距离（5.7 / 5.3 / 5.2）
都被这个上限夹到同一个值，三级和四级就完全没差别。

改成按“屏幕上可用半径”定上限：

```js
roomAbove  = 球心以上到视口顶 - 12
roomBelow  = 球心以下到视口底 - 12
roomRight  = 舞台宽/2 + 左溢出/2 - 16   // 右侧不压导航
roomCanvas = 画布高/2 - 6
maxRadius  = min(四个中的最小)
```

球可以向左潜到说明栏下方、向上向下略越过舞台（页头页脚的两条细线已去掉，
球越过时不会被一条线切断），但整个球始终在视口与画布之内，仍然不裁切。

`--globe-canvas` 同步从 `min(88svh, 940px)` 提到 `min(100svh, 1040px)`，给球留出足够画布。

#### 三、四级镜头阶梯

镜头不再传固定距离，而是传“级别”，由级别换算成球半径比例：

| 级别 | 触发 | 半径比例 | 1440×900 实测球径 |
|---|---|---|---|
| 全球 | 初始 / 复位 | 0.60 | 510 px |
| 地区 | 点中国 / 日本 / 欧洲 | 0.86 | 731 px |
| 朝代 | 点唐 / 宋 / 辽… | 0.94 | 799 px |
| 单座 | 点某座建筑 | 1.00 | 850 px |

- 换算：`d = R·H / (2·r·tan(fov/2))`，`r` 为球在屏幕上的目标半径。
- `focus(lat, lon, level)` 会把镜头转到该点并落到该级距离；`zoom()`、双指缩放
  与 `controls.minDistance/maxDistance` 共用同一组上下限，不会越界也不会被夹死。
- 朝代级的落点取**该朝代所有条目的重心**：点“唐”落在山西（38.7N, 113.3E），
  点“明清”落在北京；点单座则直接对准该建筑坐标。
- 返回（`←`）也按层级退回：单座 → 朝代视角，朝代 → 地区视角，地区 → 全球。

#### 四、点击寺庙，左侧出现介绍

这条原来就有，但这次补齐了两点，让它“真的可用”：

1. `pick()` 现在调用 `focus(item.lat, item.lon, 'building')`，点击后镜头一定落到单座级，
   不再被上限夹成和三级一样。
2. `panel.js` 每次换页给 `#panel-content` 加一次 280ms 的 `panel-in` 淡入上移，
   读起来像“左侧弹出”，而不是无声替换。

面板内容仍是原有的 `renderDetail`：返回条 → 照片 → 名称 → 年代 → 地点 →
待核提示 → 正文 → 引语 → 形制/构造/坐标。地名签与名录行都走同一个 `pick()`。

#### 五、顺带修的两个小问题

- **地名签全部挤在顶部**：原来固定从舞台顶往下排，球放大后引线拉成很长的斜线。
  改为“先贴住各自锚点高度、再向下避让、触底整体上推”，引线恢复成短横线。
- **滚轮/双指缩放被 OrbitControls 的固定 11 挡住**：改为跟随阶梯动态设置
  `controls.minDistance / maxDistance`。

#### 七、一个需要你决定的边界

地球是个有限的球。**只要坚持“整球完整可见”，镜头就只能放大到球刚好铺满视口**，
再近就必须让球边离开画面。而一个省在地球上只占几十像素，所以“聚焦到省份”目前是
**转到该省 + 放到最大**，不是地图式的“省份特写”。

如果要做真正的省份特写（球边出血、画面里只有华北），需要放开裁切限制：
把 `js/globe/globe.js` 里 `LENS` 的单座值调到 1.6—2.2，并把 `maxRadius` 的四项限制
去掉上下两项、`--globe-canvas` 提到 1600px 左右即可。这一步会与上一轮
“不要裁切地球”的要求冲突，所以我没擅自改，等你定。

#### 一、为什么先做这条

#### 三、界面与交互

左侧面板在中国视图里，收录数下方多一块「省份收录」：

- 每格一个省级单位：名称 + 条目数 + 底部一条比例线（长度 = 该省 ÷ 本视图最多的一省）。
  等宽三列（≤1180px 两列），比例因此可以横向比较，不是装饰。
- 点一格：筛到该省、把镜头落到该省重心；再点一次或点「全部」放开。
- 统计的分母是**当前地区 + 朝代的条目**，所以「唐」视图里只列出唐代有收录的省，数字也随之变小；
  选中某省后，格子里仍显示其它省的分布，方便横向换省。
- 朝代与省份可叠加。若某朝代在该省一条也没有（例如山西 + 明清），`refresh()` 自动放掉省份、回到该朝代总览，
  不会出现空白页，也不会把用户卡在空结果里。
- 省份标题只由数据推出：`本图册收录该省 17 处，年代跨唐、五代、辽、宋、金、元。`
  不写「现存最多」「全国第一」这类未经核定的断言。

返回层级随之变成四级回退：**单座 → 省份 / 朝代 → 地区 → 全球**（Esc 同样按此退）。

#### 四、与「整球不裁切」的关系

`06` 第七节留的问题：真正的省份特写必须让球边出血，与「地球放大后不裁切」冲突，当时没有擅自改。
本轮的处理是把**省份当作筛选与取景范围**，不是当作地图特写：

- 新增镜头级 `LENS.province = 1`，与单座共用最深一档（1440×900 实测球径 849—850px）。
- 落点取该省收录条目的重心（山西落在 38N/113E 一带），球仍完整可见。
- 也就是说：**省份级 = 「转到该省 + 放到当前规则允许的最大」**，仍然不是「画面里只剩华北」。

若以后确实要省份特写，仍按 `06` 第七节的办法放开裁切（`LENS.building` 调到 1.6—2.2、
去掉 `maxRadius` 的上下限制、`--globe-canvas` 提到 1600px 左右），这一步需要你确认后再做。

#### 五、同期修掉的三个缺陷

1. **「全部」按钮点了没反应。** `provinceBlock` 里把当前省份又传回 `onProvince(province)`，
   等于重新选中同一个省；再点省份格反而被当成「取消」。改为传 `null`。
   这个问题在只有省份功能的路径上会表现为「怎么点都退不回全省」，属于必修复。
2. **窄屏地名签压住缩放工具栏。** 标签列的下限原为舞台底 −64，正好落在 `+ / − / ◎` 那一排上。
   改为窄屏 −120、桌面 −56（桌面工具栏同样在右下），标签列整体止于工具栏之上。
   同时把缩放工具从透明改成纸面底盘（`--plate` + hairline + 阴影），压在球上时也读得清。

3. **地名签溢出时会被推到页头去。** 溢出处理的旧写法在循环里对每张签再减一次 `overflow`，
   同一段偏移被重复叠加，实测 390×844 时「应县木塔」被顶到 y=87（舞台从 181 才开始），
   跑到页头与朝代按钮之间。改为：
   - 先按可用高度压缩间距（`gap = min(spacing, available / (n−1))`），保证整列放得下；
   - 再只做一次整列平移：先按触底量上推，再按越顶量下压，不对单张签求值。
   
   实测同一状态下四张签落在 277 / 323 / 369 / 415，间距 46，全部在舞台内且距工具栏 60px。
   这个缺陷是上一轮留下、本轮改小标签下限后才被触发的。

#### 七、边界

- 省份数字是**本图册已收录条目的分布**，不是各省现存木构总量；31 条本身是候选样本。
- `province` 由 `place` 首段解析后人工确认，若原始地址写错，省份也会跟着错；补录时需核对。
- 省份重心是条目坐标的算术平均，只用于取景，不代表该省地理中心。
- 日本、欧洲暂不显示「县 / 郡」分组；宁波工匠赴日的线索仍未取得可靠出处，本轮未加。
