## 二、四个层级各放什么

```
docs/
├── 01-依据/        不再改动的东西：用户原稿、创意扩展稿
├── 02-内容/        「讲什么」：知识底稿、名录、信源。可反复引用，谨慎修改
├── 03-方案/        「怎么做」：现行设计稿。改版就改这里
├── 04-记录/        「改过什么」：按幕或按主题的时间线，只追加不回改
└── 09-归档/        已废止的方案与早期研究。可整包删除，不影响任何代码
```

**判断标准**：一份文档如果描述的是"现在要怎么做"，放 03；如果只是"当时怎么想过"，放 09。

## 四、怎么加一份新文档

1. 先判断层级：依据 / 内容 / 方案 / 记录。
2. 用两位数前缀排顺序：`docs/03-方案/05-第一幕-改版X.md`。
3. 文件名写清"哪一幕 + 讲什么"，不要用「最终版」「新版」。
4. 在这份索引的表格里加一行——不加行，下一个人就找不到。
5. 有旧版本要留，移到 `09-归档/`，并在开头写一句「已被 XX 取代」。
