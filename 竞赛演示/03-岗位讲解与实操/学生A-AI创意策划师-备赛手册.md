## 三、三个技能点（只演示这三个）

### 技能点 1 · 内容结构化

| 项 | 内容 |
|---|---|
| 一句话 | 把史料拆成“卷—跨页—句”三级，让别人拿到表就能做 |
| 现场动作 | 切 Excel，指三列：卷、跨页、要点；翻两屏给评委看粒度 |
| 演示时长 | 60 秒 |
| 判断标准 | 一页只说一件事；每页有图有文；正文 130—170 字 |
| 易错 | 一页塞三个概念；正文写成论文摘要 |
| 出问题时 | 表格没打开 → 直接口述三级结构，不找文件 |

**说这三句就够**：

> 第一级是卷，六卷对应六个知识台阶；第二级是跨页，一跨页一个概念，左页图右页文；第三级是句，每页一百三十到一百七十字，考据放双行夹注。

### 技能点 2 · 提示工程

| 项 | 内容 |
|---|---|
| 一句话 | 用四段式提示词，让输出结构稳定、事实可控 |
| 现场动作 | 切 Word，指四段：角色、约束、样例、反例；再翻一页输出对比 |
| 演示时长 | 60 秒 |
| 判断标准 | 四段齐全；同一提示词多次输出结构一致 |
| 易错 | 只说“帮我写一段斗拱介绍”；不设字数和禁用词 |
| 出问题时 | 文档打不开 → 口述四段结构，念一条反例 |

**说这三句就够**：

> 角色决定语气，约束决定能不能用，样例给它一个正确的句子，反例专门写一句空话告诉它别这么写。四段缺一段，输出就不能用。

### 技能点 3 · 需求转译与验收

| 项 | 内容 |
|---|---|
| 一句话 | 把策划写成建模清单和页面清单，并定义“什么样算做完” |
| 现场动作 | 切 Excel 第二张表，指两类：建筑 12 座、铺作 1 朵；指“面数上限”一列 |
| 演示时长 | 55 秒 |
| 判断标准 | 每条需求有输入、有输出、有验收标准 |
| 易错 | 口头说“做个地球”，做出来才发现不是想要的 |
| 出问题时 | 第二张表没找到 → 口述两类清单与面数上限 |

**说这三句就够**：

> 清单上写了面数上限和导出格式，不然他做出来我接不进去。交付不合规就打回，不靠人情靠标准。

一句话说清我们在做什么：**我们把中国古建筑里最难讲清楚的斗拱，做成了一套能转、能拼、能翻的网页。**

**【01:15｜P03｜手示意屏幕】**

### 项目设计（02:00—12:00）

**【02:00｜P04】**

先说为什么做这件事。

有三份文件是我们立项的依据。《关于推进国家文化数字化战略的意见》要求文化资源数字化；《十四五非物质文化遗产保护规划》讲传统技艺要活态传承；职业教育这边，讲人工智能技术进课堂。

这三件事叠在一起，指向同一个问题：**像斗拱这样的传统技艺，怎么让年轻人愿意看、看得懂、还记得住？**

我们给的答案是：不要再做图文长页了，做成能操作的。

**【03:00｜P05｜激光笔指斗拱位置】**

斗拱不是一个构件，是一组构件。

它从柱头上长出来，一层一层往外挑，把屋檐的重量接住，再传回柱子。整组东西不用一颗钉子，靠的全是榫卯。

它有三个身份。技术上是承重体系；制度上是等级标志；审美上它决定了中国建筑最有辨识度的轮廓——深远出檐。

而且它是会变的。唐代疏朗，出挑两米；宋代精密，一朵铺作能拆出二十种构件；清代繁复，但已经不承重了，变成装饰。

**同一个构件，三个朝代三个答案。这就是我们要讲的故事。**

**【04:10｜P06】**

那故事怎么讲？我们决定先去现场。

第一站是宁波保国寺大殿。去现场看和看图片完全是两回事。站在柱子底下抬头，你才知道斗拱有多大——不是书上那个抽象的图，是比人还高的一堆木头叠在一起。

我们拍了柱头铺作、藻井、瓜棱柱，回来对着修缮报告和测绘图纸一张一张比。

除了现场，还查文献、看竞品、跟同学聊。看竞品时发现一个问题：**现有的斗拱科普，绝大多数是图文长页或者短视频。看完就完了，你没法动手。**

**【05:10｜P07】**

这个发现，就是我们所有设计的起点。我们把问题归成四条。

第一条，看得到摸不着——所以要能转、能拆。
第二条，知识点散没有脉络——所以要做一条线，从一块木头讲到一座殿。
第三条，只能读不能试——所以要做一个能拼的游戏。
第四条，展陈只能到现场——所以要做成网页，一个链接、一个 U 盘就能带走。

**这四条，一条对应一幕。**

**【06:10｜P08】**

四幕，四个动词。

**第一幕《木构之间》，是一本书。** 六卷：接、用、起、变、名、归。左页图，右页竖排文字，可以翻。

**第二幕《木构星图》，是一张图。** 一颗地球，标了全球三十九处木构。点国家、点朝代、点建筑名，一路下钻，最后能点开三维模型自己转。

**第三幕《小小营造师》，是一局拼装。** 一百二十秒，把保国寺一朵柱头铺作拼回去，五十七个构件，十八组。

**第四幕《斗拱问答》，是一道关。** 这一幕现在还是原型，**我们只做完了框架和数据结构，题库还没建**。等下专门讲，这里先说清楚，不夸大。

前三幕是能用的，第四幕在做。这是我们今天真实的进度。

**【07:45｜P09】**

技术上分三层。

最下面是数据：三十九条建筑记录，一个 JSON；十三个 Blender 源文件，导成十二个 GLB，一共二十三兆。

中间是渲染：Three.js，就是 WebGL；模型用 glTF 加 Draco 压缩。

最上面是交互：原生 JavaScript，没有框架，没有 CDN，所有资源都在本地。

为什么不用框架？因为要离线。**框架和 CDN 一断网就全废。**

**【08:30｜P10｜指七步进度条】**

七个环节，四个人接力。

我做选题和内容框架；B 做建模和资产管线；C 做网页和四级交互；D 做装配游戏和联调部署。

**这条进度条后面每页右上角都在，现在亮的是第一步，讲到哪亮到哪。**

**【09:05｜P11｜切 Excel 第二张表】**

分工不是拍脑袋定的，是一条需求链。

我定完内容框架，给 C 和 D 分两幕，同时给 B 一份建模清单。清单分两类：木构建筑十二座，斗拱铺作只要保国寺柱头这一朵。

**【09:25｜指面数一列】**

**清单上写了面数上限和导出格式，不然他做出来我接不进去。**

C 和 D 按清单做，缺件就回头找 B。每周对一次表，交付不合规就打回。

**【09:50｜P12｜切 Excel 第一张表】**

具体到内容是怎么拆的。三级。

第一级是卷，六卷六个台阶；第二级是跨页，一跨页一个概念，左页图右页文；第三级是句，每页一百三十到一百七十字，考据放到双行夹注。

**【10:20｜翻两屏】**

这样写页面的人拿到表就能直接做，不用再来问“这一页讲什么”。

**【10:40｜P13｜切 Word】**

最后一个技能点是提示工程。

现场离线，我不能调模型，所以给大家看留痕。这条提示词分四段：角色、约束、样例、反例。

角色是“给高中生写展陈说明的文博编辑”；约束是字数、禁用词、术语要解释、不确定的史实不许编；样例给一个正确的句子；反例专门写一句空话，告诉它不要这么写。

**四段缺一段，输出就不能用。** 只给角色，它写得像作文；不给反例，它会写“体现了劳动人民的智慧”。

**【11:25｜指对比页】**

这是同一段内容，改提示词前后的对比。右边这版我把年份改回了“据《保国寺修缮报告》记载”，因为原来的年份是它编的。

**【11:50｜交接】**

B，从建模开始。

三十九条建筑数据，十二座可三维，全部离线可用。十三个源文件六百一十八兆，压到十二个 GLB 二十三兆。装配游戏六条单元测试全过。四个断点都没有横向溢出。

**【46:35】**

这些数都能现场复现，不是我们写的报告。

**【46:40｜P31】**

第二，三个不一样。

一是把榫卯拆成可操作的层级——不是看图，是从节点到铺作一层层拼。

**【47:15｜P32】**

第三，能放的地方。线上一个链接，扫码就能看；线下是景区互动屏、学校课堂、非遗展陈。下一步想跟保国寺合作做定点展项。

我原来会写方案，现在能把方案拆成别人能执行的清单。
