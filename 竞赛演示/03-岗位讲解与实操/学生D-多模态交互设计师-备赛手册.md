## 三、三个技能点（只演示这三个）

### 技能点 1 · 装配玩法与容错

| 项 | 内容 |
|---|---|
| 一句话 | 57 个构件、18 组、120 秒，顺序错了放不进去 |
| 现场动作 | 现场玩一局，边拼边讲规则，控制在 90 秒内 |
| 演示时长 | 130 秒 |
| 判断标准 | 放错顺序拒绝；重复归位忽略；切后台不延长倒计时 |
| 易错 | 顺序校验写成“任意顺序都能放”；计时用累加，切后台就错 |
| 出问题时 | 拼不完 → 直接讲“时间到会结算”，点重开讲一遍规则 |

**玩法三条**：120 秒；按提示顺序拼；放错放不进去。

**分组逻辑**：柱头预置，其余 56 件分 18 组，同层重复的承斗组合算一组，组内顺序随意。

**为什么开始后只显示当前落点**：整模一直亮会泛白，看不清哪一层该放。

### 技能点 2 · 状态机与单元测试

| 项 | 内容 |
|---|---|
| 一句话 | 玩法就是状态转移，状态错了玩家就卡住，所以要写测试 |
| 现场动作 | 终端跑 `node --test`，让评委看六行绿勾 |
| 演示时长 | 120 秒 |
| 判断标准 | 6 条用例覆盖：超时边界、顺序、重复归位、18 组完成、重开清零、后台延迟 |
| 易错 | 只测正常流程，边界全靠手点 |
| 出问题时 | 终端报错 → 口述六条用例，说明“上次是全过的” |

**这是你手上最硬的一张牌。**高职组里很少有学生给游戏写单元测试。把终端输出投出来，六个绿勾比说十句都管用。

**六条用例**：

1. 119 秒还能放，121 秒不能
2. 放错顺序被拒绝
3. 重复放同一件不重复计数
4. 18 组全拼完触发结算
5. 重开全部清零
6. 切到后台再回来，时间正确

### 技能点 3 · 联调与离线部署

| 项 | 内容 |
|---|---|
| 一句话 | 四幕要能在没网的一台电脑上跑起来 |
| 现场动作 | ① 双击离线包 HTML ② 等地球出来 ③ 点一座建筑看模型 ④ 指目录树讲“必须整包拷” |
| 演示时长 | 120 秒 |
| 判断标准 | 双击即可运行；无网络也能翻页、转球、开模型、玩游戏 |
| 易错 | 只拷 HTML 没带 assets；`file://` 下模块被拦 |
| 出问题时 | 双击没反应 → 拖进 Chrome，讲“默认浏览器被旧内核接管了” |

**为什么必须离线**：赛场网络不可控；而且 `file://` 会拦模块加载与本地读取，直接双击原版就是白屏。

**打包做了什么**：三维引擎、地理轮廓、39 条数据、应用代码全部内联进一个 HTML；两处 `fetch` 改静态引入；esbuild 合成单文件。

**最容易翻车的一点**：图片和模型必须与 HTML 同层。只拷一个 HTML，页面能开但所有照片是空的。
