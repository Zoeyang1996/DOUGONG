# 小拱 · IP 设定卡

**定位**：保国寺斗拱科普系统的导览角色。观众在屏幕上遇到的那个会说话的，就是它。
本图用于两处：一、A 的方案展示与界面头像；二、B 的 Tripo 图生三维输入。

---

## 一、结构对应

角色身上每一处都不是装饰，都能在真实宋构里找到对应。

| 角色部位 | 对应构件 | 用意 |
|---|---|---|
| 头 | 栌斗 | 斗拱最底下那块承托件，一切从这里开始，所以做成脑袋 |
| 头顶凹槽 + 卷草小芽 | 斗口 + 拱头 | 斗口是开槽承拱的地方，芽是"长出来"的拱，也是它名字的由来 |
| 额上一圈红线 | 七朱八白彩画 | 保国寺大殿存宋代彩画遗制，红线是唯一一处"红" |
| 肩部方木 | 交互斗 | 承上启下的节点，做成肩，暗示"扛得住" |
| 手臂 + 斜出的袖尖 | 拱 + 昂 | 拱横向挑出，昂斜向下伸，宋构挑檐的两种基本姿态 |
| 手 | 榫头 | 方形凸榫，可插入任何斗口 |
| 身体三层 | 三层铺作 | 层层出跳、逐层加宽，做成甲片状 |
| 腰间小榫 | 燕尾榫 | 上下两段的连接点，故意露出来 |
| 脚 | 斗 | 与头呼应，首尾同形 |

一句话记法：**头是斗，臂是拱，袖是昂，身是铺作，脚还是斗。**

## 二、配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 主木色 | #A9713C | 老松木，明度中等，小尺寸不发黑 |
| 深木 | #7B4B2A | 阴影面与结构转折 |
| 朱红 | #B4472F | 只用三处：额带、腮红、腰榫，多了就俗 |
| 纸底 | #F2E6CC | 与第一幕古籍纸同色，跨幕统一 |
| 墨线 | #2A2118 | 单线勾边，不用双线 |

## 三、三处不能改的识别特征

后续做表情、做动画、做三维，这三处一改就"不是它了"：

1. **栌斗头的形**：上宽、直壁、底部内收（耳、平、欹三段）
2. **额上那道朱红带**：位置固定在上沿往下一指宽
3. **斜出的昂嘴袖**：侧视必须能看见向前下方伸出的尖

## 四、给三维环节的用法

- 三视图 1536×1024，三视角等高、同基线、米色纸底、无阴影、无文字，可直接作 Tripo 输入
- 建议以**正视图**为主图喂入，侧视图作补充；背面细节少，可省略
- 生成后重点修三处：斗口凹槽（易糊平）、昂嘴尖（易钝）、腰榫（易丢）
- 导出两套：GLB 供网页与触屏，FBX 供 Unity / VR

## 五、还缺什么

- 表情包 6 个（默认、思考、惊讶、开心、抱歉、指路）
- 三个动作（招手、托举斗拱、摇头）
- 语音人格：说话短句优先，先给答案再补一句古法，遇到不知道的就答"我去查图录"
