# 榫卯智言 · 高职组人工智能赛道演示筹备

本目录用于准备学生技能大赛的 PPT / Slides、岗位讲解和现场实操。展示重点是学生完成项目任务的流程、操作方法、技能及验证结果。网页、模型和调研材料作为展示依据，按需引用已有工程。

目前阶段：需求与结构筹备。用户稍后提供 PPT 参考，再确定页序、页数与视觉样式。

## 从哪里开始

1. 阅读 [竞赛演示定位](02-内容策划/01-竞赛演示定位.md)，明确已知条件。
2. 参考 [四岗与50分钟安排草案](02-内容策划/02-四岗与50分钟安排草案.md)，待人员与赛规明确后修改。
3. 每位同学按 [岗位实操脚本模板](03-岗位讲解与实操/岗位实操脚本模板.md) 准备操作与讲解。

| 目录 | 放什么 |
|---|---|
| 01-参考与赛规 | 后续提供的参考 PPT、比赛通知、赛规、评分表；保留原文件 |
| 02-内容策划 | 项目定位、名称、技能主线、分工、时间与页面提纲 |
| 03-岗位讲解与实操 | 每位学生的讲稿、操作步骤、交接语及异常处理 |
| 04-展示素材 | 选定的截图、录屏、流程图、操作前后对照；避免复制整个模型库 |
| 05-演示文稿 | 可编辑 PPTX、Slides 链接说明及最终演示 PDF |
| 06-排练记录 | 分段用时、问题、修订与设备检查结果 |

文件命名建议：`岗位01-数据准备-讲解与操作.md`、`2026-11-15-排练记录.md`。文稿确定后优先维护一份当前可编辑版本；旧版本按日期集中归档。
