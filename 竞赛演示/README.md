每份都含：时间与页面对照 → 软件工具清单（含提前开什么）→ 3 个技能点（现场动作/判断标准/易错）→ 完整台词 → 上台检查 → 必背数字 → 追问应答。

**为什么从 6 个砍到 3 个**：50 分钟里每人只有 11—16 分钟，还要留操作时间。技能点太多必然变成"念清单"，评委看不到操作。取舍标准是三条：**能在 30 秒内做出可见结果、结果能被评委一眼判断对错、出了问题有一句话的解释**。被砍掉的（信源分级、AI 校核、性能取舍、程序化材质、热区适配等）没有消失，而是并进了保留项的口述里，或降到附录的"必背数字/红线"。
