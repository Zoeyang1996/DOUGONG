浙江省宁波市职业技能大赛（高职组）· 人工智能赛道。

## 一、项目现在的四幕

| 幕 | 内容 | 形态 |
|---|---|---|
| 第一幕 | 斗拱历史科普 | 可翻页的中式古籍网页（41 页 / 五卷） |
| 第二幕 | 现存木构建筑可视化科普 | 三维地球，39 处建筑，四级下钻，12 座可看三维 |

## 五、C 与 D 的核心设计（一页看懂）

**C：三个环节，一条工序**

| 环节 | 技能点 | 现场产出 |
|---|---|---|
| 一页书是怎么排出来的 | 数据驱动排版 · 竖排版心 · CSS 3D 折页 | 改一条数据，书页标题变长、版式自动重排 |
| 从 GLB 到能转的三维 | 资产接入 · 四级镜头按比例换算 | 详情页多出「三维 ↗」，点开可转 |
| 交付验收 | 自检脚本 · 全流程串演 | 一屏绿色「全部通过」+ 完整 demo |

配套工具：`web-exhibits/tools/selfcheck.mjs`（39 条数据 / 78 张照片 / 12 个模型，一条命令出报告）。

**D：两局，一套动作**

| | 网页《小小营造师》 | MR《桌上的一朵》 |
|---|---|---|
| 学会什么 | 顺序、层次、名字 | 体量、位置、手感 |
| 怎么玩 | 拖放或先选件再点落点，错序拒绝 | 捏合抓起，放进轮廓自动吸附 |
| 谁负责 | D + C | 技术：另一位老师；体验：D |

演示形态推荐 **B 半现场**：先播 60 秒第一视角录屏，再戴机做 30 秒实操作。
