# 小小营造师 · 120 秒挑战

从 DOUGONG 根目录运行 `python3 -m http.server 8023 --bind 127.0.0.1`，打开 `http://127.0.0.1:8023/web-exhibits/act-03-assembly/`。

## 模型与玩法

采用用户当前编辑的 `models/baoguosi_zhutou_v01/保国寺主铺作_v01_形制草模.blend`，57 个构件全部保留。柱头预置，其余 56 件分为 18 组，同层重复承斗组合放置。120 秒内按提示拼装；支持拖放以及先选件、再点落点；鼠标拖动空白处旋转、滚轮缩放，触屏使用单指旋转与双指缩放。后台停留不会延长倒计时。

修正版另存至 `models/baoguosi_zhutou_v02_game/保国寺柱头铺作_v02_游戏搭接修正版.blend`，原文件不覆盖。修正采用承口避让与互补搭接，检测由 59 处实体交叠降至 0（体积阈值 1e-8 m³）；57 个构件均为单连通闭合网格。结果与切口记录见同目录 `repair-report.json`。这是草模的游戏几何修正，不是历史榫卯测绘复原或加工图。

## 写实材质调整

Three.js 中新增程序化纵向木纹与端面年轮，按每根构件方向生成物理尺度 UV；使用颜色、微凹凸及粗糙度贴图，木件之间保持细微色差。增强主光方向与接触阴影，降低环境填充光，增加厚展台及落地阴影。纹理在本机生成，无外部图片或 CDN 依赖。

开始前展示完整实木模型；开始后仅显示当前步骤的线框落点，避免整座半透明实体叠加产生泛白。构件采用加速下落、停止于承口的短动画。效果图和右侧缩略图从相同材质生成。

网页沿用已读取的 taste skill 的对齐、统一尺度、简洁文案与真实资产主导原则；遵循用户指定的单屏游戏布局，不套用商业宣传网站的多段页面。上游配套自动设计检查未执行；远程文档可读取，但工具包下载失败。
