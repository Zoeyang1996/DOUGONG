# 从样稿到正式制作

本轮的“一木相接 / 木构星图 / 小小营造师”是界面工作标题，四幕内容与机制严格对应用户原稿。

## 先推进第一幕

1. 将六段内容逐项对应到本地研究资料，建立“说明文字—图片—模型部件—出处”的对应表。没有可靠依据的年代及器物不进入正式展项。
2. 从已经建立的榫卯原理模型开始，完善倒角、木纹、开合动作和相机路线；先形成可完整体验的一段。
3. 为工具/建筑使用、早期斗拱、历代对照分别选择具体参考对象，再进入Blender建模。不同朝代使用不同经核定的实例。
4. 对现有保国寺铺作、瓜棱柱、大殿草模复核，导出轻量化模型供末段使用。
5. 完成六段滚动、构件解释、触控阅读及短暂停留体验的现场版本。

## 第二幕

1. 确定统计单位（建筑单体/建筑群）、现存木构判定、年代口径。
2. 优先补充中国建筑，逐项核定现存年代、坐标、省份和图像来源；再扩充日本与欧洲。
3. 宁波工匠赴日线索单列资料核验，取得直接证据后才加入关联展示。
4. 完善筛选及统计，增加条目照片。用户提供Tripo模型后按条目接入旋转观察。

## 第三幕

1. 从已有资料选定简单、中等、困难的三个实际铺作，仍使用60/30/20秒。
2. Blender制作独立构件、真实槽口、正确拼装姿态；分别保留源文件和网页模型。
3. 将正确装配顺序和依赖写入关卡数据，替换当前6/8/10件占位组；件数由选定铺作决定。
4. 触屏实测调整吸附范围和零件大小，避免触控遮挡目标。
5. 接入现场统一身份/限次方案，再验收“一天两次”；当前浏览器记录仅供演示。

## 第四幕

只保留目录与空题库。等待用户补充具体内容后再制作框架细节和视觉demo。
