本轮补的是用户原稿里一直没落地的一条：**「不同省份的木构建筑数量」**。

## 一、为什么先做这条

原稿对第二幕的要求是四项：大地球可拖拽缩放、聚焦国家（以中国为主）、点朝代让对应建筑亮起、**不同省份的木构数量**、点建筑看介绍。
前四项在上一轮已完成，省份这条只有「收录数」一个总数，没有按省拆分。这一版补上，并且顺手解决了 `06-镜头与四级交互.md` 第七节挂着的边界问题（见第四节）。

## 三、界面与交互

左侧面板在中国视图里，收录数下方多一块「省份收录」：

- 每格一个省级单位：名称 + 条目数 + 底部一条比例线（长度 = 该省 ÷ 本视图最多的一省）。
  等宽三列（≤1180px 两列），比例因此可以横向比较，不是装饰。
- 点一格：筛到该省、把镜头落到该省重心；再点一次或点「全部」放开。
- 统计的分母是**当前地区 + 朝代的条目**，所以「唐」视图里只列出唐代有收录的省，数字也随之变小；
  选中某省后，格子里仍显示其它省的分布，方便横向换省。
- 朝代与省份可叠加。若某朝代在该省一条也没有（例如山西 + 明清），`refresh()` 自动放掉省份、回到该朝代总览，
  不会出现空白页，也不会把用户卡在空结果里。
- 省份标题只由数据推出：`本图册收录该省 17 处，年代跨唐、五代、辽、宋、金、元。`
  不写「现存最多」「全国第一」这类未经核定的断言。

返回层级随之变成四级回退：**单座 → 省份 / 朝代 → 地区 → 全球**（Esc 同样按此退）。

## 四、与「整球不裁切」的关系

`06` 第七节留的问题：真正的省份特写必须让球边出血，与「地球放大后不裁切」冲突，当时没有擅自改。
本轮的处理是把**省份当作筛选与取景范围**，不是当作地图特写：

- 新增镜头级 `LENS.province = 1`，与单座共用最深一档（1440×900 实测球径 849—850px）。
- 落点取该省收录条目的重心（山西落在 38N/113E 一带），球仍完整可见。
- 也就是说：**省份级 = 「转到该省 + 放到当前规则允许的最大」**，仍然不是「画面里只剩华北」。

若以后确实要省份特写，仍按 `06` 第七节的办法放开裁切（`LENS.building` 调到 1.6—2.2、
去掉 `maxRadius` 的上下限制、`--globe-canvas` 提到 1600px 左右），这一步需要你确认后再做。

## 五、同期修掉的三个缺陷

1. **「全部」按钮点了没反应。** `provinceBlock` 里把当前省份又传回 `onProvince(province)`，
   等于重新选中同一个省；再点省份格反而被当成「取消」。改为传 `null`。
   这个问题在只有省份功能的路径上会表现为「怎么点都退不回全省」，属于必修复。
2. **窄屏地名签压住缩放工具栏。** 标签列的下限原为舞台底 −64，正好落在 `+ / − / ◎` 那一排上。
   改为窄屏 −120、桌面 −56（桌面工具栏同样在右下），标签列整体止于工具栏之上。
   同时把缩放工具从透明改成纸面底盘（`--plate` + hairline + 阴影），压在球上时也读得清。

3. **地名签溢出时会被推到页头去。** 溢出处理的旧写法在循环里对每张签再减一次 `overflow`，
   同一段偏移被重复叠加，实测 390×844 时「应县木塔」被顶到 y=87（舞台从 181 才开始），
   跑到页头与朝代按钮之间。改为：
   - 先按可用高度压缩间距（`gap = min(spacing, available / (n−1))`），保证整列放得下；
   - 再只做一次整列平移：先按触底量上推，再按越顶量下压，不对单张签求值。
   
   实测同一状态下四张签落在 277 / 323 / 369 / 415，间距 46，全部在舞台内且距工具栏 60px。
   这个缺陷是上一轮留下、本轮改小标签下限后才被触发的。

## 七、边界

- 省份数字是**本图册已收录条目的分布**，不是各省现存木构总量；31 条本身是候选样本。
- `province` 由 `place` 首段解析后人工确认，若原始地址写错，省份也会跟着错；补录时需核对。
- 省份重心是条目坐标的算术平均，只用于取景，不代表该省地理中心。
- 日本、欧洲暂不显示「县 / 郡」分组；宁波工匠赴日的线索仍未取得可靠出处，本轮未加。
