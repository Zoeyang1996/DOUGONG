> 编制：2026-11-11｜用途：`shared/data/buildings.json` 扩条目、地图取点、朝代筛选与统计
> 原则：**先定口径，再列名单。** 口径不统一，"现存多少座"就是一个无法回答的问题。

## 一、必须先定的四条收录标准

现有 `buildings.json` 只有 7 条，且全部标"候选样本；待校核"。要扩到能筛选、能统计，必须先回答四个问题，否则数据一定是错的。

### 1.1 什么算"木构建筑"

| 口径 | 包含 | 排除 | 建议 |
|---|---|---|---|
| **A 主体木构**（严） | 承重结构以木材为主，梁柱体系完整 | 砖木混合、土木结构、木塔但内部砖砌 | 建议主数据集用这一档 |
| **B 含木构**（宽） | 木构殿阁、木塔、木廊桥、木阙、石窟木窟檐 | — | 建议单独字段标记，不混入主统计 |
| **C 木构构件** | 仅存斗拱、门窗、藻井 | — | 只作图文素材，不入地图点位 |

**边界案例**：正定开元寺钟楼（下层唐构、上层清代改仿唐）、敦煌莫高窟 196 窟窟檐（唐代木构但依附石窟）、应县木塔（纯木但内部有塑像与砖基）——这三类必须单独定规则，否则每次争论都重来。

### 1.2 年代怎么算

**用"现存主体结构的始建或重建年代"，不用"创建年代"。** 这是本项目最容易出错的地方：

- 法隆寺**创建于 607 年**，但现存金堂、五重塔是**670 年火灾之后重建的 7 世纪末—8 世纪初**。写成"607"会被专业人士一眼看穿。
- 保国寺大殿主体 1013 年，但**清代加了四周下檐**，现状重檐不等于宋构原貌。
- 太和殿现存为**康熙三十四年（1695）重建**，明万历原构已毁。

**建议字段拆成两个**：`year_built`（现存主体年代）+ `year_founded`（创建年代），地图筛选只用前者。

### 1.3 建筑单体还是建筑群

独乐寺的**山门**和**观音阁**是两座独立辽构，在"八大辽构"里各占一席；但游客认知里是"独乐寺"。**建议按建筑单体计数**，用 `complex` 字段归组，筛选时可选"合并显示"。

### 1.4 统计口径必须写清

山西文物局的官方数字是：**全国元以前木构 580 座，山西 495 座（85%）**，其中唐 3、五代 5、宋辽金 183、元 389。但另一处（2020 年数据）说全国 **628 座**、山西 518 座。

**差异来自国保批次与普查时点。** 所以网页上一旦出现数字，必须写：`据 XX 年 XX 口径，全国元以前木构约 XXX 座，本页收录 XX 条`。绝不能只写一个数字。

## 五、给 `buildings.json` 的字段建议

现有 8 个字段不够用。建议扩成：

```json
{
  "id": "nanchan",
  "name": "南禅寺大殿",
  "country": "中国",
  "province": "山西",
  "city": "忻州·五台县",
  "dynasty": "唐",
  "period": "唐",
  "year_built": 782,
  "year_founded": null,
  "year_basis": "重建于建中三年，殿内题记",
  "complex": "南禅寺",
  "type": "殿",
  "structure": "抬梁式",
  "bracket": "五铺作双杪偷心造",
  "lat": 38.737,
  "lon": 113.109,
  "coord_precision": "近似（乡镇级）",
  "heritage": "第一批全国重点文物保护单位",
  "text": "中国现存最古老的木构建筑……",
  "source": "山西省文物局；《中国文物地图集》",
  "url": null,
  "image": null,
  "modelUrl": null,
  "status": "已核 / 待核 / 有争议",
  "note": ""
}
```

**几个关键点：**

1. `year_built` 与 `year_founded` 必须分开——法隆寺、太和殿、保国寺都会被这张表救。
2. `coord_precision` 标精度：`精确` / `近似（乡镇级）` / `展示用近似值`。**现在 7 条全是"展示用近似值"，地图上要用不同的点样式区分**，否则会被当成精确坐标。
3. `status` 三档：`已核`（有官方来源）、`待核`（有来源但未复核）、`有争议`（如天台庵）。**有争议的条目在界面上要有明显标记**，这反而是专业度的体现。
4. `complex` 用于把独乐寺山门与观音阁归组、把佛光寺东大殿与文殊殿归组。

## 六、地图上的三个叙事机会

收了数据，别只做点位。这三层是数据本身能讲出来的故事：

### 6.1 "早期木构为什么会挤在山西"

元代以前木构 85% 在山西。原因可讲三层：气候干燥少雨、地处内陆战乱相对少、木构寺庙群密集且长期沿用。**这是全篇最有说服力的一屏**——地图上点开"唐宋"筛选，中国版图上只有山西亮着。

### 6.2 "南方只有三座"

南方早期木构极少，公认的重要三座是：**福州华林寺大殿（964）、宁波保国寺大殿（1013）、广东肇庆梅庵**。
**保国寺能位列其中，是它真正的价值所在**——这比"江南最古老"更有信息量。

### 6.3 "同一年代的南北差异"

把**佛光寺东大殿（唐 857，山西）**与**华林寺（964）／保国寺（1013，浙江）**并置：北方斗拱更高更疏，南方更紧凑、更适应多雨。这条对比线正好接上第一幕 G4/G5。

| 3 | 正定开元寺钟楼、敦煌 196 窟窟檐是否入表 | 影响唐代实例计数 |
| 4 | 所有坐标精度 | 现 7 条均为展示用近似值 |
| 5 | 每条建筑的**条目图授权** | 无图的点位体验很差，但抓图不能用 |
| 6 | 日本条目是否纳入"朝代"筛选 | 建议单列"飞鸟/奈良/平安"，不与唐宋混排 |
| 7 | 明清是否入表 | 建议入表但默认关闭 |
