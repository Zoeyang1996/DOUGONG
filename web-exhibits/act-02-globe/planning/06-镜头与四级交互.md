## 二、二级视角拉近

**根因不是常数太小，而是上限算错了。** 原来“不裁切”的上限用的是
`min(舞台高 × 0.97, 舞台宽)`——在窄窗口（浏览器预览面板、平板）里**宽度变成瓶颈**，
球被压到和舞台同宽，于是二级看起来很远；而且所有级别的固定距离（5.7 / 5.3 / 5.2）
都被这个上限夹到同一个值，三级和四级就完全没差别。

改成按“屏幕上可用半径”定上限：

```js
roomAbove  = 球心以上到视口顶 - 12
roomBelow  = 球心以下到视口底 - 12
roomRight  = 舞台宽/2 + 左溢出/2 - 16   // 右侧不压导航
roomCanvas = 画布高/2 - 6
maxRadius  = min(四个中的最小)
```

球可以向左潜到说明栏下方、向上向下略越过舞台（页头页脚的两条细线已去掉，
球越过时不会被一条线切断），但整个球始终在视口与画布之内，仍然不裁切。

`--globe-canvas` 同步从 `min(88svh, 940px)` 提到 `min(100svh, 1040px)`，给球留出足够画布。

## 三、四级镜头阶梯

镜头不再传固定距离，而是传“级别”，由级别换算成球半径比例：

| 级别 | 触发 | 半径比例 | 1440×900 实测球径 |
|---|---|---|---|
| 全球 | 初始 / 复位 | 0.60 | 510 px |
| 地区 | 点中国 / 日本 / 欧洲 | 0.86 | 731 px |
| 朝代 | 点唐 / 宋 / 辽… | 0.94 | 799 px |
| 单座 | 点某座建筑 | 1.00 | 850 px |

- 换算：`d = R·H / (2·r·tan(fov/2))`，`r` 为球在屏幕上的目标半径。
- `focus(lat, lon, level)` 会把镜头转到该点并落到该级距离；`zoom()`、双指缩放
  与 `controls.minDistance/maxDistance` 共用同一组上下限，不会越界也不会被夹死。
- 朝代级的落点取**该朝代所有条目的重心**：点“唐”落在山西（38.7N, 113.3E），
  点“明清”落在北京；点单座则直接对准该建筑坐标。
- 返回（`←`）也按层级退回：单座 → 朝代视角，朝代 → 地区视角，地区 → 全球。

## 四、点击寺庙，左侧出现介绍

这条原来就有，但这次补齐了两点，让它“真的可用”：

1. `pick()` 现在调用 `focus(item.lat, item.lon, 'building')`，点击后镜头一定落到单座级，
   不再被上限夹成和三级一样。
2. `panel.js` 每次换页给 `#panel-content` 加一次 280ms 的 `panel-in` 淡入上移，
   读起来像“左侧弹出”，而不是无声替换。

面板内容仍是原有的 `renderDetail`：返回条 → 照片 → 名称 → 年代 → 地点 →
待核提示 → 正文 → 引语 → 形制/构造/坐标。地名签与名录行都走同一个 `pick()`。

## 五、顺带修的两个小问题

- **地名签全部挤在顶部**：原来固定从舞台顶往下排，球放大后引线拉成很长的斜线。
  改为“先贴住各自锚点高度、再向下避让、触底整体上推”，引线恢复成短横线。
- **滚轮/双指缩放被 OrbitControls 的固定 11 挡住**：改为跟随阶梯动态设置
  `controls.minDistance / maxDistance`。

## 七、一个需要你决定的边界

地球是个有限的球。**只要坚持“整球完整可见”，镜头就只能放大到球刚好铺满视口**，
再近就必须让球边离开画面。而一个省在地球上只占几十像素，所以“聚焦到省份”目前是
**转到该省 + 放到最大**，不是地图式的“省份特写”。

如果要做真正的省份特写（球边出血、画面里只有华北），需要放开裁切限制：
把 `js/globe/globe.js` 里 `LENS` 的单座值调到 1.6—2.2，并把 `maxRadius` 的四项限制
去掉上下两项、`--globe-canvas` 提到 1600px 左右即可。这一步会与上一轮
“不要裁切地球”的要求冲突，所以我没擅自改，等你定。

## 八、标注点击热区（19:40 补）

原本只有红点能点（画布上的 30px 拾取），地名签是"看得见、点不动"——
`#map-labels` 设了 `pointer-events: none`，子按钮没有单独开放，所以点名字没有任何反应。

| 文件 | 改动 |
|---|---|
| `css/globe.css` | `.map-label` 加 `pointer-events: auto`、`cursor: pointer`、`touch-action`；热区从 `min-height: 30px / padding 2px 4px` 改为 **44px 高、左右 10px**；底部划线相应移到 `bottom: 8px`；窄屏覆盖也从 30 改成 44 |
| `js/labels.js` | 标注间距 34 → **50**（窄屏 30 → 46），保证 44px 热区不互相压住 |
| `js/globe/globe.js` | 红点拾取容差 26px → **30px**，手指稍微偏一点也能中 |

两种点法都走同一个 `pick(item)`，跳转逻辑、面板内容、数据结构均未改动。

**顺带修的两个连带问题**（都是球放大后才暴露的）：

1. **引线一直没画出来。** `#leaders` 是内联 `<svg>`，有 300×150 的固有尺寸，
   只写 `left/right` 不会把它撑开，SVG 视口只有 300px 宽，引线全被裁在视口外。
   补 `#leaders { width: calc(100% + var(--bleed)) }` 后引线正常。
2. **纸面蒙版的右缘是一条硬边。** 球放大后能明显看出"一块矩形盖在球上"。
   渐变从 64px 的短过渡改为 150px 的长渐隐（58% 不透明 → 100% 透明），并去掉那条竖细线。
