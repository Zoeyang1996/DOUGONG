# 第二幕界面改版说明（2026-11-12）

改版依据：`taste-skill 2.5`（`design-taste-frontend`）的房子规则——一屏一节、等边距、
统一字号与间距刻度、图下不放说明文字、悬浮有回响、动作名为动词。改版只动第二幕自身文件，
未触碰 `shared/`、`act-01/03/04`。

改版后截图见 `planning/screens/`。

## 一、四条要求的落点

### 1. 移除画面正上方的所有文字

| 文件 | 改动 |

### 2. 减少零散小字、精简层级

- 名录的「展开 / 收起」伪标签、列表行的序号
- 首页眉标「木构星图 · 卷二」、收录数后的「条 · 图册收录」
- 页脚「一木承千年，一览见天地。」「木构星图 / 贰」
- 朝代导航的两位数字

层级收敛为三级：**h2（26—38px）→ 正文 16px → 标注 13px**，全站不再出现 13px 以下的字。

### 3. 地球放大后不裁切，左侧 UI 压在地球之上

这是本次唯一的架构性改动。原来 `.earth-stage { overflow: hidden }` 直接裁掉溢出，
且画布与舞台同尺寸，球一旦放大就被画布边缘切平。

| 文件 | 改动 |
|---|---|
| `css/globe.css` | 舞台 `overflow` 改为 `visible`；`#globe`/`#leaders`/`#map-labels` 从 `inset:0` 改为**大于舞台的画布**：右缘与舞台对齐、左缘外扩 `--bleed`、高度 `--globe-canvas`（`min(88svh,940px)`），垂直居中；刻度盘与投影跟随球心（`left: calc(50% - var(--bleed)/2)`） |
| `js/globe/globe.js` | 新增 `layoutMetrics()`：把舞台矩形换算进画布坐标（`stageTop/stageHeight/stageRight/stageWidth/bleed`）；按舞台算“不裁切”最近距离 `fitDistance = R·h / (min(0.97·stageH, stageW)·tan(fov/2))`；`focus()`、`zoom()`、双指缩放统一 clamp 到该距离；同时监听舞台尺寸变化，防止布局晚到导致上限算错 |
| `css/panel.css` | `.panel` 提到 `z-index:4`（舞台 1、导航 5），并用 `::before` 做纸质蒙版 + `::after` 一条竖细线，交代“纸压球”的前后关系；蒙版默认 `opacity:0` |
| `js/main.js` | `syncDial()` 里按球半径与舞台宽度判定是否真的压到说明栏，命中才给 `<body>` 加 `is-underlap`，蒙版淡入 420ms。首页不压球时不会出现多余色块 |
| `css/layout.css` | `@media (max-width:1023px)` 改为纵向叠放（导航在上、地球居中、文字在下），避免平板竖屏被三栏挤成 208px 窄列 |

几何结果（1440×900）：舞台 786×758，球最大直径 736，球心较舞台中心左移 158px，
左缘压进说明栏约 60px。球在任何缩放级别都不超出舞台，因此永不被画布或视口切边。

### 4. taste skill 的 UI 细节

- **间距**：所有外边距、内距、间隙改用 `--s-1…--s-8` 一套刻度，不再出现 2/7/9/13px 这类散值。
- **字体**：字面层级统一（h2 / 16 正文 / 13 标注）；中文标题字距 0.08em、正文 0.01—0.02em；`text-wrap: pretty` 避免孤字。
- **色彩**：纸 `#eecaa2`、墨 `#1c1712`、朱 `#bf3a1e` 三色不动；标注降到 60% 墨保证 4.5:1 以上，正文 82%。
- **层级**：面板 4 > 导航 5 / 舞台 1；蒙版只在需要时出现，避免“糊一块”。
- **图下不放说明**：详情照片的 `figcaption` 整段删除（house rule 1）。
- **动效**：保留原有下划线生长与按压回弹；去掉印章的 `rotate(-3deg)` 倾斜（house rule：不许倾斜），改为 1.04 缩放；照片框 hover 抬升 2px、照片由灰调转暖（house rule 5）。
- **滚动提示**：`.panel-inner` 底部 32px 渐隐，提示还有内容，不额外加箭头或文字。
