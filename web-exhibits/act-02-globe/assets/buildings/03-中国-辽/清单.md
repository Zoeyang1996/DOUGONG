# 03 · 中国辽代木构

> **全国现存：8 座（官方口径"八大辽构"）**
> 名单据山西省文物局、中国日报 2026 年"八大辽构古建筑技艺展"报道确认，梁思成誉为"千年国宝"。
> 共同特征：上承唐风雄健、下融宋制精巧；斗拱硕大、出跳多；平面以多边形与矩形为主。

## liao-01 · 独乐寺观音阁

| 项 | 内容 |
|---|---|
| 英文名 | Dule Temple Guanyin Pavilion |
| 年代 | **984 年**（辽统和二年） |
| 地点 | 天津市蓟州区武定街 |
| 坐标 | 40.049, 117.399（近似 · 城区级） |
| 类型 | 楼阁 · 重檐歇山 · 外观两层实为三层 |
| 斗拱 | 柱头与补间出跳数不同，形成收放节奏 |
| 状态 | 已核 |

**一句话**：中国现存最古老的楼阁式木构之一。

**说明**：建于辽统和二年（984），外观两层、实为三层，中间夹一暗层。阁内立 16 米高的十一面观音塑像，为国内现存最大的辽代泥塑。千余年来经历多次地震，包括 1976 年唐山大地震，结构仍基本完好。辽代斗拱上承唐风、下启宋制，此阁是八大辽构中最具代表性的一座。

**图片 01（全景）**：观音阁正面，能看出重檐与暗层关系（最好带前景院落）。
**图片 02（局部）**：上层檐下铺作近景。**重点是拍出柱头与补间出跳数不同**——这是本阁最精彩的结构细节。

**采集**：Commons 搜 `Dule Temple Jixian`；中国日报八大辽构报道。
**注意**：山门与观音阁在同一寺院，图易混。山门的图必须是那座单檐庑殿顶的门，不要用观音阁的图代替。

## liao-02 · 独乐寺山门

| 项 | 内容 |
|---|---|
| 英文名 | Dule Temple Shanmen Gate |
| 年代 | **984 年**（辽统和二年） |
| 地点 | 天津市蓟州区武定街 |
| 坐标 | 40.048, 117.398（近似 · 城区级） |
| 类型 | 门 · 单檐庑殿顶 |
| 斗拱 | 柱头铺作五铺作 |
| 状态 | 已核 |

**一句话**：现存最早的庑殿顶山门之一。

**说明**：与观音阁同期建造，面阔三间，单檐庑殿顶，是中国现存最早的庑殿顶山门。屋顶举折平缓，出檐深远，鸱吻为辽代原物。山门与观音阁一前一后，构成一组完整的辽代寺院建筑序列，也是八大辽构中唯一的门类建筑。

**图片 01（全景）**：山门正面，能看出庑殿顶的四面坡。
**图片 02（局部）**：檐下铺作或正脊鸱吻近景（鸱吻为辽代原物，价值更高）。

**采集**：Commons 搜 `Dule Temple Shanmen`。

**一句话**：辽代最大的佛殿。

**说明**：建于辽开泰九年（1020），面阔九间、进深五间，是中国现存最大的辽代佛殿，也是辽代三大寺院之一。殿内保存辽代彩塑七尊大佛，高逾九米，为国内现存最大的辽代塑像群。斗拱用材硕大，出檐深远，代表辽代建筑的最高规格。

**图片 01（全景）**：大雄宝殿正面，注意面阔九间的横向尺度（建议广角或接片）。
**图片 02（局部）**：檐下铺作近景，或殿内七佛全景。

**采集**：Commons 搜 `Fengguo Temple Yixian`。

## liao-04 · 应县木塔（佛宫寺释迦塔）

| 项 | 内容 |
|---|---|
| 英文名 | Yingxian Wooden Pagoda / Sakyamuni Pagoda of Fogong Temple |
| 年代 | **1056 年**（辽清宁二年） |
| 地点 | 山西省朔州市应县 |
| 坐标 | 39.566, 113.183（近似 · 城区级） |
| 类型 | 塔 · 纯木楼阁式 · 八角五层六檐（实为九层含四暗层） |
| 斗拱 | **54 种** |
| 状态 | 已核 |

**一句话**：世界现存最高、最古老的纯木结构楼阁式塔。

**说明**：建于辽清宁二年（1056），高 67.31 米，外观五层六檐，内部实为九层（含四个暗层），是中国现存最高最古的木塔，与比萨斜塔、埃菲尔铁塔并称"世界三大奇塔"。全塔使用 54 种斗拱，层层叠叠，被称为"斗拱博物馆"。2016 年获吉尼斯认证为世界最高木塔。目前塔身已出现明显倾斜，保护方案仍在论证。

**图片 01（全景）**：木塔正面，能看出五层六檐的层叠关系，最好带塔刹。
**图片 02（局部）**：檐下斗拱近景，**尽量拍出多种斗拱并存的密集感**。

**采集**：Commons 搜 `Yingxian Wooden Pagoda`；有 `Fogong temple corner dougong.JPG` 与 `Fogongsi ang.JPG` 两张 CC 图可用（后者专拍昂，很适合第一幕下昂页）。
**注意**：54 种斗拱是"种类数"，不是"朵数"，文案不要混。塔身倾斜属现状问题，**不要当"设计巧妙"来讲**。

| 类型 | 殿 · 单檐庑殿顶 |

| 状态 | 已核 |

**一句话**：辽金寺院中布局保存最完整的一座。

**说明**：善化寺是国内辽金寺庙中布局保存最完整者，大雄宝殿面阔七间、进深十椽，单檐庑殿顶，屋顶平缓、出檐深远。殿内佛坛上塑五方佛、二弟子、二胁侍菩萨，两侧为二十四诸天，共计三十三尊，是辽金彩塑的代表。同寺另有金代三圣殿与山门，可作辽金两代同院对照。

**图片 01（全景）**：大雄宝殿正面。
**图片 02（局部）**：殿内梁架与佛坛全景。

**采集**：Commons 搜 `Shanhua Temple Datong`。
**加分提示**：善化寺同时收录辽构（大雄宝殿）与金构（三圣殿），是"一院两代"的第二处样本（另一处是佛光寺唐+金）。

| 斗拱 | 柱头铺作五铺作 |
| 状态 | 已核 |

**一句话**：殿内藏经壁藏是辽代小木作的巅峰。

**说明**：建于辽重熙七年（1038），是华严寺现存最早的建筑。殿内沿墙排列三十八间重楼式壁藏，为存放佛经所用，是国内现存最完整的辽代小木作精品，被梁思成称为"海内孤品"。殿内辽代彩塑三十一尊，其中合掌露齿菩萨像尤为著名。

**图片 01（全景）**：薄伽教藏殿正面。
**图片 02（局部）**：**殿内壁藏（小木作）近景**——这是本条目最不可替代的画面，比外观更有价值。

**采集**：Commons 搜 `Huayan Temple Datong`。
**注意**：华严寺分上寺、下寺。薄伽教藏殿在下寺，大雄宝殿在上寺，两个条目不要配错图。

## 辽构的三个叙事点

1. **"八座"本身就是一个数字奇观**：辽代两百余年，只留下 8 座完整木构。地图上八个点，可以一眼看完一个王朝的建筑遗产。
2. **独乐寺山门+观音阁 → 佛光寺东大殿**：辽构上承唐风，把这两者并排，能看出"唐的雄浑怎么变成辽的豪劲"。
3. **大同双辽构**：善化寺大雄宝殿 + 华严寺薄伽教藏殿，两座在同城，可做一条"大同辽构一日"的路线。
