# 06 · 中国元代木构

> **全国现存：约 389 座**（山西 338 座，占 87%）——元代是木构数量激增的转折点。
> 本目录收 3 座代表。元代建筑用材趋于随意，梁架常直接使用**自然弯曲的木料**（"原木作梁"），
> 减柱造、移柱造运用更自由，整体风格从宋的规整转向粗放实用。

## yuan-01 · 永乐宫三清殿

| 项 | 内容 |
|---|---|
| 英文名 | Yongle Palace Sanqing Hall |
| 年代 | 1247—1358 年（元） |
| 地点 | 山西省运城市芮城县永乐北路 |
| 坐标 | 34.717, 110.684（近似 · 城区级） |
| 类型 | 殿 · 单檐歇山顶 |
| 斗拱 | 柱头铺作 |
| 状态 | 已核 |

**一句话**：元代壁画与木构的双重巅峰。

**说明**：元代全真教宮观，三清殿为主体建筑，建于 13 世纪。殿内《朝元图》壁画面积逾 400 平方米，绘有 290 余位神祇，是中国现存最精彩的元代壁画。1957—1965 年因三门峡水库工程，整座宮观连同壁画被整体迁移至现址，是世界文物保护史上的创举。

**图片 01（全景）**：三清殿正面。
**图片 02（局部）**：**殿内《朝元图》壁画局部**——本条目真正的价值在壁画，不在斗拱。

**采集**：Commons 搜 `Yongle Palace Ruicheng`。
**叙事提示**：整体迁移这件事本身极具故事性（把一座宮连同壁画一起搬走），比讲形制更吸引普通观众。

## yuan-02 · 北岳庙德宁殿

| 项 | 内容 |
|---|---|
| 英文名 | Beiyue Temple Dening Hall |
| 年代 | 元代 |
| 地点 | 河北省保定市曲阳县 |
| 坐标 | 38.622, 114.704（近似 · 城区级） |
| 类型 | 殿 · **重檐庑殿顶** |
| 斗拱 | 柱头铺作 |
| 状态 | 已核 |

**一句话**：元代等级最高的大殿。

**说明**：北岳庙为历代祭祀北岳恒山之所，德宁殿是主体建筑，重檐九开间，是元代建筑中等级最高的大殿。殿内保存元代壁画《天宫图》，以及历代碑刻百余通。元代木构用材趋于随意，梁架常作自然弯材，此殿可见这一特征。

**图片 01（全景）**：德宁殿正面，能看出重檐与九间面阔。
**图片 02（局部）**：殿内梁架（**注意拍出自然弯材**）或元代壁画局部。

**采集**：Commons 搜 `Beiyue Temple Quyang`。
**注意**：北岳庙在河北曲阳，不在山西浑源恒山。历代祭祀北岳长期在曲阳，这是个常见的认知错误，文案可以点一句。

## yuan-03 · 广胜寺下寺

| 项 | 内容 |
|---|---|
| 英文名 | Guangsheng Temple Lower Monastery |
| 年代 | 元代 |
| 地点 | 山西省临汾市洪洞县 |
| 坐标 | 36.290, 111.700（近似 · 乡镇级） |
| 类型 | 寺 · 单檐歇山 / 悬山 |
| 斗拱 | 柱头铺作 |
| 状态 | 已核 |

**一句话**：元代民间木构与壁画的组合。

**说明**：广胜寺分上、下二寺，下寺主体为元代建筑，包括前殿、后殿与水神庙。水神庙明应王殿内的元代壁画《打球图》《杂剧图》是中国戏曲史上的重要图像资料。上寺飞虹塔为**明代琉璃塔**，常被误传为木塔，需注意区分。

**图片 01（全景）**：下寺后殿正面。
**图片 02（局部）**：水神庙元代壁画局部（《杂剧图》最著名）。

**采集**：Commons 搜 `Guangsheng Temple Hongtong`。
**⚠️ 常见错误**：飞虹塔是**明代琉璃塔**，不是元代木塔，也不是纯木构。不要把它的图放进木构条目里。

## 元代的两个叙事点

1. **数量断崖式增长**：唐 3、五代 5、辽 8、宋约 183、金约 113、**元约 389**。地图上把元以前各代和元代分别上色，这个"忽然变多"的视觉冲击非常强——它说明的不是"元代建筑水平高"，而是"更早的木构能被保存下来的太少了"。
2. **原木作梁**：元代工匠直接拿弯曲的原木当梁，不做过多加工。这是"从规整走向实用"的转折，与明清的"从结构走向装饰"是两条不同的下坡路线。
