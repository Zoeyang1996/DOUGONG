## mingqing-01 · 故宫太和殿

| 项 | 内容 |
|---|---|
| 英文名 | Forbidden City, Hall of Supreme Harmony |
| 年代 | **1695 年**（清康熙三十四年重建） |
| 地点 | 北京市东城区故宫 |
| 坐标 | 39.916, 116.390（近似 · 精确到建筑） |
| 类型 | 殿 · 重檐庑殿顶 |
| 斗拱 | 平身科五踩重翘；**构件厚度减至唐宋的 1/2** |
| 状态 | 已核 |

**一句话**：明清斗拱退化为装饰的终点。

**说明**：现存太和殿为清康熙三十四年（1695）重建，是中国现存最大的木构殿宇。面阔十一间，重檐庑殿顶。此时梁已不再插入斗拱，而直接压在斗拱最上一跳之上，斗拱不再承担结构整体性，尺度缩小、间距加密，转为等级标识。构件厚度减至唐宋时期的二分之一，是「斗拱从结构走向装饰」最清晰的物证。

**图片 01（全景）**：太和殿正面，含三层台基（汉白玉须弥座）。
**图片 02（局部）**：**上檐斗拱近景，要能看出"密集的小尺度斗拱"**——与唐代斗拱的稀疏硕大形成强烈对比。

**采集**：Commons 搜 `Hall of Supreme Harmony`。有 `Interlocking wooden brackets.jpg`（CC BY-SA 3.0，故宫内部斗拱，**但描述未指明具体殿名，只能注"故宫某殿"**）。
**⚠️ 注意**：现存太和殿是清康熙重建，**不是明代原构**。明万历原殿已毁。写年代必须写 1695。

## mingqing-02 · 智化寺

| 项 | 内容 |
|---|---|
| 英文名 | Zhihua Temple |
| 年代 | **1444 年**（明正统九年） |
| 地点 | 北京市东城区禄米仓胡同 |
| 坐标 | 39.921, 116.432（近似 · 城区级） |
| 类型 | 寺 · 单檐歇山 / 庑殿 |
| 斗拱 | 明代官式斗拱（尺度已明显小于宋元） |
| 状态 | 已核 |

**一句话**：明代官式木构与京音乐的双重遗存。

**说明**：明正统九年（1444）由太监王振所建，是北京保存最完整的明代木构寺院。寺内藏殿的转轮藏为明代小木作精品，雕刻极精。智化寺京音乐为国家级非物质文化遗产，传承五百余年。作为明代官式建筑，其斗拱尺度已明显小于宋元，但仍保有结构作用。

**图片 01（全景）**：智化寺山门或智化殿正面。
**图片 02（局部）**：**藏殿转轮藏（小木作）近景**——这是智化寺最不可替代的画面。

**采集**：Commons 搜 `Zhihua Temple Beijing`。

## 明清这一段的叙事：斗拱的退场

> **唐（857）**：斗拱高近柱身一半，出檐三四米，梁插进斗拱里。
> **宋（1013）**：斗拱规整化，写进《营造法式》，成为国家标准。
> **清（1695）**：梁压在斗拱最上一跳，斗拱不再承重，尺度缩小、构件变薄，成为等级标识。
>
> 三段并排，用同一角度拍斗拱，就是一条完整的"构件退化史"。
> **这正是第一幕 G4→G5→G6 的素材来源**，两幕可以共用同一批图片。
