# 01 · 中国唐代木构

> **全国现存：3—4 座（全在山西，口径有争议）**
> 争议点见 `_01-有争议条目说明.md`：天台庵弥陀殿原列唐构，2014—2016 年大修发现后唐题记后，官方口径改定为五代。本目录收录 3 座唐代、天台庵归入五代目录。
> 唐代木构的共同特征：斗拱硕大（高近柱身一半）、出檐深远（可达三四米）、屋顶平缓、柱子粗壮并有侧脚。

## tang-01 · 南禅寺大殿

| 项 | 内容 |
|---|---|
| 英文名 | Nanchan Temple Main Hall |
| 年代 | **782 年**（唐建中三年） |
| 地点 | 山西省忻州市五台县阳白乡李家庄 |
| 坐标 | 38.737, 113.109（近似 · 乡镇级） |
| 类型 | 殿 · 单檐歇山顶 · 抬梁式 |
| 斗拱 | 柱头铺作五铺作双杪偷心造 |
| 状态 | 已核 |

**一句话**：中国现存最古老的木构建筑。

**说明**：重建于唐建中三年（782），是唐武宗会昌灭法（845）之前唯一留存至今的木构殿宇。面阔进深各三间，单檐歇山顶，殿身小巧而比例严整。殿内保存唐代彩塑十七尊，与建筑同期。1953 年发现，1961 年列为首批全国重点文物保护单位。它的存在证明：唐代木构并非只存在于文献与壁画中。

**图片 01（全景）**：大殿正面，能看到单檐歇山顶的完整轮廓、台基与出檐深度。避开游客与围栏。
**图片 02（局部）**：前檐柱头铺作近景，能数出两跳华栱，并能看出跳头没有横栱（偷心做法）。

**采集**：Wikimedia Commons 搜 `Nanchan Temple Wutai`；官方来源见山西省文物局。
**注意**：不要把殿内彩塑单独当"斗拱图"用；本条目两个槽位都要拍建筑本体。

## tang-02 · 佛光寺东大殿

| 项 | 内容 |
|---|---|
| 英文名 | Foguang Temple East Hall |
| 年代 | **857 年**（唐大中十一年） |
| 地点 | 山西省忻州市五台县豆村镇佛光村 |
| 坐标 | 38.869, 113.386（近似 · 乡镇级） |
| 类型 | 殿 · 单檐庑殿顶 · 殿堂型构架 |
| 斗拱 | 柱头铺作七铺作双杪双下昂（八铺作说并存，需注明） |
| 状态 | 已核 |

**一句话**：中国现存规模最大、最完整的唐代殿堂，梁思成称"中国第一国宝"。

**说明**：建于唐大中十一年（857），面阔七间、进深四间，单檐庑殿顶。1937 年由梁思成、林徽因等中国营造学社成员发现，直接打破了"中国境内已无唐代木构"的论断。殿内唐代建筑、彩塑、壁画、题记"四绝"并存。斗拱单栱出挑即达 2 米，是理解唐代出檐尺度的基准样本。

**图片 01（全景）**：东大殿正面，能看出庑殿顶的完整形态与深远出檐。经典机位在殿前平台。
**图片 02（局部）**：转角铺作或柱头铺作近景，要能看出双杪双下昂的层叠关系。

**采集**：Commons 已有可用图 `Wutai 2009 492.jpg`（CC BY-SA 4.0，转角铺作特写，描述已核）。
**注意**：铺作数存在"七铺作/八铺作"两种说法，界面文案建议写"七铺作双杪双下昂（另有八铺作说）"。

## tang-03 · 广仁王庙正殿

| 项 | 内容 |
|---|---|
| 英文名 | Guangrenwang Temple Main Hall |
| 年代 | **831 年**（唐大和五年） |
| 地点 | 山西省运城市芮城县古魏城遗址北 |
| 坐标 | 34.693, 110.689（近似 · 县级） |
| 类型 | 殿 · 单檐歇山顶 |
| 斗拱 | 柱头铺作五铺作双杪偷心造 |
| 状态 | 已核 |

**一句话**：中国现存最早的道庙木构之一。

**说明**：俗称五龙庙，因祀奉水神广仁王得名。正殿建于唐大和五年（831），面阔五间，单檐歇山顶，是现存少数唐代道教建筑实物。与南禅寺、佛光寺同处山西，共同构成唐代木构的三个基本样本。殿内无唐代塑像留存，价值集中于大木结构本身。

**图片 01（全景）**：正殿正面，含台基与踏道，能看出五间面阔。
**图片 02（局部）**：檐下铺作近景。

**采集**：Commons 搜 `Guangrenwang Temple`；芮城县文管所资料。
**注意**：此处与永乐宫同在芮城，地图上两点距离很近，需在界面上避免点位重叠遮挡。

## 唐代三座的一句话对照（可直接做成一屏）

| 建筑 | 年代 | 面阔 | 看点 |
|---|---|---|---|
| 南禅寺大殿 | 782 | 三间 | **最早**，会昌灭法前唯一幸存 |
| 广仁王庙正殿 | 831 | 五间 | **唯一道庙**，三个样本之一 |
| 佛光寺东大殿 | 857 | 七间 | **最大最完整**，四绝并存 |

> 三座全部在山西，相隔最远不到 300 公里——这也是"地上文物看山西"最直接的证据。
