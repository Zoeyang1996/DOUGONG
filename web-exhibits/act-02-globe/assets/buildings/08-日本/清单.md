# 08 · 日本木构

> **作用**：与中国唐宋木构做横向对照，展示同一木构体系在海外的独立演化。
> **核心提醒**：日本斗拱源于中国，但**已独立演化出云斗、云肘木等本土形式**。
> 界面文案**不可直接套用中国宋清术语**（不能说"这是日本的七铺作"）。

**四条必须记住的年代陷阱**：

| 建筑 | 常见误写 | 正确 |
|---|---|---|
| 法隆寺 | 607 年 | 创建 607，**现存为 670 年火灾后重建（7 世纪末—8 世纪初）** |
| 东大寺大佛殿 | 8 世纪 | **现存为 1709 年江户重建** |
| 唐招提寺金堂 | 759 年 | 创建 759，现存为 8 世纪后半 |
| 药师寺东塔 | 697 年 | 创建期唯一留存，但需注明"创建期"而非"697 年建成" |

## jp-01 · 法隆寺金堂与五重塔

| 项 | 内容 |
|---|---|
| 英文名 | Horyu-ji Kondo and Five-story Pagoda |
| 年代 | 创建 **607 年**；**现存 7 世纪末—8 世纪初**（670 年火灾后重建） |
| 地点 | 日本奈良县生驹郡斑鸠町 |
| 坐标 | 34.614, 135.735（近似 · 精确到寺院） |
| 类型 | 寺院建筑群 · 飞鸟样式 |
| 斗拱 | 云斗、云肘木等日本早期斗拱形式 |
| 状态 | 已核 |

**一句话**：世界现存最古老的木构建筑群。

**说明**：法隆寺创建于推古天皇十五年（607），由圣德太子主持兴建。据《日本书纪》记载，670 年寺院毁于大火，现存金堂、五重塔、中门、回廊为 7 世纪末至 8 世纪初重建，是世界现存最古老的木构建筑群。五重塔高约 32.5 米，塔心柱使用 594 年采伐的扁柏，贯通五层，可吸收地震能量。1993 年成为日本第一处世界文化遗产。日本斗拱源于中国，但已独立演化出云斗、云肘木等本土形式，不可直接套用中国宋清术语。

**图片 01（全景）**：**金堂与五重塔同框**（西院伽蓝经典视角，这是法隆寺的标志性画面）。
**图片 02（局部）**：金堂檐下斗拱近景，**注意拍出云斗与云肘木**（与中国斗拱形制明显不同）。

**采集**：Commons 搜 `Horyu-ji Kondo` / `Horyu-ji Pagoda`；法隆寺官网 https://www.horyuji.or.jp/
**⚠️ 上线要求**：年代必须双写"创建 607 / 现存 7 世纪末"，只写 607 会被专业人士一眼看穿。

## jp-02 · 唐招提寺金堂

| 项 | 内容 |
|---|---|
| 英文名 | Toshodai-ji Kondo |
| 年代 | 创建 **759 年**；现存 8 世纪后半 |
| 地点 | 日本奈良县奈良市五条町 |
| 坐标 | 34.675, 135.785（近似 · 城区级） |
| 类型 | 殿 · 单檐庑殿顶 · 和样 |
| 斗拱 | 三手先等日本斗拱形式 |
| 状态 | 已核 |

**一句话**：鉴真东渡所建，中日交流的物证。

**说明**：由中国唐代高僧鉴真主持创建，始建于天平宝字三年（759），鉴真于 763 年在此圆寂。金堂面阔七间，单檐庑殿顶，是日本奈良时代最大、最美的建筑之一，也是最接近唐代建筑做法的现存实例。堂内供奉卢舍那佛坐像与千手观音立像，为日本国宝。与法隆寺同为研究中国唐代建筑在海外影响的关键实物。

**图片 01（全景）**：金堂正面，注意庑殿顶与出檐比例（与佛光寺东大殿可并置比较）。
**图片 02（局部）**：檐下斗拱近景。

**采集**：Commons 搜 `Toshodai-ji Kondo`；唐招提寺官网。
**叙事提示**：鉴真六次东渡、双目失明后抵达日本——这个故事本身就是最好的入口，不需要额外解释建筑。

## jp-03 · 东大寺大佛殿

| 项 | 内容 |
|---|---|
| 英文名 | Todaiji Great Buddha Hall (Daibutsuden) |
| 年代 | **1709 年**（江户宝永六年重建） |
| 地点 | 日本奈良县奈良市杂司町 |
| 坐标 | 34.689, 135.840（近似 · 城区级） |
| 类型 | 殿 · 重檐庑殿顶 |
| 斗拱 | 江户期斗拱 |
| 状态 | 已核 |

**一句话**：世界最大级木构殿阁，但现存为江户重建。

**说明**：东大寺始建于 8 世纪，圣武天皇发愿建造，原大佛殿为世界最大的木构建筑之一。现存大佛殿为江户宝永六年（1709）重建，面阔七间，规模虽比原构缩小约三分之一，仍是世界最大级的木构殿阁。殿内供奉 15 米高的卢舍那大佛。

**图片 01（全景）**：大佛殿正面，能体现巨大体量（最好有人物做尺度参照）。
**图片 02（局部）**：殿内卢舍那大佛与梁架。

**采集**：Commons 搜 `Todaiji Daibutsuden`。
**⚠️ 关键提醒**：**现存建筑不是奈良时代原构**。它与法隆寺（7 世纪）、唐招提寺（8 世纪）不在同一个年代层级，做对照时不能并列。放在这里是为了说明"日本也在不断重建"，而不是"日本有个 8 世纪的巨大木殿"。

## jp-04 · 药师寺东塔

| 项 | 内容 |
|---|---|
| 英文名 | Yakushi-ji East Pagoda |
| 年代 | 8 世纪（奈良时代，创建期唯一留存） |
| 地点 | 日本奈良县奈良市西之京町 |
| 坐标 | 34.669, 135.784（近似 · 城区级） |
| 类型 | 塔 · 三重塔 · 木构 |
| 斗拱 | 日本早期斗拱 |
| 状态 | 已核 |

**一句话**：日本现存最古老的塔之一。

**说明**：药师寺为天武天皇发愿、持统天皇于 697 年建成的官寺。东塔是创建期唯一留存至今的建筑，为三重塔，各层附有裳阶，外观呈六重檐的效果，被称为「凝固的音乐」。塔身比例优美，是白凤艺术的代表。1998 年作为「古都奈良的文化财」列入世界遗产。

**图片 01（全景）**：东塔全景，**注意各层裳阶形成的重檐效果**（三重塔看起来像六重檐，这是它最特别的地方）。
**图片 02（局部）**：塔身斗拱与云斗近景。

**采集**：Commons 搜 `Yakushi-ji East Pagoda`；药师寺官网。

## 日本这一屏怎么讲

> **不要讲"日本保存了唐代建筑"**——这句话不准确，也容易引起争议。
>
> 准确的讲法是：
> **"同一个木构体系，传过去之后走上了自己的路。"**
>
> - 中国的斗拱：斗 + 栱 + 昂，层层出跳，追求出檐深度。
> - 日本的斗拱：云斗 + 云肘木，形式更简洁，与和样、大佛样、禅宗样三种样式并行发展。
> - 两者同源，但不能互相套用术语。
>
> 建议做成一张并置图：**保国寺前檐柱头铺作 ｜ 法隆寺金堂檐下斗拱**，
> 同为 11 世纪前后，形制已经明显分岔。
