# 04 · 中国宋代木构

> **全国现存：北宋约 34 座、南宋若干，宋辽金合计约 183 座**（山西占 150 座）
> 本目录只收 6 座最有代表性的：**保国寺大殿是本项目主角**，其余用于对照。
> 共同特征：斗拱开始规整化、制度化，《营造法式》（1103）把经验写成国家标准；屋顶渐陡、出檐收敛；南方与北方做法分化明显。

## song-01 · 保国寺大殿 ⭐ 本项目主角

| 项 | 内容 |
|---|---|
| 英文名 | Baoguo Temple Main Hall |
| 年代 | **1013 年**（北宋大中祥符六年） |
| 地点 | 浙江省宁波市江北区洪塘街道鞍山村 |
| 坐标 | 29.984, 121.515（近似 · 村级） |
| 类型 | 殿 · 单檐歇山（清代加下檐成重檐）· 厅堂型构架 |
| 斗拱 | 外檐七铺作双杪双下昂，第一跳偷心；斗拱共 **20 种** |
| 状态 | 已核 |

**一句话**：南方早期木构三座之一，形制最完整的一朵七铺作。

**说明**：建于北宋大中祥符六年（1013），长江以南最古老、保存最完整的木构建筑之一。面阔三间 11.91 米、进深三间 13.36 米，**进深大于面阔**。16 根柱全为瓜棱柱，其中四根为四段拼合、外镶四瓣，是现存唯一的宋代拼合柱实例；柱上栌斗也做八瓣，为现存遗构中的唯一案例。斗拱用材断面高宽比 3:2，与九十年后成书的《营造法式》高度吻合。2009—2012 年东南大学完成构件级测绘，近 3000 个构件、1504 个斗、673 根栱。

**图片 01（全景）**：大殿正面，能看出清代所加重檐与宋构主体的关系（**不要只拍重檐，要能分辨哪一圈是宋代原构**）。
**图片 02（局部）**：前檐柱头铺作近景，能数出双杪双下昂。

**采集**：**首选现场自拍**（申报书里 500 元差旅就为这个）。Commons 上暂未找到明确标注"保国寺大殿斗拱"的照片，`Ningbo Baoguo Si 2013.07.27 10-24-13.jpg`（CC BY-SA 3.0）描述为"宁波市保国寺——大殿"，需目视确认是外观还是局部后再用。
**注意**：现状是"重檐"，但宋代原构是单檐，清代加了四周下檐。文案必须说清这一点，否则会被当作宋构原貌。

## song-02 · 晋祠圣母殿

| 项 | 内容 |
|---|---|
| 英文名 | Jinci Sacred Lady Hall |
| 年代 | **1023—1032 年**（北宋天圣年间） |
| 地点 | 山西省太原市晋源区晋祠 |
| 坐标 | 37.707, 112.438（近似 · 城区级） |
| 类型 | 殿 · 重檐歇山顶 |
| 斗拱 | 柱头铺作五铺作 |
| 状态 | 已核 |

**一句话**：宋代祠庙建筑的巅峰之作。

**说明**：建于北宋天圣年间（1023—1032），是为奉祀唐叔虞之母邑姜而建。面阔七间，重檐歇山顶，殿前廊柱上八根木雕盘龙柱为国内孤例。柱身有明显的侧脚与生起，殿内采用减柱造以拓展空间，做法严格契合《营造法式》规制。是宋式建筑「雅致灵动」一面的代表。

**图片 01（全景）**：圣母殿正面，能看出重檐与廊柱。
**图片 02（局部）**：**前廊盘龙柱近景**——八根宋代木雕盘龙柱是国内孤例，比斗拱更有辨识度。

**采集**：Commons 搜 `Jinci Saint Mother Hall`。

## song-03 · 隆兴寺摩尼殿

| 项 | 内容 |
|---|---|
| 英文名 | Longxing Temple Moni Hall |
| 年代 | **1052 年**（北宋皇祐四年；1977—1980 大修发现墨书题记） |
| 地点 | 河北省石家庄市正定县 |
| 坐标 | 38.147, 114.573（近似 · 城区级） |
| 类型 | 殿 · 重檐歇山 · **平面十字形** |
| 斗拱 | 柱头铺作五铺作 |
| 状态 | 已核 |

**一句话**：平面最特殊的宋代殿宇。

**说明**：建于北宋皇祐四年（1052），平面呈十字形（四面各出抱厦），是中国现存唯一采用这种平面布局的宋代建筑。殿内保存宋代彩塑与「倒坐观音」像，被鲁迅誉为「东方美神」。1977—1980 年大修时在构件上发现北宋墨书题记，为断代提供了确切依据。正定一城之内集唐、五代、宋、金、元、明、清七代木构，被称为「古建博物馆」。

**图片 01（全景）**：摩尼殿，**必须能看出十字形平面与四面抱厦**（俯视或斜面机位最佳）。
**图片 02（局部）**：殿内倒坐观音彩塑。

**采集**：Commons 搜 `Longxing Temple Zhengding`。
**加分提示**：「一城七代」是很好的地图叙事点——正定的点位可以做成一个"多层叠加"的特殊节点。

| 类型 | 殿 · 单檐歇山顶 |
| 斗拱 | 柱头铺作与补间铺作 |
| 状态 | 已核 |

**一句话**：江南现存最大的宋代殿宇之一。

**说明**：重建于南宋淳熙六年（1179），面阔九间，是江南地区现存规模最大的宋代木构殿宇。殿内保存唐代吴道子画像石刻与老子像碑。位置在苏州闹市中心，与保国寺同属南方宋构，但一为道观、一为佛寺，可作类型对照。

**图片 01（全景）**：三清殿正面，注意它被商业街区包围的现状。
**图片 02（局部）**：殿内梁架与柱网全景。

**采集**：Commons 搜 `Xuanmiao Temple Suzhou`。

## 宋代最值得做的一屏：南方三座

> **福州华林寺（964）· 宁波保国寺（1013）· 肇庆梅庵（北宋）**
>
> 中国南方潮湿多雨、白蚁横行，早期木构极难保存。这三座是仅存的硕果。
> 保国寺能位列其中，才是它真正的价值——比"江南最古老"更有信息量。
> 建议在地图上单独做一条"南方三座"的连线，与"山西密集区"形成强对比：**一个在北方成片，一个在南方只剩三点**。
