# 02 · 中国五代木构

> **全国现存：约 5 座**（含原定唐构、现改定为五代的平顺天台庵；含建成时当地未归宋的福州华林寺）
> 五代（907—960）仅五十余年，战乱频仍，木构留存极少，每一座都是孤例级别的实物。
> 共同特征：上承唐风、下启宋制，处于"唐宋之间"。斗拱仍然硕大，但已开始规整化。

| 项 | 内容 |

| 年代 | **929 / 933 年（后唐天成四年 / 长兴四年）· 有争议** |
| 地点 | 山西省长治市平顺县王曲村 |
| 坐标 | 36.190, 113.444（近似 · 乡镇级） |
| 类型 | 殿 · 单檐歇山顶 |
| 斗拱 | 柱头铺作四铺作（形制古朴） |
| 状态 | **有争议** |

**一句话**：唐构还是五代构？中国木构断代最著名的一桩争议。

**说明**：长期被列为中国四座唐代木构之一。2014—2016 年落架大修时，在脊槫与替木间发现墨书「长兴四年九月二日」，又在飞子上发现「大唐天成四年建创立，大金壬午年重修……」。天成四年为 929 年、长兴四年为 933 年，均晚于唐亡（907）二十余年。据此，官方口径改定为五代后唐。但题记月份后关键字不明，仍有学者主张「唐建五代重修」，且殿身保留中唐更早做法。

**图片 01（全景）**：弥陀殿正面，注意其小巧体量与「如鸟斯革」的屋面曲线。
**图片 02（局部）**：转角铺作近景，用于对照唐代做法的存留程度。

**采集**：Commons 搜 `Tiantaian Pingshun`；新华社报道见 `_02-来源与待核.md`。
**⚠️ 上线要求**：此条目**必须在卡片上标注"年代有争议"**，并给出两种说法。这是本项目专业度的关键体现，不要为了让数据干净而抹平它。

## wudai-02 · 镇国寺万佛殿

| 项 | 内容 |
|---|---|
| 英文名 | Zhenguo Temple Wanfo Hall |
| 年代 | **963 年**（北汉天会七年） |
| 地点 | 山西省晋中市平遥县郝洞村 |
| 坐标 | 37.236, 112.222（近似 · 村级） |
| 类型 | 殿 · 单檐歇山顶 |
| 斗拱 | 柱头铺作七铺作双杪双下昂 |
| 状态 | 已核 |

**一句话**：国内唯一有确切纪年的北汉木构孤品。

**说明**：建于北汉天会七年（963），面阔进深各三间。斗拱总高约为柱高的十分之七，比佛光寺东大殿更显硕大，是唐宋之间过渡形态的关键实物。殿内保存五代彩塑十一尊，为除敦煌外国内寺观仅存的五代雕塑。屋面出檐极深，约达柱高之半，形成稳重浑朴的外观。

**图片 01（全景）**：万佛殿正面，注意出檐深度与柱高的比例。
**图片 02（局部）**：檐下柱头铺作近景，用于与佛光寺对比出跳比例——这是最好的"斗拱变小了"的证据。

**采集**：Commons 搜 `Zhenguo Temple Pingyao`；平遥古城世界遗产资料。

## wudai-03 · 大云院弥陀殿

| 项 | 内容 |
|---|---|
| 英文名 | Dayuan Temple Mituo Hall |
| 年代 | **940 年**（后晋天福五年） |
| 地点 | 山西省长治市平顺县龙耳山 |
| 坐标 | 36.205, 113.352（近似 · 乡镇级） |
| 类型 | 殿 · 单檐歇山顶 |
| 斗拱 | 柱头与补间五铺作双抄；转角出斜拱斜昂 |
| 状态 | 已核 |

**一句话**：五代木构中转角做法最特殊的一例。

**说明**：位于浊漳河谷，面阔三间、进深三间，通檐用三柱。柱头与明次间补间铺作均为五铺作双抄，转角铺作出斜拱斜昂，圆柱方额，飞檐起翘。殿内保存五代壁画，是同期少见的壁画遗存。五代历时短暂，木构留存极少，此殿因此尤为珍贵。

**图片 01（全景）**：弥陀殿正面，含台基。
**图片 02（局部）**：**转角铺作近景，重点拍斜拱斜昂**——这是本条目唯一不可替代的画面。

**采集**：Commons 搜 `Dayuan Temple Pingshun`；浊漳河谷古建筑群研究资料。
**注意**：浊漳河谷一带有天台庵、大云院、龙门寺等多处早期木构，是"古建走廊"，可在界面做成一条聚落线索。

## wudai-04 · 龙门寺西配殿

| 项 | 内容 |
|---|---|
| 英文名 | Longmen Temple West Annex |
| 年代 | **925 年**（后唐同光三年） |
| 地点 | 山西省长治市平顺县石城镇 |
| 坐标 | 36.352, 113.548（近似 · 乡镇级） |
| 类型 | 配殿 · 悬山顶 |
| 斗拱 | 柱头铺作五铺作 |
| 状态 | 已核 |

**一句话**：一院之内集六个朝代建筑。

**说明**：建于后唐同光三年（925），是龙门寺现存最早的建筑。寺内自五代经宋、金、元、明至清，各代建筑并存于一院，被称为「中国古代建筑编年史」。西配殿体量不大，但结构简净，是观察五代小体量建筑做法的重要样本。

**图片 01（全景）**：西配殿正面。更好的选择是一张能拍到院内多代建筑并置的全景。
**图片 02（局部）**：檐下铺作与梁架近景。

**采集**：Commons 搜 `Longmen Temple Pingshun`。
**加分提示**：如果能拿到"同一院落内六朝建筑"的俯瞰图，比单栋照片更有价值。

## wudai-05 · 华林寺大殿

| 项 | 内容 |
|---|---|
| 英文名 | Hualin Temple Main Hall |
| 年代 | **964 年**（北宋乾德二年；时福建未归宋，常作五代论） |
| 地点 | 福建省福州市鼓楼区屏山南麓 |
| 坐标 | 26.083, 119.283（近似 · 城区级） |
| 类型 | 殿 · 单檐歇山顶 · 厅堂型构架 |
| 斗拱 | 柱头铺作七铺作双杪双下昂 |
| 状态 | 已核 |

**一句话**：长江以南最重要的早期木构之一，也是保国寺的直接参照。

**说明**：建于北宋乾德二年（964），但当时福建尚不归宋管辖，故常作五代建筑论。面阔三间，用材硕大，斗拱与梁架的做法与保国寺大殿高度相似，同属南方体系。它是「南方早期木构仅存三座」（华林寺、保国寺、肇庆梅庵）中年代最早的一座，也是理解保国寺来源的关键参照。

**图片 01（全景）**：大殿正面，含清代增建的外檐部分（注意区分宋构主体与后世增建）。
**图片 02（局部）**：柱头铺作近景，**用于与保国寺前檐柱头铺作并排对照**。

**采集**：Commons 有 `福州华林寺斗栱2018.jpg`（CC BY-SA 4.0，6000×4000，描述已核）。
**加分提示**：华林寺 + 保国寺 的斗拱并排图，是第二幕最有价值的一张对比图，建议单独做一屏。
