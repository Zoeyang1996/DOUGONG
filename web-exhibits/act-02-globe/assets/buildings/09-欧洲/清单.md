# 09 · 欧洲木构

> **作用**：把"木构建筑"从"东亚现象"扩展成"人类共同的技术选择"。
> **核心提醒**：欧洲木构与东亚木构**不同源、不同逻辑**。
> - 中国：抬梁 / 穿斗，斗拱层层出跳，追求**出檐深度**。
> - 挪威木板教堂：石基上架地梁，**立柱（stav）与墙板互扣**，追求**垂直向上升腾**。
> **不可套用斗拱分类，不可用"铺作""斗口"等术语。**

## eu-01 · 乌尔内斯木板教堂

| 项 | 内容 |
|---|---|
| 英文名 | Urnes Stave Church |
| 年代 | **约 1130 年**（最早木材采伐于 1070 年） |
| 地点 | 挪威韦斯特兰郡吕斯特市镇，吕斯特峡湾畔 |
| 坐标 | 61.298, 7.322（近似 · 精确到建筑） |
| 类型 | 教堂 · 木板教堂（Stave Church） |
| 结构 | 立柱（stav）与墙板互扣的承重框架 |
| 状态 | 已核 |

**一句话**：现存最古老、装饰最精美的木板教堂。

**说明**：位于吕斯特峡湾畔，约建于 1130 年，是挪威现存 28 座木板教堂中最古老的一座。北门与外墙的木雕被认为是维京艺术向罗曼式过渡的关键作品，龙纹与藤蔓交织。1979 年列入世界遗产。木材测年显示最早构件采伐于 1070 年，说明教堂部分木料来自更早的前身建筑。木板教堂的承重逻辑是石基上架地梁、立柱与墙板互扣，与中国抬梁、穿斗体系不同源，对比时不可套用斗拱分类。

**图片 01（全景）**：教堂外观，**含峡湾背景的经典视角**（这个地理位置本身就是画面的一部分）。
**图片 02（局部）**：**北门木雕近景**——维京艺术向罗曼式过渡的关键作品，是本条目最不可替代的画面。

**采集**：Commons 搜 `Urnes Stave Church`；UNESCO https://whc.unesco.org/en/list/58/

## eu-03 · 海达尔木板教堂

| 项 | 内容 |
|---|---|
| 英文名 | Heddal Stave Church |
| 年代 | **约 1240 年起分期建造**（历经 200 余年） |
| 地点 | 挪威泰勒马克郡诺托登 |
| 坐标 | 59.579, 9.193（近似 · 精确到建筑） |
| 类型 | 教堂 · 木板教堂（现存最大） |
| 结构 | 立柱与墙板框架 |
| 状态 | 已核 |

**一句话**：现存最大的木板教堂。

**说明**：位于泰勒马克郡，是挪威现存木板教堂中最大的一座，长约 25 米、宽 17 米，高 29 米，有三座塔楼。自 13 世纪中叶起经 200 余年分期建成，内部有传统玫瑰彩绘。至今仍是当地在用的教区教堂。其规模反映了中世纪富裕教区可调动的资源，代表木板教堂这一建筑类型的成熟形态。

**图片 01（全景）**：教堂正面，能看出三塔与整体体量。
**图片 02（局部）**：内部玫瑰彩绘或祭坛近景。

**采集**：Commons 搜 `Heddal Stave Church`。

## eu-04 · 基日岛主显圣容教堂

| 项 | 内容 |
|---|---|
| 英文名 | Kizhi Pogost, Church of the Transfiguration |
| 年代 | **1714 年** |
| 地点 | 俄罗斯卡累利阿共和国，奥涅加湖基日岛 |
| 坐标 | 62.067, 35.224（近似 · 精确到建筑） |
| 类型 | 教堂 · 木构多层穹顶 |
| 结构 | 木构件咬合，**"不用一钉"说法待核** |
| 状态 | **待核** |

**一句话**：22 个穹顶的木构奇观。

**说明**：建于 1714 年，位于奥涅加湖中的基日岛，教堂顶部有 22 个洋葱形穹顶，由木瓦覆盖，最高处约 37 米。整座建筑以木构件咬合而成，传说不用一钉。1990 年列入世界遗产，与旁边的圣母帡幪教堂、钟楼共同构成基日教堂群。

**图片 01（全景）**：教堂外观，**必须能数出多个穹顶**（这是它唯一的识别特征）。
**图片 02（局部）**：穹顶木瓦细部，或建筑构件的咬合节点。

**采集**：Commons 搜 `Kizhi Transfiguration Church`；UNESCO https://whc.unesco.org/en/list/544/
**⚠️ 待核**："不用一钉"是流传极广的说法。木构建筑内部用木销是常规做法，"完全无金属"需要具体研究支撑。**建议写"以木构件咬合为主"，不写"不用一根钉"**——这与第一幕"保国寺无一根铁钉"的表述是同一类问题，两处都要谨慎。

## 欧洲这一屏怎么讲

> **不要把欧洲木构讲成"另一种斗拱"。**
>
> 正确的讲法是：**同样面对"用木头盖一座大房子"这个问题，不同地方给出了不同答案。**
>
> - 中国：横向出挑——用斗拱把屋檐推出去，保护墙身不受雨淋。
> - 北欧：纵向升腾——用立柱与墙板互扣，把结构往高处做，屋顶层层叠落。
> - 俄罗斯：用木瓦做穹顶，把木构做成多塔聚落。
>
> **共同点**：都在解决"木材怕水"这一个问题，只是解法不同。
> 这一屏的价值不是"中国也有、外国也有"，而是**"为什么长成了不一样"**。
