# 05 · 中国金代木构

> **全国现存：约 113 座**（山西占绝大多数）
> 本目录收 4 座代表。金代建筑上承辽制、下启元风，处于"辽的豪劲"与"元的随意"之间。
> 技术特征：减柱造、移柱造大量使用；补间铺作流行**斜拱**（斜向出跳），与宋式规整的十字交叉形成对比。

| 英文名 | Huayan Temple Mahavira Hall |

| 地点 | 山西省大同市平城区下寺坡街（上寺） |

| 类型 | 殿 · 单檐庑殿顶 |
| 斗拱 | 柱头铺作五铺作 |
| 状态 | 已核 |

**一句话**：中国现存最大的金代木构佛殿。

**说明**：中国现存规模最大的金代木构佛殿，单体建筑面积达 1559 平方米，矗立在 4 米高的台基之上。殿内采用金代典型的减柱造，抽去 12 根内柱以拓展礼佛空间。正脊上 4.5 米高的琉璃鸱吻为国内古建之最，其中北侧一尊仍为金代原物。与薄伽教藏殿同院，可作辽金两代对照。

**图片 01（全景）**：大雄宝殿正面，含 4 米高台基，能体现体量之大。
**图片 02（局部）**：**正脊琉璃鸱吻近景**（4.5 米高，国内古建之最，比斗拱更抓人）。

**采集**：Commons 搜 `Huayan Temple Datong Mahavira Hall`。
**注意**：华严寺上寺（金·大雄宝殿）与下寺（辽·薄伽教藏殿）是两个条目，配图不能混。

| 斗拱 | 柱头铺作与补间铺作 |
| 状态 | 已核 |

**一句话**：金代建筑的代表作。

**图片 01（全景）**：弥陀殿正面。
**图片 02（局部）**：殿内梁架与彩塑，或金代门窗细部。

**采集**：Commons 搜 `Chongfu Temple Shuozhou`。

## jin-03 · 善化寺三圣殿

| 项 | 内容 |
|---|---|
| 英文名 | Shanhua Temple Sansheng Hall |
| 年代 | 金代（12 世纪） |
| 地点 | 山西省大同市平城区南寺街 |
| 坐标 | 40.085, 113.293（近似 · 城区级） |
| 类型 | 殿 · 单檐庑殿顶 |
| 斗拱 | 柱头铺作与补间铺作**出斜拱** |
| 状态 | 已核 |

**一句话**：金代斜拱做法的典型。

**说明**：善化寺中轴线上的第二座大殿，建于金代。殿内采用减柱造，用粗大的内额跨越数间，是金代大木作的典型手法。补间铺作使用斜拱，斜向出跳，是辽金时期北方流行的做法，与宋式规整的十字交叉形成对比。与寺内辽代大雄宝殿同院，可直接对照。

**图片 01（全景）**：三圣殿正面。
**图片 02（局部）**：**补间铺作斜拱近景**——斜拱是本条目唯一不可替代的画面，务必拍到 45° 斜向出跳。

**采集**：Commons 搜 `Shanhua Temple Datong Sansheng`。
**加分提示**：善化寺一院之内有辽构（大雄宝殿）+ 金构（三圣殿），是"一院两代"的绝佳样本，可与佛光寺（唐+金）并列讲。

## 金代最值得做的一屏：斜拱

> 金代补间铺作大量使用**斜拱**——构件以 45°（或 60°）斜向出跳，而不是宋式规整的十字交叉。
> 这是辽金时期北方特有的做法，也是判断"这不是宋代建筑"最快的视觉线索。
>
> 建议做成一张对照图：**宋式十字交叉（保国寺）｜ 金代斜拱（善化寺三圣殿）**，
> 同一角度、同一距离，一眼看出差别。这比讲十句形制术语有效。
