## 三、图片规范

### 3.1 每栋两张，分工固定

| 文件 | 内容 | 用途 |
|---|---|---|
| `01.jpg` | **全景 / 外观** | 列表缩略图、卡片头图、地图弹窗 |
| `02.jpg` | **局部 / 斗拱** | 详情页主图，也是横向对比的素材 |

**为什么要固定这两个槽位**：第二幕最想讲的是"斗拱在一千年里怎么变的"。只有每栋都有"同类型的局部图"，才能做并排对比。如果每栋图内容随意，这个功能就废了。

### 3.2 技术规格

| 项 | 要求 |
|---|---|
| 格式 | JPG（不要 PNG，体积大） |
| 长边 | 1600 px（详情页够用，4K 屏也不糊） |
| 体积 | 单张 < 400 KB，目标 250 KB |
| 比例 | 4:3 或 3:2 均可，**同一朝代内尽量统一** |
| 处理 | 只做等比裁切与轻微调色，**不做变形、不加滤镜、不拼贴** |

### 3.3 登记（每张都要填 `_source.txt`）

```
01.jpg
  来源URL: https://commons.wikimedia.org/wiki/File:XXX.jpg
  作者: 摄影者名 / 上传者名
  许可: CC BY-SA 4.0
  核对结论: 已目视确认是本建筑，非同名建筑，朝代标注正确
```

**缺任何一项，这张图不上屏。**

## 四、许可与署名

| 类型 | 能用吗 | 要求 |
|---|---|---|
| **自拍** | ✅ 最优 | 无需署名，建议仍标拍摄者 |
| **Wikimedia Commons CC BY / CC BY-SA** | ✅ 能 | 图注写「作者 / Wikimedia Commons / 许可」；只做等比裁切，改编后须同协议发布 |
| **博物馆 / 官网图** | ⚠️ 仅内部 | 公开展示前须联系馆方或换源 |
| **学术著作插图**（李乾朗、潘德华等） | ❌ 不能 | 仍在版权期，只能作建模参考 |

**署名写法**（放在详情页图下方 12px 小字）：
```
图片：张三 / Wikimedia Commons / CC BY-SA 4.0
```
> 作者名必须从 Commons 文件页读取，不能省略。

## 五、五个必须守住的编年红线

这些是最容易被专业人士一眼挑出来的错误，**每一条都在对应清单里标了**：

| # | 红线 | 正确写法 |
|---|---|---|
| 1 | **法隆寺 ≠ 607 年建成** | 创建 607，现存为 670 年火灾后重建（7 世纪末—8 世纪初） |
| 2 | **东大寺大佛殿 ≠ 奈良原构** | 现存为 1709 年江户重建 |
| 3 | **太和殿 ≠ 明代原构** | 现存为 1695 年康熙重建 |
| 4 | **保国寺现状重檐 ≠ 宋构原貌** | 宋代原构为单檐，清代加四周下檐 |
| 5 | **飞虹塔 ≠ 木塔** | 广胜寺飞虹塔是明代琉璃塔，不能放进木构条目 |

另外两条口径问题：

- **天台庵**：唐 / 五代有争议，必须双写并标注。
- **"不用一根钉"**：保国寺与基日岛教堂都有这个说法，都属于"流传广但需谨慎"的表述。建议写"以榫卯/木构件咬合为主"。
