# 世界现存木构建筑图册

## 打开网页

从 DOUGONG 项目根目录运行：

```sh
python3 -m http.server 8022 --bind 127.0.0.1
```

在浏览器访问 http://127.0.0.1:8022/web-exhibits/act-02-globe/ 。请通过 HTTP 服务访问，不要双击 HTML 文件；模块和资料加载需要 HTTP。

页面、39 条资料、照片、Three.js 与地理轮廓均来自本地，无外部 CDN 依赖。复制到展览电脑时保留整个 `web-exhibits` 文件夹，或至少保留 `act-02-globe`、`shared/vendor`、`shared/data/land.geojson`；若需返回展览首页，也保留上一级 `index.html`。

## 交互

- 地区：中国、日本、欧洲；平滑旋转并拉近对应区域。
- 中国：全览、唐、五代、辽、宋、金、元、明清。统计来自实际收录数据。
- 光点、展开名称和左侧名录均可打开详情；详情可返回或前后翻阅。
- 鼠标：拖动旋转、滚轮缩放。触摸：单指旋转、双指缩放。按钮最小高度 48px。
- 地图名称通过引线展开，解决同一寺院、奈良等密集点位的选择问题。桌面最多展示 8 个标签，窄屏最多 5 个；完整条目可从名录访问。
- 右上角全屏；地图下方放大、缩小和全球复位；键盘 Tab/Enter 选择，Esc 返回上层。
- 手机竖屏改为地区导航、地球、图文的纵向布局；桌面保留左文、中图、右导航。

## 内容维护

`data.json` 为本幕独立数据，整理自 `assets/buildings/*/清单.md`，未修改其他幕共用的数据。每条记录含资料相对路径、近似坐标说明、核验状态与本地照片路径。数量按条目计，包括个别建筑群，不能当作全国或全球建筑总量。

现有图片来源登记声明仅供内部学习参考；公开发布须替换为有授权的照片。未逐项开展新的史料校核，原有待核、争议说明保留。照片暂用已归档的全景图，不使用尚待复核的局部图。

## 设备验收

推荐使用支持 WebGL 和 Pointer Events 的现代浏览器。西沃平台可在其浏览器中打开本地服务页面并进入全屏。网页已实现标准触控事件，但仍需在目标西沃设备上检查双指缩放、拖动与点击区分，以及系统缩放后的字号。无 WebGL 时保留左侧名录和详情浏览。
