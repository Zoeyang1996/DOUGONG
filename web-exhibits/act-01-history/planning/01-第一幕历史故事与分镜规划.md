# 第一幕：从一处榫卯，读懂保国寺

整理日期：2026-11-11。需求基线：《斗拱11_11网站想法.md》。本稿是联网检索后的内容与资产规划，不改动现有网页。下文的镜头、标题、时长、文案均为策划建议；史实依据另标来源。

## 一、主线与内容容量

保留用户原定六段：榫卯出现 → 工具及建筑的应用 → 斗拱出现与发展 → 不同时代对照 → 常见构件 → 保国寺运用。

一句话主线：从木件怎样相接，走到屋檐怎样被承托，最后让游客认出保国寺眼前的结构。

建议主线体验3—5分钟，每段约25—45秒；热点可选阅读，不阻断滚动。主屏每段1个问题、1段45—70字左右的文字、1次关键交互。时间只是制作目标，需现场观察停留行为后调整。

本幕不增加全球地图、拼装竞速或答题；分别留给第二、三、四幕。六段是同一HTML中的连续故事，不再拆成六个展项。

## 二、历史故事清单与镜头

### 01｜木头怎样握住另一块木头？

- 故事：用河姆渡出土梁头榫作为早期实物证据，再解释凸出的榫与凹入的卯如何配合。
- 史实锚点：国博专题列有河姆渡文化梁头榫及其图片、尺寸、收藏单位。年代按馆方给出的文化范围展示，不给单件擅定精确年代。[S01](https://www.chnmuseum.cn/portals/0/web/zt/202311hmdwh/)
- 主文案草案：木件上的凸起与凹槽，让连接成为可能。河姆渡出土的木构件留下了早期榫卯技术的实物证据。先观察遗物，再看两块示意木件怎样相接。
- 镜头：考古实物照片近景 → 轮廓描线 → 切换为明确标注的原理模型。照片与模型之间不用暗示百分之百复原的无缝变形。
- 交互：滚动推进榫头插入；点“榫”“卯”看名称和连接面。
- 资产：I01、D01、M01、M02；热点H01/H02。
- 边界：不写“河姆渡发明了世界上第一处榫卯”，不把现代矩形榫模型当出土遗物，不引入鲁班发明榫卯的传说作为年代证据。

### 02｜从手中器用，到容身的房屋

- 故事：保留工具线索，同时说明加工工具、工具柄接合、建筑榫卯是不同问题。主视觉由器物连接转入干栏建筑的柱、梁与架空居住面。
- 史实锚点：国博专题展示骨耜及干栏建筑的考古背景；科学出版社《中国科学技术史·图录卷》对石锛的木柄绑扎有说明。湖北省博物馆的曾侯乙墓漆器研究可支撑后续器物中榫卯连接的扩展阅读。[S01](https://www.chnmuseum.cn/portals/0/web/zt/202311hmdwh/)、[S02](https://www.ecsponline.com/yz/BC031BE412E664B39B9DA4713389AAE82000.pdf)、[S03](https://www.hbww.org.cn/hhfz70n/p/9135.html)
- 主文案草案：器具和房屋都需要连接不同的材料。工具上的绑扎、插接，与房屋中的榫卯各有做法。把视线移向干栏建筑，看看柱、梁和地板怎样共同组成居住空间。
- 镜头：工具/器柄照片小卡 → 木材加工动作示意 → 一处建筑接点 → 拉远至简化干栏框架。工具与建筑并列，不画未经证实的“先工具、后房屋”发明箭头。
- 交互：点建筑接点，显示柱、梁、地板；工具接合方式用一张可展开图解释。
- 资产：I02/I03、D02、M03；热点H03/H04。
- 边界：骨耜有孔不等于已证明其为纯榫卯接合；石锛不是榫卯模型。干栏模型标“结构示意”，取得发掘平剖面前不声称精准复原某座房屋。

### 03｜屋檐下面，为什么多出一组木件？

- 故事：从柱与屋檐的关系引出斗拱，再用东汉陶楼上的斗拱形象说明早期可见证据。
- 史实锚点：河南博物院《绿釉三层陶楼》明确标东汉，并描述楼上斗拱；故宫词条解释斗栱的承托构成。[S04](https://www.chnmus.net/sitesources/hnsbwy/page_pc/dzjp/zpjc/tq/article7b37de012be44686ac39588368ed3dd8.html)、[S05](https://www.dpm.org.cn/lemmas/241374.html)
- 主文案草案：视线来到柱头与屋檐之间。东汉陶楼上，已经能看到斗拱的形象。层层相接的斗与栱，参与承托屋檐，也让木构建筑形成独特的轮廓。
- 镜头：陶楼整体 → 放大可辨斗拱局部 → 转至抽象柱头节点 → 显示向外承托与相接关系。
- 交互：拖动小范围滑杆展开节点；高亮接触面。箭头只表示结构关系，不显示未经计算的受力百分比。
- 资产：I04、D03、M04；热点H05/H06。
- 边界：陶楼是陶制明器，不能说是留存的汉代木楼；其形象能证明可见形式，不能独自确定隐藏榫口。原理模型不标“东汉斗拱精确复原”。不把斗拱第一次出现定在汉代。

### 04｜不同年代，斗拱怎样变了？

- 故事：只选三座具体建筑，比较同类部位；用《营造法式》补充宋代营造知识的系统记录。
- 对照对象：唐·佛光寺东大殿（857） → 北宋·保国寺大殿（1013） → 清·太和殿现存康熙重建形制。太和殿的1695年重建起点与1697年完工分开记录。[S06](https://www.dpm.org.cn/Uploads/pdf/5075/T00028_00.pdf)、[S08](https://html.rhhz.net/linyekexue/html/20110421.htm)、[S09](https://www.dpm.org.cn/explore/building/236465.html)、[S10](https://www.dpm.org.cn/building/talk/223525.html)
- 主文案草案：把三个时代的实例放在一起，观察出挑、构件组织和檐下排列。再翻开《营造法式》，看看宋代如何记录营造制度。每座建筑都保有自己的特点，也留下历次修缮的痕迹。
- 镜头：同一相机方向，切换三个柱头局部；一键切到一间檐下的概况图，比较排列。书页只在宋代节点展开。
- 交互：唐／宋／清三个按钮。比较轮廓时可统一显示大小，但必须标“轮廓对照、非同比例”；比较尺寸时使用同一比例尺与完整测绘数据。
- 资产：I05/I06/I07/I08、D04、M05/M06/M07；热点H07/H08。
- 边界：三个实例不是三个时代全部建筑的标准答案；不写唐一定粗大、宋一定复杂、清只剩装饰。宋式“材分”与清式“斗口”不混成同一单位。第一版不另做五代、辽金、元、明四套模型。

### 05｜把一朵斗拱，认成几个名字

- 故事：从历史观察转到结构识读。用上一段的保国寺铺作，避免重新引入陌生模型。
- 内容层级：主层只认“斗、栱、昂”三类；点开具体部件后再出现栌斗、华栱、泥道栱等经该实例核实的名称。枋作为与斗拱相接的构件单独说明，不把所有横木都叫栱。
- 主文案草案：一组斗拱，由不同形状、不同位置的木件配合组成。点亮一件，再看它接住哪一件。先认清斗、栱与昂，名字就能和真实的位置对应起来。
- 镜头：保国寺选定铺作缓慢展开 → 选择某件，其余淡化 → 显示相接面 → 收回整体。
- 交互：点构件，显示名称、位置、作用三项；不要求游客逐件背完，不加入竞速考核。
- 资产：D05、复用M06；热点H09/H10。
- 依据及边界：清式词条只作术语对照，不能用清式昂的比例直接建宋式下昂；具体构件清单须回查《营造法式》与保国寺测绘。当前网页草模的对象名称不是学术核验结果。[S07](https://www.dpm.org.cn/ancient/mingqing/149329.html)、[S11](https://www.dpm.org.cn/lemmas/241883.html)、[S12](https://ria.seu.edu.cn/24655/list.htm)

### 06｜回到1013年，抬头看保国寺

- 故事：从选定铺作退回大殿，以真实照片帮助游客现场定位；说明这座建筑与后世典籍的研究关联。
- 核心锚点：1013年建成的大殿早于1103年刊行的《营造法式》。相差90年可作时间轴提示；先后关系不能证明李诫直接取法此殿。[S08](https://html.rhhz.net/linyekexue/html/20110421.htm)、[S07](https://www.dpm.org.cn/ancient/mingqing/149329.html)
- 主文案草案：现在，把这组木件放回保国寺大殿。大殿建于1013年，比《营造法式》刊行早90年。沿着柱头向上寻找，你刚认识的名字，就藏在眼前的结构之中。
- 镜头：单组铺作 → 柱头定位 → 大殿局部空间 → 同角度实景图。清代增建与宋代核心分层标识，现状照片不冒充1013年外观。
- 交互：主任务只有“找到刚刚认识的铺作”；附加两个自选热点“瓜棱柱怎样拼合”“藻井怎样组织”。退出热点回到原镜头。
- 资产：I09/I10，I11/I12可选；D06、M06/M08；热点H11/H12。
- 边界：不把防震、无虫、无尘解释成斗拱的单一效果。2011年研究区分了整木、拼合与包镶柱，并提出拼合/包镶涉及后期维修的判断；展陈复制模型与现存柱检测结论要分层表述，不把四柱的内部每个节点直接标为1013年原构。[S08](https://html.rhhz.net/linyekexue/html/20110421.htm)

## 三、滚动中的六句转场文案

1. 让两块木头，先相遇。
2. 把一处连接，放进生活。
3. 镜头向上，来到屋檐之下。
4. 换一个时代，再看这组木件。
5. 看见形状，也认识名字。
6. 最后，回到你眼前的保国寺。

以上为原创界面文案，不是古籍引文；正式文字在资产核定后再按画面修订。

## 五、第一版收束原则

保留工具与建筑应用，但不扩写家具通史；保留历史变化，但先比较三个具体实例；保留部件认识，但先认三类；保留保国寺的特色，但主线聚焦一组铺作。材料不足的内容以照片、线图和明确标注的原理示意呈现，待有尺寸与构造依据再制作实物复原模型。
