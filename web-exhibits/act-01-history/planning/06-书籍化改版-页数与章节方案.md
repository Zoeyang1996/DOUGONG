## 一、先给结论

| 项 | 结论 |
|---|---|
| **章节** | **六卷**（与现有 G1—G6 六段一一对应）＋ 序、尾声、附录 |
| **跨页** | **20 个跨页 = 40 页**（含封面、封底） |
| **其中必做** | **17 个跨页**（34 页）；另 3 个跨页为可选加页 |
| **每页字数** | 正文 130—170 字；夹注 40—60 字 |
| **开本** | 整书 4:3 居中（每页 2:3），两侧留桌面与书签 |
| **文字方向** | 右页竖排、自右向左；提供"横排"切换开关 |
| **三维** | 全书只保留 **2 处**真 3D，其余用已有渲染图与线稿 |

**为什么是六卷而不是五卷**：现有脚本就是 G1—G6 六段，11 组模型也按这六段建的（加五种单一部件）。按六卷切，模型、文案、图版全部平移，不用重写；若合成五卷，卷四要把唐、宋、清与保国寺压在一起，反而要重编。

## 二、一本书的骨架

```
封面（单页，居中，点击开启）
└ 扉页 + 环衬
   └ 目次（右侧竖排书签，可点跳）
      └ 序
         ├ 卷一 接 · 榫卯初见        2 跨页
         ├ 卷二 用 · 从节点到房屋     2 跨页
         ├ 卷三 起 · 柱头上的木件     2 跨页
         ├ 卷四 变 · 三个时代         4 跨页（含 1 页对照）
         ├ 卷五 名 · 斗、栱、昂       2 跨页
         └ 卷六 归 · 保国寺           3 跨页（其中 2 页可选）
      └ 尾声
         └ 附录 · 材料与核验
            └ 封底
```

页数分配的逻辑：**一卷两跨页**是下限——一个概念要"看见一次"（左页图）＋"说清一次"（右页文）；只给一页会挤，给三页会拖。卷四必须四页，因为唐、宋、清各要一页，再加一页把三者并排对照，那一页是整幕的高潮。

## 四、左右两页各放什么

### 左页（图）：三种版式，不混用

| 版式 | 用在哪 | 规格 |
|---|---|---|
| **整幅图版** | 序、卷六、尾声 | 出血到版心边，四周留天头地脚，右下角压图版号「图三」 |
| **分解图** | 卷一、卷三、卷五 | 米色底 + 朱色引线 + 竖排小字标注，像考古报告的插图页 |
| **多图并置** | 卷四对照、卷二 | 2—4 张同尺寸并排，间距等于版心界行宽 |

**只有 2 处放真 3D**：S4（榫头推入卯口）与 S14（三类部件可转）。理由：翻页时 WebGL 与页面动画抢帧，西沃一体机容易掉帧；其余用 1024² 渲染图加线稿，观感不差，性能稳得多。

### 右页（文）：古籍版式

| 元素 | 做法 |
|---|---|
| 版框 | 四周双边框，外粗内细，内框 1px 墨色 |
| 界行 | 竖排 9 行，行间细线，行距 = 版心宽 ÷ 9 |
| 字体 | 正文宋体（SimSun / 宋体-简），字号按屏幕折算约 19—21px；标题用楷体或黑体 |
| 竖排 | `writing-mode: vertical-rl`，自右向左；阿拉伯数字用 `text-combine-upright` 直立 |
| 夹注 | 双行小字（字号 0.6 倍），放在对应词句右侧，承载考据、出处、「待核」提示 |
| 鱼尾 | 版心中缝下缘一枚鱼尾，上方写卷名，下方写「卷一 · 三」式页码 |
| 朱印 | 每卷首页右下一枚小印，印文即卷名（接／用／起／变／名／归） |

**正文写法**：一页一段，一段一义。开头不用「首先」，结尾不写「综上所述」；年代用中文（唐大中十一年），关键数字用阿拉伯数字但不超过三处。

## 五、内容怎么整理（从现有六段改成 20 页）

现有 6 段脚本每段 90—150 字，20 跨页需要约 20 × 150 = 3000 字正文 + 20 × 50 = 1000 字夹注。做法是**拆而不是写**：

1. **先分句**：把每段脚本按句拆开，一句一个意思。
2. **一页一句为主**：右页以其中一句立骨，其余作支撑。例：G5 那段拆成「七铺作双杪双下昂」「一朵斗拱二十种」「比《营造法式》早九十年」三块，分别落到 S11、S15 夹注、S18。
3. **考据降为夹注**：原「边界」条款（不写河姆渡发明榫卯、陶楼不是木楼、太和殿是康熙重建）全部改成夹注小字，既守住严谨，又不打断正文。
4. **12 个热点改旁批**：原 H01—H12 十二个弹窗，压缩成 **6 条旁批**（页边小字，一句一问）＋ **6 个可点处**（图上点击出释名）。弹窗在书里会破坏"读"的动作，旁批不会。
5. **每卷一句题记**：接／用／起／变／名／归，各配一句十字以内的题记，放在卷首页右上。

## 六、翻页交互（必须提前定的三件事）

1. **翻页手势**：拖拽页角超过页宽 28% 松手即翻，否则回弹；点击左右各 12% 区域翻页；键盘 ←/→、Home/Esc；目录书签直接跳卷。
2. **3D 与翻页抢手势**：左页 3D 区域内，单指拖动优先给 3D；只有从版心外侧 48px 起手，才判为翻页。这一条不定清楚，现场一定出现"想转模型结果翻页了"。
3. **动画选型**：用 CSS 3D 折页（`transform: rotateY` + 渐变阴影），不做真实纸张卷曲。卷曲要 WebGL 或 canvas 逐像素变形，在西沃上很难稳 60fps；折页在触屏上已经足够"像书"。

## 八、三处需要你拍板

1. **竖排还是横排**：竖排最像古籍，但长段落在触屏上阅读效率低。我的建议是**默认竖排 + 右上角一个「横排」开关**，两套版式共用同一份文字。
2. **封面要不要做成"合着的书"**：合着时只见封面，点击才展开成全屏跨页。体验更像书，但多一层状态；不做则一进来就是摊开的跨页。
3. **卷四是否把"保国寺"提前**：现在 S11 已用保国寺作宋代实例，卷六再回来深讲。若怕重复，可把 S11 换成晋祠圣母殿，把保国寺完全留给卷六。
