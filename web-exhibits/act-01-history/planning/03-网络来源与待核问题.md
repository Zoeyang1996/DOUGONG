## 必须提前解决的史实问题

| 问题 | 这版的处理 |
|---|---|
| 榫卯究竟何时、何地首次发明？ | 不在主线作唯一发明归属；从河姆渡可见实物证据讲起 |
| 具体梁头榫是否能写“7000年前”并精确复原？ | 用馆方给出的文化年代范围；单件形制的隐蔽面待多视角资料 |
| 工具是否都用榫卯？ | 区分绑扎、插接、榫卯及加工工具；按具体器物举例 |
| 汉代陶楼是否就是当时木楼的完整实录？ | 作为形象证据；不据此确定全部隐藏构造或宣布斗拱发明年代 |
| 唐、宋、清对照是否能归纳成线性进步？ | 不做“越来越先进/越来越装饰”的结论；讲实例差别 |
| 保国寺是否按《营造法式》建造？ | 1013早于1103；谈研究对照，不写照书施工，也不推断编书直接取样 |
| 保国寺现存外观是否等于1013原貌？ | 区分宋代核心、后期增建/修缮与今天可见形态 |
| 瓜棱柱是否全是四根圆木拼合？ | S08给出多种构造；四根主要拼合柱与其他柱分别讨论 |
| 四拼柱是否可直接定为宋代原作？ | 复制模型展签与检测论文的修缮判断分别记录，待结合更完整研究核定 |
| 论文单位和网页识别是否可直接录进模型？ | 不可。S08网页部分柱径单位与上下文尺度不协调，先对原刊及测绘书；不自动纠正后当确定值 |
| 宣传中的无尘、无虫是否能作结构结论？ | 不放入本幕主线，不用气流或木材传说替代证据 |
| 清式“昂”的词条是否可直接给宋式模型命名和定尺？ | 不可；分别标明语境，用测绘与宋式原典复核 |

## 图片与模型的来源管理

表内网页图和论文图目前作为资料来源候选。是否可用于景区公开屏幕，需逐项确认图片或扫描件的使用条件。用户已提供的网络转载图仍登记原作者；现场自拍可优先选用。自行画图或建模也应记录参考依据，不把照搬现代测绘图误称完全无来源的原创。

不以短视频和营销文案作为结构定型依据；不下载不明来源的付费书籍扫描本。本轮没有采购书籍、联系机构或发布素材。
