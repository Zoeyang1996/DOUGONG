# 第一幕改版说明（古籍书版）

## 一、这一版改了什么

上一版是"滚动装配"式的长页面，这一版按你提出的概念，改成**一本全屏可翻阅的中式古籍**：

1. **全书即书**：整页只有一本书，没有网页导航条。宽屏摊开两页（右页先读、左页后读），
   窄屏（≤900px）自动切成单页，一页一页翻。
2. **右起竖排**：`writing-mode: vertical-rl`，字竖排、行从右往左。每页为：
   版框（双线）→ 版心（卷次 / 鱼尾 / 页码，永远朝中缝）→ 书耳（左缘互动入口）。
3. **按章节分页**：五卷 + 序 + 尾 + 附，共 41 页 / 21 跨页；一页装不下就另起一页
   （如卷三：题记 → 图版 → 定义 → 六构件 → 宋清对照 → 数斗拱 → 受力 → 拆解，共 8 页）。
4. **每页左边都有互动区**（书耳）：`目`（目录，可跳转）、`器`（本页对应的三维）、
   `注`（夹注与依据）。悬停显示竖排标签。
5. **点图立起三维**：
   - 四种榫卯（直榫 / 燕尾榫 / 企口榫 / 馒头榫）程序化建模，滑杆演示榫头推入；
   - 一朵斗拱载入保国寺柱头铺作草模：拖动旋转、双指缩放、按类隔离
     （斗 / 拱 / 昂 / 翘 / 耍头 / 枋）、滑杆拆解、点选显示宋式构件名。
6. **走向世界**：卷五有两页地图——"东亚木构圈"与"四条路"。九个地名可点，
   点开出现图文卡（年代、说明、考据细节、站内链接）。
7. **趣味科普**：四问四答"数一朵斗拱"、可拖动檐口、可切换时代对照、
   图版索引可点击回跳。

## 二、技术要点

- 翻页引擎 `js/book.js`：叶片 `rotateY` 绕书脊旋转，拖拽掀页（超过 1/3 落页），
  键盘 ←/→、滚轮、左右边缘热区都能翻。
- 竖排自适应 `fitText`：竖排的 `scrollWidth` 是所有列的总宽，超了就是被裁掉；
  逐级缩小字号直到装进版框，换视口会重新拟合。
- 三维只保留一个 WebGL 上下文：浮层打开时创建，关闭即 `dispose`。
- 地图用 `shared/data/land.geojson`，等距圆柱投影，按**整环外接框**判交
  （否则中国大陆这种首点在视野外的环会被整块丢掉）。
