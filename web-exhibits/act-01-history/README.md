# 第一幕 · 木构之间（可翻阅的竖排古籍）

一本书：全屏可翻阅的中式古籍，文字自右向左、从上往下。
翻页即翻纸：书页从左掀起，越过书脊落到右半边。宽屏一次摊开两页，
窄屏（≤900px）自动切成单页模式，一次只摊一页。共 **21 跨页 / 41 页**。

打开方式：在项目根目录运行 `node web-exhibits/tools/serve.cjs`，
再访问 `http://127.0.0.1:4173/act-01-history/`。
（需 http 环境：三维模型、地图数据用 `fetch` 加载。）

---

## 一、怎么翻、怎么读

| 操作 | 结果 |
| --- | --- |
| 点封面 / 点屏幕左边缘 / 按 `←` `空格` `PageDown` | 往前翻一页 |
| 点屏幕右边缘 / 按 `→` `PageUp` | 往回翻一页 |
| 在左页外口往右拖 | 手动掀页，松手超过 1/3 才落页 |
| 滚轮上下 | 翻页 |
| 点每页最左侧的书耳（圆形小章） | 打开目次 / 三维 / 夹注 与 依据 |

版式细节：版框双线、版心窄栏（卷次 + 鱼尾 + 页码）、书耳贴外口、
文字右起竖排、夹注小字随行。竖排版面有自适应：
若整段列数超出可用宽度会逐级缩字，绝不裁切（`fitText`）。

## 二、页面结构（content.js 一处改全书）

`js/content.js` 导出 `PAGES`，数组顺序即书页顺序：

- `cover` 封面
- `contents` 目次（可点跳转）
- `text` 竖排正文页（标题 + 正文 + 夹注 + 依据）
- `chapter` 卷首（卷次、卷名、题记、封面线稿）
- `plate` 图版（图片 + 可点热区）
- `figure` 自绘线稿页（河姆渡、三力、三台阶、出檐、四段、同比例、此消彼长、当代三帧）
- `model-grid` 四种榫卯（点格子立起三维）
- `parts` 六构件（斗·拱·昂·翘·耍头·枋，点字立起三维）
- `quiz` 四步读出一朵斗拱的全名（可进三维）
- `table` 朝代表
- `compare` / `bar` 可切换的比例对照与趋势条
- `map` / `routes` 东亚木构圈地图（点地名出图文卡）
- `explode` 拆解页（滑杆 + 三维）
- `index` 图版索引

## 三、跳出书页的三维

`js/gl.js` 提供展台：一次只跑一个 WebGL 上下文，关掉浮层即释放。
`js/mortise.js` 四类榫卯为程序化建模（直榫 / 燕尾榫 / 企口榫 / 馒头榫），
可拖滑杆看榫头推入；`js/dougong.js` 加载保国寺柱头铺作草模
（`../shared/models/baoguosi-bracket.glb`），支持：

- 拖动旋转、双指缩放、复位视角
- 构件分类隔离：整朵 / 斗 / 拱 / 昂 / 翘 / 耍头 / 枋
- 滑杆拆解：构件沿自身方向退开
- 点选识别：射线拾取，显示构件中文名（宋式命名）
- 说明栏按页给出读法与口径（形制草模、尺寸待核）

## 四、东亚地图

`js/map.js` 取 `../shared/data/land.geojson` 的海岸线，
按等距圆柱投影绘制，裁到东亚范围（lon 103–146 / lat 10–46）。
九个节点：宁波、五台山、奈良、镰仓、庆州·安东、汉城、首里、顺化、上海。
点节点 → 下方图文卡（名称、年代、说明、考据细节、站内链接）。
`routes` 页额外画出四条传播路线。

## 六、素材与口径

- 文字依据见各页「注 · 夹注与依据」，争议处并置两说（如天台庵唐/五代、
  唐构 4 座与「唐 3 座、五代 5 座」两种口径）。
- 三维为形制草模，只说明原理，不作测绘依据。
- 地图为示意投影，不用于定位。
- 「宁波工匠赴日」等未获可靠出处者，书中明确标注不作事实使用。
