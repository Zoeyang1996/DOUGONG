# 木构之间 · 四幕独立互动项目

本地项目，需求来自用户《斗拱11_11网站想法.md》。当前交付为正式开发前的框架、视觉交互 demo 与素材准备。没有发布网站，没有改动旧项目和用户原稿。

## 打开方式

在此目录运行 `node tools/serve.cjs`，浏览器打开 http://127.0.0.1:4173 。也可在此目录用 Python 启动静态服务器。请通过本地服务访问，浏览器直接双击 HTML 可能无法加载三维模型。

- 总入口：`index.html`
- 第一幕：`act-01-history/index.html`，六段滚动叙事和构件点击说明。
- 第二幕：`act-02-globe/index.html`，三维地球、国家聚焦、朝代筛选、样本统计、建筑详情。
- 第三幕：`act-03-assembly/index.html`，姓名、每日两次、60/30/20秒、三维构件拖拽和旋转。
- 第四幕：`act-04-quiz/index.html`，只保留入口；`questions.json` 为空数组。

每幕有独立 HTML 入口，模型与依赖位于 `shared`。复制或部署时应一起保留，尚非内嵌所有资源的单文件 HTML。

## 查看制作依据

- `00-planning/项目规划.md`：需求对应、阶段和操作规则。
- `00-planning/素材与模型台账.md`：已有模型、待建模型、资料缺口和授权状态。
- 每幕的 `框架与风格.md`：开始正式制作前的框架与视觉方向。
- `blender/`：本次源模型；`shared/models/`：网页 GLB 模型。
- `previews/`：实际浏览器截图；`00-planning/验证记录.md`：演示验证结果。
