## 离线包支持三维（11-16 晚）
- 结论：只把 GLB 拷进去不行（file:// 禁止 fetch 本地文件），但**可以做到双击看三维**。
- 做法：①GLB→base64→普通 .js（`window.__MODEL_B64[id]`），用 `<script src>` 按需注入后 `loader.parse(arrayBuffer)`（脚本加载不受 file:// 限制，被禁的是 fetch/XHR/模块导入）；②draco_wasm_wrapper.js + draco_decoder.wasm 的 base64 内联进 HTML 给 `window.__DRACO_LIB`，把 `DRACOLoader._loadLibrary` 换成内存返回，解码器跑 `new Worker(blobURL)`（file:// 下可用）。
- viewer.js 加 `OFFLINE = location.protocol === 'file:'` 分支，http 下仍走 loadAsync，线上线下同一份代码。
- 新增 `web-exhibits/tools/build_offline.py`：一条命令重建（镜像→改 fetch 为 import→esbuild→GLB 转 b64→内联→组装），输出 `~/Downloads/木构星图-离线版`（63MB：html 1.5MB + 照片 30MB + models-js 31MB）。
- 实测：佛光寺/太和殿/法隆寺/乌尔内斯均正常出图；太和殿（330 万面、9.3MB b64）点击到出图 1.2 秒；拖拽旋转正常。线上版回归通过（viewer 走 fetch 分支）。
- 旧包里 assets/models/*.glb 与 vendor/draco 已删（不再需要），包体 56MB→63MB 但多了三维。
- 文档：docs/04-记录/04-发布与离线包.md 第三节重写；使用说明.txt 重写。
