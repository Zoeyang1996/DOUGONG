# 2026-11-09

## 建立 research 资料体系（保国寺斗拱数智科普项目）

**背景**：项目来自《人工智能赛道+数字媒体技术.docx》——省职业院校技能大赛培育项目申报书，项目名"榫卯智言——基于AI的保国寺古建斗拱数智科普交互系统"，负责人谭恒松，2027 年冲省赛银奖以上。团队为学生 4 人（谢欣怡、唐晶钰、应昕彤、庄可欣，数媒大二）。

**产出**：`research/` 下 14 份 Markdown，6 个子目录：
- `01-对象本体/` 保国寺历史价值、结构与斗拱形制（含建模尺寸底稿）
- `02-斗拱知识库/` 术语体系、铺作读法、三阶段演变
- `03-产品设计/` 产品定位与差异化、交互形式选型、展陈触屏规范
- `04-技术实现/` three.js 可跑骨架、模型资产管线、vibe coding prompt 库
- `05-对标案例/` 案例库
- `06-素材与来源/` 信息源与版权

**关键结论（后续工作要一直记着）**：
1. 保国寺现场**已有 AR 触屏"拆装斗拱"** + 沉浸式影厅 + 国家专利斗拱教具 + 研学小程序。差异化是生死线，不能做"再拆一遍"。
2. 差异化方向定为：**受力可视化（力流/杠杆）+ 20 种斗拱横向比较 + "为什么是保国寺"的地理气候推理 + AI 按身份改写讲解 + 四步"读斗拱"闯关**。
3. 产品形态：主线触屏 three.js 单页（离线可跑、原生 three.js、不上 React），支线 5 分钟 VR 高光片段，共用一套 GLB 资产。
4. 精确数据：面阔 11.91m / 进深 13.36m（进深>面阔）；16 根瓜棱柱；斗拱 20 种（外檐 7 全为七铺作双杪双下昂、内檐 7、天花 3）；近 3000 构件、1504 个斗、673 根栱；斗拱材断面 3:2。
5. 建模取舍：**只精做一朵前檐柱头铺作**（约 40—60 件），全殿只做低模背景。80% 预算压在那一朵上。

**技术栈已定**：Vite + 原生 three.js + GLB/Draco + 本地化资源 + Service Worker。禁止 CDN 依赖（展厅断网）。

**待办**：实地调研（申报书已列 500 元差旅）；需查找张十庆《宁波保国寺大殿》(2012) 与郭黛姮《东来第一山》(2003) 两本书；20 种斗拱逐一清单公开资料缺失，需现场或原书补。
