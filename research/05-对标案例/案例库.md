## 一、国内标杆

### 1. ZP-historicBuilding（中国古建筑三维拆解科普站）⭐ 最直接可参考
- **技术**：React 19 + TypeScript + Vite + three.js + React Three Fiber + drei + React Router
- **模型**：万法归一殿，源模型 236 MB → 用 glTF-Transform（Draco + WebP + Simplify）压到 20 MB
- **交互**：两阶段爆炸——0—45% 按模块径向散开（台基、柱网、梁架、斗栱），45—100% 收拢为平面「构件清单」布局；左侧点选模块读科普，或直接点 3D 模型；底部滑杆控制爆炸程度；「复位/分离/清单」快捷按钮
- **在线**：https://zybkpro.github.io/ZP-historicBuilding/
- **仓库**：https://github.com/zybkpro/ZP-historicBuilding
- ✅ **可借**：两阶段爆炸节奏、模块文案与 3D 分离（`data/parts.ts` + `data/partGuides.ts`）、滑杆控制爆炸程度、模型压缩流水线
- ❌ **不能照抄**：它是"一栋房子分模块"，我们是"一朵斗拱拆到零件"，且它是通用古建，无保国寺专属性

### 2. 北邮「拾光筑梦」——手势隔空搭斗拱
- **技术**：MediaPipe 自研手势算法 + three.js，浏览器内实时手势识别，无需穿戴设备
- **定位**：文化遗产数字化传承，解决斗拱传承手段单一、公众认知度低
- **交互**：摄像头 + 双手，隔空抓取、旋转、拼接虚拟斗拱构件
- **创新表述**：技术集成创新（手势+3D 渲染）、应用模式创新（纯 Web 平衡深度与普及）、文化表达创新（复杂知识解构为游戏化流程）
- ✅ **可借**：把"知识解构为游戏化流程"的说法框架；"无穿戴沉浸"的表述
- ❌ **不能照抄**：手势识别在展厅强光/多人环境下极不稳定，且观众不会用。**触屏比手势可靠 10 倍。**

### 3. 同济大学虚拟仿真实验「基于虚拟现实技术的传统木构认知与建造」⭐ 学术深度的天花板
- **方法**：三维激光扫描 → 点云 → 数字化模型 → Microsoft Access 构件数据库
- **最精彩的设计**：构件定位不用 XYZ 坐标，而用传统术语——**"缝"（柱子行列轴线）、"间"（东西向）、"进"（前后向）**，并设"补间"细分。保国寺大殿北宋时"三间三进"，有四根柱"缝"
- **成果**：可逐一显示大殿每一个构件
- ✅ **可借**：**"缝/间/进"定位法**——这是把传统知识变成交互导航的绝妙思路，强烈建议做成"按缝看斗拱"的浏览模式
- ❌ **不能照抄**：它是教学实验平台，无展陈化设计，无科普叙事

### 4. 保国寺馆方自有数字资产 ⚠️ 最重要的一条
- AR 触摸屏：可在大殿前"亲手拆解、组装"斗拱、拼合柱模型
- 沉浸式影厅：3D 动画再现 1013 年营造过程
- 获国家专利的斗拱 / 北宋大殿模型教具（含 1:20 大殿可搭模型）
- 微信公众号「研学小程序」、《发现保国寺》《印象保国寺》《匠·小小工匠》系列视频
- 原创 IP 卡通形象「阿符」+ 近百款文创
- 荣誉：全国中小学生研学实践教育基地（宁波唯一入选的博物馆，获教育部专项奖励）
- ✅ **可借**：IP「阿符」可考虑联动；研学课程体系（六大主题、三十余门）是我们的内容需求来源
- ❌ **必须避开**："再做一个拆装斗拱"

### 5. 应县木塔 3D 还原（AI 生成案例，技术参考）
- **提示词结构值得抄**：建筑结构（真实形制）→ 技术实现（three.js + importmap + OrbitControls）→ 视觉风格（木色区分构件）→ 交互（点击高亮、拆解按钮、悬停高亮、移动端适配）→ 输出（单文件 HTML、60fps）
- **现实反馈**：需 2—3 轮迭代；源码约 4000 行；普通笔记本 55—60fps
- ✅ **可借**：**提示词五段式结构**（见下）
- ❌ **不能照抄**：AI 一次生成的斗拱"形似神不似"，榫卯关系基本是错的

**AI 提示词五段式模板**（可直接用于 vibe coding）
```
1. 建筑结构：基于真实历史结构（平面/层数/构件/比例/侧脚等）
2. 技术实现：three.js CDN importmap + OrbitControls + 点击拾取
3. 视觉风格：材质色、光源、氛围、构件区分方式
4. 交互：拆解按钮、悬停高亮、触屏适配、爆炸程度滑杆
5. 输出格式：单文件 HTML / 兼容浏览器 / 帧率目标 / 加载性能
```

## 三、行业数据（写申报书背景用）

- 配备基础互动装置的展厅，平均用户停留时长 **8.7 分钟**，比传统静态展陈高 **62%**
- 大脑处理图像信息的速度比文字快 **6 万倍**；加入动态元素后，信息记忆周期可延长至 **72 小时以上**
- 全国重点文物保护单位 5058 处中，约 **三分之一**是古建筑
- 第三次全国文物普查：我国现有不可移动文物逾 **76.67 万处**，古建筑占比较高
- 保国寺自 2018 年以来接待中小学生研学团队超 **100 万人次**

## 五、创新点表述（答辩口径，三条）

1. **内容创新**：从"形制展示"转向"受力解释"——首次用可视化受力流线 + 杠杆交互讲清保国寺七铺作双杪双下昂"以昂为斜梁"的结构巧思。
2. **方法创新**：知识库与模型同源（`parts.js` 既是渲染索引也是 AI 检索语料），保证"AI 讲的每一句都能在模型上指出来"。
3. **应用创新**：一套资产、两种终端（触屏 + VR 片段）、零硬件增量的部署路径，适配研学与场馆双场景。
