【结构】
01 你伸手抽掉最底下那块小方木——整朵斗拱会怎样？ A 纹丝不动 / B 哗啦散架 / C 只响一声 → B 它叫“栌斗”，整朵斗拱的底座；上 面几十块木头的重量，最后都从它这里落进柱头。 动画：木块抽离 → 构件自下而上依次错位、坠落 → 屋顶局部下凹 

02 你攥住那根斜插的、尖头朝下的木头往外拔——屋檐会？ A 耷拉下来 / B 翘得更高 / C 毫无变化 → A 它叫“昂”，是一根杠杆：昂尾被屋顶压住，昂头挑起檐口。拔掉它，檐口就失去托举。 动画：昂被缓缓抽出 → 檐角像泄了气一样下垂 

03 把这朵斗拱拆成一堆木块，还能原样装回去吗？ A 装不回去 / B 得靠胶水 / C 能，榫卯对位 → C 全殿不用一根钉，全靠榫卯咬合；构件按“材份”预制，拆得开也装得回。 动画：爆炸视图 → 每块木料浮起、编号 → 倒放归位，“咔哒”合拢。

04 斗拱向外挑出的“跳头”上空着一块，是偷工减料吗？ A 宋初的讲究 / B 偷工减料 / C 被人偷走了 → A 这叫“偷心造”：跳头不装横栱，省料、减重，还让斗拱看着空灵；

05 假如把整朵斗拱换成一块实心大木头，会更结实吗？ A 更结实 / B 没差别 / C 反而更脆 → C 实心大木又重又容易开裂，地震时只能硬碰硬；一层层叠起来的斗拱能错动、能摩擦，把地震力“磨”掉。 动画：左右分屏震动测试：实心块“咔嚓”开裂，斗拱摇晃几下站稳。

【地震、台风、暴雨】
06 撤掉大殿里的一根内柱，屋顶会立刻塌吗？ A 立刻塌 / B 不会，但会下沉 / C 完全没事 → B 梁架把荷载分给相邻的柱子，一时塌不了；但大梁会明显下弯，斗拱跟着错位，这就是框架的“冗余”。 动画：柱子抽走 → 大梁缓缓下弯 → 力流重新分配到相邻的柱子 

07 把四面墙全推倒，屋顶还站得住吗？ A 站得住 / B 跟着塌 / C 看天气 → A “墙倒屋不塌”：墙只负责围合，不承重；重量全由柱、梁、斗拱扛着。 动画：墙体像纸片一样消失，只剩骨架；一阵风吹过，骨架微晃，屋顶安然无恙。

08 地震来了，这座大殿是“硬扛”还是“跟着晃”？ A 硬扛 / B 先晃后塌 / C 跟着晃 → C 斗拱和榫卯都是柔性节点，地震时整座殿像弹簧一样晃，靠构件之间的摩擦把能量耗掉。千年不倒，靠的不是硬。 动画：地震波扫过 → 大殿左右摇摆 

09 台风正面吹来，屋顶会被掀翻吗？ A 被掀飞 / B 越吹越紧 / C 瓦全飞 → B 屋顶自重把层层构件压得更紧，榫卯又咬住不让上拔；有研究认为凹曲的屋面还会把风变成向下的压力。 动画：狂风箭头撞上屋面 →  斗拱被压得更密实 → 屋顶纹丝不动。

10 暴雨天墙脚会湿吗？ A 基本不湿 / B 湿透 / C 看风向 → A 出檐深远，檐口把雨水甩到台基外；斗拱一层层向外跳，就是为了把屋檐的雨水送得更远。 动画：雨水落到檐口 → 水帘向外抛出一道弧线 

【保国寺的“四谜”】
11 抬头看——鸟为什么不在斗拱上筑巢？最常被提起的解释是？ A 殿里太吵 / B 木头的气味 / C 鸟怕高 → B 一说大殿用的黄桧木自带芳香油，气味让鸟虫都不愿靠近； 动画：镜头推近木纹 → 淡青色气味分子飘出 → 一只鸟落下来又扑棱飞走。

12 这些木头一千年没被虫蛀，靠的是什么？ A 刷了药 / B 虫不吃古建 / C 木材自带气味 → C 黄桧类木材含芳香油，虫不爱蛀；加上大殿通风干燥，木头始终保持“不好吃”的状态。 

13 梁上为什么不见蜘蛛结网？换个角度想—— A 没虫可吃 / B 风太大 / C 蜘蛛怕高 → A 木不生虫，蜘蛛就没有口粮，自然不在这儿安家。一条链子：木不蛀 → 虫不来 → 蛛不结网。 

14 一千年了，梁上为什么很少积灰？ A 天天有人擦 / B 木头不沾灰 / C 气流把灰带走 → C 斗拱和藻井让空气在梁架间打转，灰尘不容易停下来；动画：灰尘粒子落下 → 被一股上升的旋流卷起 → 从藻井口散出去。

15 藻井正中为什么盘着一条龙？ A 好看 / B 镇火 / C 皇帝专用 → B “藻”是水草，藻井属水；龙主水。古人把它安在屋顶正中，是一套防火的“心理装置”。 

【匠义】
16 只给工匠一把“材”尺，他能盖起整座大殿吗？ A 不能，得一堆图纸 / B 能，所有构件按它算 / C 得看运气 → B 宋代《营造法式》以“材”为模数，再分成“份”，斗拱、梁、柱全按份数算，一套古代的标准化预制体系。 动画：一把发光的材尺 → 构件按份数自动生成、拼接 → 整朵斗拱“长”出来。

17 为什么后来的宫殿，斗拱越做越小、越做越密？ A 更结实 / B 省木头 / C 结构变装饰 → C 明清斗拱的承重作用退化，成了等级和装饰的符号；保国寺这朵，还是真正在“干活”的宋构。 动画：宋构（大而疏）与清构（小而密）并置 → 力流在清构上变暗、在宋构上亮起。
