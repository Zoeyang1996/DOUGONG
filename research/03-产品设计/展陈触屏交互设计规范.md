# 展陈触屏交互设计规范（可直接当验收清单）

> 用途：公共触摸屏不是"网页"，它有独立的设计约束。这份规范用于团队自查与答辩时的"标准化流程"表述。

---

## 一、硬件与人体工学

| 项 | 推荐值 | 说明 |
|---|---|---|
| 屏幕中心高度（成人站立） | 1200—1400 mm | 柜式/立式 |
| 屏幕中心高度（儿童区） | 800—1000 mm | 研学场景常见 |
| 屏幕倾角 | 15°—30° | 垂直易反光，过倾易手酸 |
| 环境光对策 | 亮度 ≥ 700 nit，防眩光 AG 涂层 | 展厅射灯直射是常态 |
| 触控技术 | 投射式电容（PCAP）优先 | 多点触控、响应快、易清洁 |
| 防护 | 防刮、防暴、防指纹；接口穿管 | 公共场所，儿童会拍屏 |
| 主机 | 商用/工业级，7×24 散热 | 不要用家用笔记本 |

**无障碍底线**（源自 Smithsonian 指南）
- 轮椅正向接近：控件最高 ≤ 1220 mm，最低 ≥ 380 mm
- 轮椅侧向接近：最高 ≤ 1370 mm，最低 ≥ 230 mm
- 触敏区域直径 ≥ 75 mm（我们取更严的 **≥ 88 px @1080p**）
- 屏幕表面**必须消除反光**（坐姿与矮个子视高同样要考虑）

---

## 二、界面设计硬指标

| 项 | 指标 |
|---|---|
| 最小触控目标 | 44×44 px（移动端下限）；公共大屏建议 **≥ 48×48 px**，高频按钮（返回/首页）**≥ 60×60 px** |
| 相邻按钮间距 | ≥ 8 px |
| 正文字号 | ≥ 16 px（约 4.2 mm 字高）；标题 ≥ 24 px |
| 字体缩放 | 至少提供两档放大，放大后不破版 |
| 对比度 | 正文 ≥ 4.5:1（WCAG AA），大字号 ≥ 3:1；建议向 7:1 靠 |
| 响应时间 | 视觉反馈 < 100 ms |
| 信息层级 | 一级界面不超过 5 个可点项 |

**颜色使用**
- 不要只用颜色传达状态（色盲用户）。选中 = 颜色 + 描边 + 图标/文字三重标注。
- 避免大面积高饱和纯色做背景（反光 + 视觉疲劳）。
- 深色背景 + 暖木色主体，在展厅低照度环境下更稳。⚠️ 但若是自然采光强的位置，浅底更清晰——**现场测光后再定主题色**。

## 三、交互行为规范

### 必须遵守
1. **手势只用三种**：点击、拖动、双指缩放。其余一律禁止。
2. **同一手势在任何页面行为一致**（这是最容易被忽略的）。
3. **每屏只有一个主操作**，其他操作降级为次要。
4. **永远有出口**：每屏都有"返回"，三秒内能回到首页。
5. **不做悬停依赖**：触屏没有 hover。
6. **自动重置**：10 秒无操作 → 提示动画；30 秒 → 回首页并清空进度。
7. **进度可见**：底部固定步骤指示（1/5）。

### 禁止
- ❌ 长按（不可发现）
- ❌ 多指旋转 / 手势组合
- ❌ 需要精确 1—2 px 拖动的操作（如滑块做细调）
- ❌ 弹出系统级对话框、浏览器的 confirm/alert
- ❌ 任何需要文字输入的必填项（公共屏输入体验极差；如需姓名，用字母/汉字选择盘）

## 四、鲁棒性（展项与网页的分界线）

| 机制 | 做法 |
|---|---|
| 看门狗 | 主线程心跳；10 s 无响应自动 reload |
| 定时重启 | 闭馆后（如 22:00）自动重启并清内存 |
| 异常兜底 | window.onerror 捕获 → 显示友好页 + 3 s 后自恢复 |
| 断网运行 | 全部资产本地化 + Service Worker；零外部 CDN 依赖（含 Draco 解码器、字体） |
| 资源降级 | 启动检测 GPU 能力（`renderer.capabilities`），低配自动关阴影/降贴图 |
| 防盗链/防误触 | 禁用右键、禁用文本选择、禁用双指缩放的浏览器默认行为（`touch-action`） |
| 日志 | 本地记录交互次数、崩溃点，方便运营与答辩展示"使用数据" |

**关键：所有 CDN 都要下载到本地。** 展厅断网是常态，一次白屏就是一次事故。

## 五、内容呈现规范

1. **每屏文字 ≤ 60 字**（不含标题）。要长，就分层。
2. **术语首次出现必须给白话解释**（如"铺作——宋代的'斗拱计量单位'，一朵即一组"）。
3. **每个知识点标注来源**，形式：小号字 + 可展开的"依据"折叠区。
4. **数字必须可视化**（"50 吨"要有一个可感知的对照，如"约等于 33 辆小汽车"）。
5. **争议内容加标签**：`相传` / `有学者认为` / `尚无定论`（用不同颜色的角标）。
6. **不出现无解释的专业缩写**（如"七铺作双杪双下昂单偷心造"必须先拆解再给全称）。

## 六、验收清单（打印出来逐项打勾）

**硬件与场地**
- [ ] 屏幕中心高度实测并记录
- [ ] 现场照度与反光测试（正午/傍晚各一次）
- [ ] 触摸精度测试（四角 + 中心）

**交互**
- [ ] 三种手势全部可用，其他手势无副作用
- [ ] 每屏都能 3 秒内回首页
- [ ] 10 s / 30 s 自动重置生效
- [ ] 无任何 hover 依赖的信息
- [ ] 触控目标尺寸全屏扫描 ≥ 48 px

**性能**
- [ ] 冷启动首屏 < 3 s（本地）
- [ ] 交互场景稳定 60 fps（用 `stats.js` 截图存档）
- [ ] 内存无持续增长（连续 30 分钟操作后 < 500 MB）
- [ ] 断网状态下全流程可用
- [ ] 连续运行 4 h 无崩溃

**内容**
- [ ] 所有知识点有来源标注
- [ ] 传说/争议/无定论均有角标
- [ ] 术语首次出现有白话解释
- [ ] 数字均有可视化对照
- [ ] AI 兜底答案已离线内置（断网也能答）

**无障碍**
- [ ] 对比度抽检（用浏览器工具）
- [ ] 字号两档放大测试
- [ ] 色盲模拟（灰度模式下信息不丢失）
