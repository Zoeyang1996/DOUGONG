# 保国寺大殿：结构与斗拱形制（建模前的技术底稿）

> 用途：三维建模的尺寸依据、构件命名依据、讲解热点的定位依据
> ⚠️ 建模比例建议以本表数据为基准，模型单位统一为**米**

---

## 一、总体尺寸与平面

| 项 | 数据 | 备注 |
|---|---|---|
| 面阔 | 3 间，通面宽 **11.91 m** | 当心间 5.8 m，次间各 3.05 m |
| 进深 | 3 间，**13.36 m** | **进深大于面阔**，这是宋构特征，值得做成一个"反直觉"知识点 |
| 屋顶形式 | 单檐歇山顶 | 清代四周加下檐 → 今见重檐 |
| 柱数 | 16 根（内柱 4 + 檐柱 12） | 全部为瓜棱柱 |
| 构架类型 | 近宋式**厅堂型**构架，但柱上重叠多层柱头枋、前部装平藻井，又具**殿堂型**特征 | 北宋与辽特有的过渡形态 |
| 梁架 | 八架椽屋，前三椽栿、中三椽栿、后乳栿，用四柱 | |
| 屋顶重量 | 约 **50 余吨** | 无一根铁钉，靠榫卯承托 |

**空间布局的奇特处（强烈建议做成交互观察点）**：
沿进深方向最南一间是**敞廊**（三面敞开，装平藻井），殿门设在前内柱处，其北才是殿内——而殿内反而是梁架完全暴露的"**彻上露明造**"。
即：**外面精装，里面素装**。这与今天"入口大堂豪华、内部简化"的直觉完全相反，是极好的叙事反差。同类做法见于福州华林寺大殿，可能是当时南方佛殿的共性。

## 二、斗拱总览

| 项 | 数据 |
|---|---|
| 总数 | **20 种**（依位置变幻组合） |
| 分布 | 外檐、内檐、天花装修三处 |
| 外檐斗拱 | 7 种，**全部为下昂造**，外跳均为**七铺作双杪双下昂**，下一杪**偷心** |
| 内檐斗拱 | 7 种 |
| 天花装修斗拱 | 3 种（含虾须拱） |
| 补间铺作配置 | 当心间 2 朵，次间 1 朵；内外槽相同 |
| 用材断面 | 高宽比 **3:2**（≈15:10 分），出材率与受力最优解 |
| 特殊构件 | 虾须拱（小藻井角部、平棊四角）、镊口鼓卯 |

> **一句话讲清"为什么是七铺作"**：七铺作 = 出四跳，属宋代高等级做法；双杪（两跳华栱）+ 双下昂（两跳下昂）。前檐柱头铺作的下昂昂身长达**两椽跨**，尾端抵在内柱华栱之下，中间承下平槫，**作用相当于一根斜梁**——这是保国寺斗拱最精彩的结构巧思，建议做成核心动画。

## 三、构件级数据（做"零件库"用）

### 1. 柱
- 16 根柱**全部为瓜棱柱**，共 6 种形式：
  1. 拼合柱（两种）
  2. 包镶式
  3. 整木柱 3/4 带瓜棱
  4. 整木柱 1/2 带瓜棱
  5. 整木瓜棱柱
- 中心 4 根最特殊：**四段合小柱承重 + 外围镶四瓣装饰 → 外观八瓣**。宋代称"八觚"或"八混"。
- 柱身有明显**侧脚**（向内微倾），省材且稳固。
- 柱上栌斗随柱身做八瓣；补间铺作栌斗为矩形，四角刻入作海棠瓣。

### 2. 额枋与装修
- 阑额两肩有**卷杀**；前檐及山面南侧一间的阑额为**月梁形**。
- 额下采用**蝉肚绰幕**构件（前檐阑额下的雀替与殿内小藻井，是现存最古的木制实物）。
- 阑额上有**"七朱八白"彩画**（《营造法式》"檐额或大额刷八白者……俗谓之七朱八白"）。
- 藻井：当心间大藻井（下部八角井，直径 185 cm，穹窿高 90 cm）+ 两侧小藻井（直径 128 cm，高 75 cm）+ 两侧平棊。
- 明间藻井两侧平棊有**卷草纹彩画**（疑为后世所绘）。

### 3. 石构件
- 佛坛为北宋崇宁元年（1102）建，束腰处有《造石佛座记》。
- 柱础均为石质但**非宋代遗物**（须弥座式、鼓形、圆短柱形不等），是多次更换的结果。

### 4. 构件总量（做"数据可视化"用）
- 大殿内近 **3000 个构件**逐一手测，精确到毫米。
- 其中 **斗 1504 个**、**栱 673 根**。

## 四、建模工作量估算与取舍建议

| 层级 | 范围 | 预估构件数 | 建议 |
|---|---|---|---|
| L0 体块 | 大殿外形 + 屋顶 | 10 | 一周内出，用于场景定位 |
| L1 主角 | 一朵**前檐柱头铺作**（七铺作双杪双下昂） | 约 40—60 件 | **核心资产**，精细到榫卯 |
| L2 对照 | 一朵**补间铺作** + 一朵**转角铺作** | 各 40—60 件 | 用于"三种位置"对比 |
| L3 天花 | 大藻井 + 虾须拱 | 约 80 件 | 做"海内孤例"高光点 |
| L4 全殿 | 16 根柱 + 梁架 + 铺作层 | 3000+ | **不做全量**，只做剪影/低模做背景 |

**核心建议**：把 80% 的模型预算压在 L1 那一朵上。观众记住的是"我看清了一朵斗拱怎么咬住的"，不是"我看了整栋房子"。
