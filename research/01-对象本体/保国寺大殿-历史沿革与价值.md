# 保国寺大殿：历史沿革与价值定位

> 用途：讲解脚本的事实底稿、答辩陈述、AI 知识库的"人物小传"部分
> 核实状态：✅ 已由多个独立信源交叉验证（见文末）

## 一、基础档案（可直接做成信息卡）

| 项 | 内容 |
|---|---|
| 正式名称 | 保国寺（旧名灵山寺，唐僖宗赐名"保国寺"） |
| 现机构 | 宁波市保国寺古建筑博物馆 / 天一阁博物院下属 |
| 地址 | 浙江省宁波市江北区洪塘街道鞍山村安东 49 号（灵山山岙） |
| 大殿建造年代 | 北宋真宗大中祥符六年（公元 1013 年） |
| 保护级别 | 1961 年第一批全国重点文物保护单位 |
| 景区等级 | 国家 AAAA 级旅游景区 |
| 发现时间 | 1954 年 8 月，南京工学院刘敦桢教授带暑期实习小组发现 |
| 核心定位 | 长江以南最古老、保存最完整的木构建筑之一；《营造法式》的南方实证 |

**一句话卖点**：这是 1013 年的房子，用 1100 年前的榫卯、没有一根铁钉，托起 50 余吨屋顶，扛过 1000 多个江南的梅雨、台风和白蚁。

## 二、时间轴（可做成交互时间轴组件）

| 年代 | 事件 |
|---|---|
| 东汉 | 骠骑将军张意父子隐居灵山，舍宅为寺，初名"灵山寺"（传说层，可标注"据寺志记载"） |
| 唐会昌五年（845） | "会昌灭法"，寺宇被毁 |

| 1954 | 刘敦桢团队发现，震动中国建筑史学界 |
| 1961 | 列入第一批全国重点文物保护单位 |
| 2003 | 与清华大学郭黛姮团队合作，出版《东来第一山——保国寺》 |

| 2013 | 大殿千年大庆；获评 AAAA 级景区 |

## 三、四个"为什么值得做"的价值点

### 1. 结构价值：北宋官方标准的活标本
- 营造技艺代表 11 世纪初世界先进水平，与 90 年后成书的《营造法式》大量吻合。
- 为说明《营造法式》中"某些制度源自南方"提供关键佐证。
- **讲解切口**：不是"中国古建筑很厉害"，而是"一部国家标准，是从这样一栋房子这样的地方经验里长出来的"。

### 2. 技术价值：四个"海内孤例/最早实例"
| 技术点 | 意义 |
|---|---|
| 拼合瓜棱柱 | 以四段小木拼成大柱、外镶四瓣形成八瓣外观，实现"以小拼大"，是**仅存的宋代拼合柱实例** |
| 瓜瓣栌斗与柱身对应 | 柱上栌斗也做八瓣，与柱身呼应成一体，**现存遗构中的唯一案例**，反证瓜棱柱确为宋代原物 |
| 虾须拱 + "鼓卯到心" | 用于小藻井角部与平棊四角，**海内孤例** |
| 镊口鼓卯（反做燕尾榫） | 一般燕尾榫是"柱开卯眼、梁做榫头"，此处反过来做，是**已知最早案例**之一 |

> 这四点是产品最硬的差异化素材——每一条都能做成一个"放大镜"式交互热点。

### 3. 历史价值：一部活的建筑史教科书
寺内同时存有汉（骠骑井）、唐（经幢）、宋（大殿）、明（迎薰楼）、清（天王殿、观音殿、钟楼、鼓楼）、民国（藏经楼）各期建筑。**可以做一个"同一座山、六个朝代"的横向对比交互**，这是绝大多数单点古建做不到的。

### 4. 文化价值：江南气候下的千年生存
江南多雨潮湿、台风频繁、白蚁横行，木构能存千年本身是奇迹。殿内"虫不蛀、鸟不栖、蜘蛛不结网、梁上无灰尘"（俗称"四奇"）的现象至今无完全统一的科学解释——**适合做成"悬疑钩子"引入，但要明确标注"尚无定论"，不可当结论讲**。

## 四、文案红线（AI 讲解必须遵守）

1. **不把传说当史实**。张意舍宅、德贤法师募化、鲁班显灵等均为寺志/民间传说，须标"相传"。
2. **不把清代加建当宋代原构**。现存重檐的下檐是清代所加，宋构是单檐歇山。
3. **"四奇"须标"现象记载/尚无定论"**，不可写成科学结论。
4. **不做超出文献的建筑复原推测**。若做"1013 年建成时"的三维复原，须在界面显著标注"复原示意，非考古结论"。
5. 引用数据须给出来源（张十庆测绘、郭黛姮研究等），符合申报书"知识库内容标注来源、不臆造史实"的要求。
