小小营造师 · 西沃离线版

1. 把本文件夹拷贝到西沃电脑的桌面。
2. 双击“ 双击打开-斗拱挑战.html ”即可开始，不需要联网、不需要安装 Blender、不需要服务器。
3. 如果系统没有用浏览器打开：右键 HTML 文件 → 打开方式 → Microsoft Edge 或 Google Chrome。
4. 点击网页右上角“全屏”，或按键盘 F11。
5. 点击“开始挑战”，在120秒内完成18组拼装。可拖放，也可先点右侧构件，再点左侧落点。

所有模型、Three.js、木材贴图生成代码、样式、效果图均已内嵌在 HTML 内。仅复制这个 HTML 文件也可以运行。ZIP文件请先完整解压，再打开其中的HTML，不要直接从压缩包预览。

运行环境：支持 WebGL 2 的现代 Edge / Chrome。网页使用系统中文字体，不同电脑字形可能略有差异。西沃的具体设备性能及真实多点触摸仍需现场确认。若显示三维载入失败，请先用 Edge 打开并检查浏览器硬件加速；无需降低浏览器安全设置。

模型为现有形制草模的游戏搭接修正版，非施工或加工依据。
