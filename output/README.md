# 导出成果

| 文件或目录 | 用途 |
|---|---|
| `小小营造师-西沃离线版/` | 第三幕离线游戏，HTML 已内嵌模型与程序，直接双击打开 |
| `小小营造师-西沃离线版.zip` | 同版打包副本，方便复制到其他电脑；先解压再打开 |

| `保国寺斗拱-FBX资产包-v01.zip` | FBX 交付压缩包 |

这里放交付物，不作为源代码编辑入口。网页源文件在 `../web-exhibits/`，模型工程在 `../models/`。离线包可能落后于源码；演示前按需重新生成。

第三幕重新打包：在项目根目录运行 `node web-exhibits/act-03-assembly/scripts/build-offline.mjs`。不要删除第一幕的 `node_modules`，此命令目前使用其中的打包工具。
